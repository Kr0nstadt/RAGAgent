# AGENTS.md — инструкции для RAGAgent

## Стек
- Ядро: `graph_rag_1c_erp.py` — Graph RAG + LLM генератор инструкций
- Локальная LLM: **Ollama** (`http://localhost:11434`), модель `qwen2.5:7b`
- Загружено: 48639 чанков, 48480 узлов графа (документация + код конфигурации)
- Граф строится из:
  - Markdown-документации ITS (`001--1С-ERP Управление предприятием 2, редакция 2.5/`)
  - XML-выгрузки конфигурации 1С ERP (`ERPcode/`)

## Команды
```powershell
# Сборка графа (документация + код конфигурации)
python graph_rag_1c_erp.py build

# Интерактивный режим (поиск + промпт + генерация)
python graph_rag_1c_erp.py interactive

# Сгенерировать инструкцию (локальная Ollama)
python graph_rag_1c_erp.py instruct "твой запрос"

# Указать провайдер/модель явно
python graph_rag_1c_erp.py instruct "запрос" --provider ollama --model qwen2.5:7b

# Запустить FastAPI-сервер
python graph_rag_1c_erp.py serve --port 8000
```

## Режимы работы
| Режим | Команда | Что делает |
|-------|---------|------------|
| **Сборка** | `build` | Парсит .md + XML → строит граф + эмбеддинги |
| **Интерактивный** | `interactive` | Вводишь запрос → видишь что нашёл граф → видишь промпт для LLM → решаешь генерировать ли инструкцию |
| **Пакетный** | `instruct "запрос"` | Сразу генерирует инструкцию и выводит результат |
| **Поисковый** | `query "запрос"` | Только поиск по графу, без LLM |
| **API сервер** | `serve` | FastAPI сервер для интеграций |

## Важные особенности
1. **Компактный промпт для Ollama**: для маленьких локальных моделей используется `_build_compact_prompt()` — короткий промпт без полного текста документации (только названия 3-х релевантных разделов)
2. **Для облачных моделей** (DeepSeek, Gemini) — полный промпт `build_prompt()` с полным контекстом документации
3. Ollama на CPU — очень медленный (30-120с на ответ), qwen2.5:7b должен давать более точные инструкции. Таймаут увеличен до 600с.
4. **ERPcode**: XML-выгрузка конфигурации 1С ERP парсится в граф отдельно — из каждого XML извлекаются Name, Synonym, Attributes (реквизиты) с типами и ссылками на другие объекты метаданных

## Если Ollama не отвечает
```powershell
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" list
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" ps
# Если модель зависла — остановить:
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" stop qwen2.5:7b
```
