## Часть 2. Пошаговая инструкция по настройке сквозного бизнес-процесса

### Описание процесса

Настраивается **сквозной бизнес-процесс производства хлебобулочных изделий с двухэтапным производством**: Закупка сырья → Входной контроль → Передача в холодный цех → Замес теста (полуфабрикат) → Передача теста в горячий цех → Выпечка (готовая продукция) → Передача на склад ГП → Списание брака.

---

### Шаг 0. Предварительные настройки (НСИ)

#### 0.1. Склады
**Путь:** Раздел **НСИ** → подраздел **Склады и магазины** → **Склады**

Создайте следующие склады:
1. **Склад сырья** — Тип: «Оптовый склад», настройка «Контроль остатков»: да.
2. **Кладовая холодного цеха** — Тип: «Кладовая» (для полуфабрикатов/теста).
3. **Кладовая горячего цеха** — Тип: «Кладовая» (или подразделение «Горячий цех» как склад).
4. **Склад готовой продукции** — Тип: «Оптовый склад».
5. **Склад упаковочных материалов** — Тип: «Оптовый склад».

> **Проверка:** В отчете «Остатки по складам» (Раздел **Склад** → **Отчеты** → **Остатки товаров на складах**) все 5 складов должны быть в списке.

#### 0.2. Подразделения
**Путь:** Раздел **НСИ** → подраздел **Организации** → **Подразделения** (или **Производство** → **Структура предприятия**)

Создайте:
1. **Холодный цех** — Производственное подразделение (где замешивается тесто).
2. **Горячий цех** — Производственное подразделение (где происходит выпечка).

#### 0.3. Виды цен (для оценки стоимости)
**Путь:** Раздел **Маркетинг и ценообразование** → **Виды цен**

Создайте **Учетный вид цены** (например, «Цена для производства») с настройкой: использовать для стоимости передачи в производство.

#### 0.4. Ставки НДС
**Путь:** Раздел **НСИ** → подраздел **Финансы** → **Ставки НДС**

Проверьте наличие ставки **20%** (или **Без НДС**).

#### 0.5. Качество товаров (для учета брака)
**Путь:** Раздел **НСИ** → подраздел **Номенклатура** → **Качество товаров**

Создайте элемент: **«Негоден/Брак»**. В дальнейшем при списании брака будем указывать это качество.

---

### Шаг 1. Заведение видов номенклатуры

**Путь:** Раздел **НСИ** → подраздел **Номенклатура** → **Виды номенклатуры**

1. Нажмите кнопку **«Создать»**.
2. Заполните для каждого вида:
   - **Наименование**: «Готовая продукция».
   - **Тип номенклатуры**: «Продукция» (выпадающий список).
   - **Группа аналитического учета**: «Готовая продукция».
   - **Политика учета серий**: Создайте новую политику «УчетГП_ПоСрокуГодности»:
     - **Использовать серии**: ✓.
     - **Политика**: «Учет по партиям».
     - **Определяется по**: «Партии».
     - **Добавить реквизит серии**: «Срок годности» (или «Годен до»).
   - Сохраните.
3. Аналогично создайте виды: **«Полуфабрикаты»**, **«Сырье»**, **«Упаковочные материалы»**.

> **Проверка:** Откройте **Справочник «Виды номенклатуры»** — в списке 4 элемента. У вида «Готовая продукция» в поле «Политика серий» стоит ваша настройка.

---

### Шаг 2. Заполнение справочника «Номенклатура»

**Путь:** Раздел **НСИ** → подраздел **Номенклатура** → **Номенклатура**

#### 2.1. Готовая продукция (5 позиций)
Для каждой позиции:
- **Наименование**: Батон белый, Хлеб белый высший сорт, Хлеб бородинский ржаной, Слойка с изюмом, Лепешка из тандыра.
- **Вид номенклатуры**: «Готовая продукция» (ссылка из шага 1).
- **Единица измерения**: шт.
- **Срок годности**: 5 (дней).
- **Ставка НДС**: 20%.
- **Качество**: «Новый» (основное).

#### 2.2. Полуфабрикат
- **Наименование**: Тесто для батона белого (отдельная позиция для каждого рецепта).
- **Вид номенклатуры**: «Полуфабрикаты».
- **Единица измерения**: кг.

#### 2.3. Сырье
- **Наименование**: Мука пшеничная, Мука ржаная, Дрожжи, Соль, Сахар, Семена для посыпки.
- **Вид номенклатуры**: «Сырье».
- **Единица измерения**: кг.

#### 2.4. Упаковка
- **Наименование**: Пакет, Пленка.
- **Вид номенклатуры**: «Упаковочные материалы».
- **Единица измерения**: шт.

> **Проверка:** В **Отчете «Остатки номенклатуры»** (Раздел **НСИ** → **Отчеты** по номенклатуре) — список всех созданных позиций.

---

### Шаг 3. Создание ресурсных спецификаций (рецептур)

**Путь:** Раздел **Производство** → подраздел **Нормативно-справочная информация** → **Ресурсные спецификации**

1. Нажмите **«Создать»**.
2. **Наименование**: «Рецепт теста для батона белого».
3. **Продукция (выход)**: 1000 кг — полуфабрикат «Тесто для батона белого».
4. **Подразделение-исполнитель**: «Холодный цех».
5. Заполните таблицу **«Материалы»** (на 1000 кг теста): мука пшеничная — 700 кг, дрожжи — 20 кг, соль — 15 кг, сахар — 5 кг, вода — 260 кг.
6. Аналогично создайте рецепты для теста под каждый вид хлеба.
7. Затем создайте спецификацию для **выпечки**: 
   - **Продукция (выход)**: Батон белый (1 шт).
   - **Полуфабрикат на входе**: Тесто для батона (0,5 кг на 1 батон).
   - **Упаковка**: Пакет (1 шт).
   - **Подразделение-исполнитель**: «Горячий цех».

> **Проверка:** В **Отчете «Спецификации»** (Раздел **Производство** → **Отчеты**) отображаются все созданные спецификации.

---

### Шаг 4. Сквозной документооборот (хозяйственные операции)

#### 4.1. Поступление сырья от поставщика
**Путь:** Раздел **Закупки** → подраздел **Закупки товаров, работ, услуг** → **Поступление товаров и услуг**

1. Создайте документ.
2. **Шапка**: Контрагент (поставщик), Соглашение, Склад получения: **«Склад сырья»**.
3. **Табличная часть «Товары»**:
   - Мука пшеничная — 1000 кг, Цена: 50 ₽, Сумма: 50 000 ₽, НДС: 20%.
   - Аналогично дрожжи, соль, сахар.
4. **Входной контроль**: После проведения документа входной контроль фиксируется через **«Акт о расходе материалов при входном контроле»** или через отражение **«Качества товара»** = «Ограниченно годен» (если мука не прошла контроль). Если качество «Ограниченно годен», используйте документ **«Изменение качества товаров»** (Раздел **Склад**).
5. Проведите документ.

> **Проверка:** В **Отчете «Остатки товаров на складах»** → склад «Склад сырья» — есть поступившее сырье.

#### 4.2. Передача сырья в производство (холодный цех)
**Путь:** Раздел **Производство** → **Этап производства** (или **Заказ на производство** → **Этап производства**)

Рекомендуется сначала создать **«Заказ на производство»**, затем на основании него — **«Этап производства»**.

1. **Раздел Закупки** не нужен — используем **Раздел Производство** → **Этапы производства**.
2. Создайте **«Этап производства»** (этап 1 — замес теста):
   - **Дата**: текущая.
   - **Подразделение**: «Холодный цех».
   - **Продукция (выход)**: Тесто для батона — 1000 кг.
   - **Спецификация**: выберите созданную.
   - **Склад (для материалов)**: «Склад сырья» (откуда списываем).
   - **Кладовая (куда приходуем полуфабрикат)**: «Кладовая холодного цеха».
   - Таблица «Материалы» подтянется автоматически из спецификации.
3. Проведите документ. Нажмите кнопку **«Передать к выполнению» → «Отметить выполнение»**.

> **Проверка:** В **Отчете «Остатки полуфабрикатов»** (Раздел **Производство** → **Отчеты**) — на «Кладовой холодного цеха» появилось тесто в количестве 1000 кг.

#### 4.3. Передача теста из холодного цеха в горячий
**Путь:** Раздел **Производство** → **Движение продукции и материалов**

Согласно контексту документации: «Документ предназначен для отражения в системе движения ТМЦ между складами, производственными подразделениями и цеховыми кладовыми в рамках операций: Передача продукции из производства, Передача продукции из кладовой, Передача материалов».

1. Создайте документ **«Движение продукции и материалов»**.
2. **Хозяйственная операция**: **«Передача продукции из кладовой»**.
3. **Шапка**:
   - **Дата**: текущая.
   - **Отправитель**: «Кладовая холодного цеха».
   - **Получатель**: «Кладовая горячего цеха» (или подразделение «Горячий цех»).
   - **Подразделение**: «Горячий цех».
4. **Табличная часть «Продукция»**:
   - Номенклатура: «Тесто для батона белого», Количество: 500 кг.
5. Проведите документ.

> **Проверка:** В **Отчете «Движение продукции и материалов»** или в **«Остатках по складам»** — тесто ушло с «Кладовой холодного цеха» и появилось на «Кладовой горячего цеха».

#### 4.4. Этап производства 2 — Выпечка (горячий цех)
**Путь:** Раздел **Производство** → **Этап производства**

1. Создайте **«Этап производства»** (этап 2 — выпечка):
   - **Подразделение**: «Горячий цех».
   - **Продукция (выход)**: Батон белый — 1000 шт (1 шт = 0,5 кг теста).
   - **Спецификация**: рецепт выпечки.
   - **Склад (откуда списываются материалы)**: «Кладовая горячего цеха» (тесто) + «Склад упаковочных материалов» (пакеты).
   - **Кладовая / Склад прихода продукции**: **«Склад готовой продукции»**.
2. **Важно:** В материалах табличной части должны быть и полуфабрикат (тесто), и упаковка (пакет) — спецификация подтянет их автоматически.
3. Проведите документ. Нажмите **«Отметить выполнение»**.

> **Проверка:** В **Отчете «Выпуск продукции»** (Раздел **Производство** → **Отчеты**) — на «Складе готовой продукции» появился «Батон белый» в количестве 1000 шт. Упаковка (пакеты) списана со «Склада упаковочных материалов».

#### 4.5. Списание брака готовой продукции

### Важные примечания (согласно ответам пользователя)

1. **Двухэтапное производство**: Обязательно используйте **два «Этапа производства»** в рамках одного **«Заказа на производство»** или двух связанных заказов. Граница ответственности: **Холодный цех** (замес) → передача → **Горячий цех** (выпечка).

2. **Контроль сроков годности**: Так как в политике серий вида номенклатуры «Готовая продукция» включен реквизит «Срок годности» с политикой «Партия», при выпуске документ «Этап производства» будет запрашивать ввод серии (дату выработки/срок годности) автоматически.

3. **Брак — простое списание**: Используется документ **«Списание товаров»** с указанием качества «Негоден/Брак». Без возврата в производство и без реализации со скидкой.

4. **Упаковка включается в стоимость**: В **Спецификации** на этапе выпечки упаковка указана в материалах → списывается автоматически в момент выпуска → включается в себестоимость ГП. Отдельных норм расхода на единицу не задается (указывается фактическое количество в этапе производства).

5. **Многооборотная тара не учитывается**: Лотки и тележки **не создаются** в справочнике «Номенклатура» и не отражаются в системе.

### Что нужно уточнить дополнительно

Для полной настройки не хватает следующих данных (рекомендую согласовать с пользователем):

1. **Организация** — заведена ли в системе? Необходима для всех документов (поле «Организация» в шапке).
2. **Соглашения с поставщиками сырья** — нужны для автоматического заполнения документа «Поступление товаров и услуг».
3. **Учетная политика производства** — настроена ли в разделе «Производство» (способ учета себестоимости, плановая цена и т.п.)?
4. **График производства** — двухэтапное производство может оформляться через «Заказ на производство» с двумя «Этапами производства» (по датам). Уточните, нужна ли привязка к плану продаж или производство идет «на склад».
5. **Каким документом оформляется входной контроль качества** — через документ **«Изменение качества товаров»** или через **«Акт о расходе при входном контроле»**?
