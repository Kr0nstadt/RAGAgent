# Механизм партионного учета

## Варианты использования партионного учета

В прикладном решении используется механизм партионного учета товарно-материальных ценностей, при котором каждая партия учитывается обособленно.

Партионный учет построен на использовании регистра оперативного учета Себестоимость товаров.

Особенности распределения партий:

■ выполняется целиком за месячный отчетный период, хронологическая последовательность приходных и расходных документов не важна;

■ распределение выполняется по одной из организаций (при условии отсутствия фактов передачи товаров между организациями) либо по группе организаций, между которыми были оформлены передачи товаров;

■ необходимо избегать встречных перемещений, так как в этом случае стоимость не будет рассчитана.

Необходимо обратить внимание, что учет в разрезе исходных партий поступления товаров в регистре оперативного учета **Себестоимость товаров** ведется для организаций, у которых в учетной политике выбран способ оценки запасов **ФИФО**.

## Контроль актуальности распределения по партиям товаров

Применение контроля актуальности распределения по партиям товаров определяется функциональной опцией НСИ и администрирование – Настройка НСИ и разделов – Финансовый результат и контроллинг – Автоматические расчеты – Автоматически запускать фоновое задание распределения партий товаров.

Контроль актуальности распределений партий выполняется при помощи отчета Ведомость по партиям товаров.

Если данные неактуальны, то отчет формируется, но в отчете выводится предупреждение Распределение партий выполнено по… и автоматически запускается фоновое задание по актуализации партионного учета.

При формировании отчета за текущий месяц задание выполняет расчет до конца текущего месяца, в остальных случаях – до начала текущего месяца.

После успешного выполнения фонового задания выводится информационное сообщение с предложением переформировать отчет. Если пользователь соглашается, то отчет формируется по новым рассчитанным данным.
