# Ввод начальных остатков по учету кадров и зарплаты

Процесс ввода начальных остатков по учету кадров и зарплаты следует разделить на две части:

■ Ввод начальных данных в зарплатном контуре.

○ Сначала в подсистеме Кадры необходимо создать документ Начальная штатная расстановка.

○ При этом, если кадровые приказы вводились до начала учета в системе, то информацию о них можно внести в регистр сведений Реестр кадровых приказов документом НСИ и администрирование – Начальное заполнение - Перенос данных подсистемы расчета зарплаты.

○ Затем в подсистеме Зарплата создается документ Начальная задолженность по зарплате.

○ Для ввода остатков по взаиморасчетам по займам сотрудникам нужно ввести остатки по регистрам при помощи документа Перенос данных. Необходимо наличие остатков по регистру накопления Взаиморасчеты по займам сотрудникам, а также корректные записи в регистре сведений Условия договора займа сотруднику.

○ Остатки сумм исчисленного и не удержанного НДФЛ могут быть с помощью документа Перенос данных перенесены в регистр накопления Расчеты налогоплательщиков с бюджетом по НДФЛ по виду движения Приход.

■ Ввод остатков (долгов по выплатам зарплаты) в финансовом (управленческом, регламентированном) учете.

○ Необходимо ввести остатки по статьям активов/пассивов при помощи документа НСИ и администрирование – Начальное заполнение – Начальное заполнение – Документы ввода начальных остатков с типом операции Прочие активы и пассивы (документ является в данном случае непроводкообразующим).

○ Для формирования остатков по счетам бухгалтерского учета используется документ Регламентированный учет – Операция (регл. учет).

Для ввода остатков резервов по оплате труда используется документ Резервы по оплате труда (операция Корректировка), который вводится в конце года. В способе отражения зарплаты рекомендуется настроить статью активов и пассивов и указать счет 000.
