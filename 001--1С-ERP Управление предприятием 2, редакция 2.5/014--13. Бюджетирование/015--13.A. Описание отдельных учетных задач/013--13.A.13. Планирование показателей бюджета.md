# Планирование показателей бюджета

## Планирование расчетного показателя

Актуально до версии 2.5.27.

Шаг 1. Первоначально необходимо определить максимально возможную границу фактических данных, до которой данные изменяться не будут.

При составлении прогнозного баланса для вида бюджета нужно установить границу фактических данных до начала периода бюджета. Это необходимо сделать, если нужно спланировать прогнозный баланс, по которому плановые остатки по статьям баланса (показателям бюджета) не должны изменяться.

Шаг 2.

В рассматриваемом примере определим границу фактических данных - 1 ноября 2021 года.

Создаем вид бюджета «Прогноз баланса» на 2022 год и зададим период планирования Год. Флаг Ввод плановых данных устанавливать не будем, поскольку для прогнозного баланса используем расчетные показатели.

Далее установим переключатель Граница фактических данных на значении Располагается до начала периода бюджета и установим значение 2 месяца в поле Бюджет составляется за.

Поскольку мы установили в границе фактических данных Год и планируем формировать бюджет за 2022 год, а также мы определили 1 ноября 21 года как границу фактических данных, поэтому в этом виде бюджета в поле Бюджет составляется за установим значение 2 месяца.

Внимание

Если создается вид бюджет без остатков статей баланса, т.е. только статьи доходов и расходов, то можно использовать любое значение переключателя Граница фактических данных или вариант Предполагается внутри периода бюджета (данный вариант по умолчанию).

Если бюджет состоит из плановых балансовых статей или плановые денежные остатки для БДДС, то необходимо использовать значение переключателя Граница фактических данных Располагается до начала периода бюджета.

Для вида бюджета «План-факт баланса» зададим период планирования Месяц. Переключатель установим на значении Граница фактических данных на значении Располагается до начала периода бюджета и установим значение 4 месяца в поле Бюджет составляется за.

Поскольку мы установили в границе фактических данных Месяц и планируем формировать бюджет с марта 2022 года, а также мы определили 1 ноября 21 года как границу фактических данных, поэтому в этом виде бюджета в поле Бюджет составляется за установим значение 4 месяца.

Шаг 3. Для расчета планового остатка на начало периода бюджета необходимо ввести сумму корректировки по одной из статей бюджетов, влияющих на показатель бюджетов, на дату между границей фактических данных и началом периода бюджета. Для этого необходимо в показателе бюджета в настройке связей показателя добавить статью бюджета, с помощью которой далее введем корректировку.

И далее с помощью экземпляра бюджета вводим корректировку значений остатков по балансовым статьям (показателям бюджета) между значением факта на 1 ноября 21 года и прогнозным значением на начало планирования - 1 марта 22 года. Корректировку можно внести в любой месяц между 1 ноября 2021 годом и 1 марта 2022 года.

Шаг 4.

Дополнительно для расчета начального и конечного остатков показателей бюджетов необходимо настроить границы данных показателей для получения данных для отчета. Для этого необходимо зайти в настройку ячеек (для сложной таблицы), открыть для показателя бюджета окно Настройки показателя бюджетов

перейти по гиперссылке Установлены границы периода и в окне Настройка периода данных в поле Границы данных необходимо выбрать значение От границы факт. данных по окончание периода бюджета.

Смещение задавать не нужно, так как оно уже задано для вида бюджета в целом. Уточнение периода данных в группировке не требуется, оставляем Из текущей группировки.

При настройке показателей бюджета в настройках периода данных можно выбрать несколько вариантов значений для группировки:

■ Из текущей группировки - за указанный период группировки в бюджетном отчете;

■ Нарастающий итог;

■ За весь интервал данных - все данные по периодам группировки за весь период бюджета указанного в экземпляре бюджета или в бюджетном отчете;

■ Произвольный период.

Шаг 5. Формируем отчет. Данные по смещению границы фактических данных устанавливаются автоматически, исходя из периода, который задан в отчете и периоду корректировки, указанному в виде бюджета в поле Бюджет составляется за.
