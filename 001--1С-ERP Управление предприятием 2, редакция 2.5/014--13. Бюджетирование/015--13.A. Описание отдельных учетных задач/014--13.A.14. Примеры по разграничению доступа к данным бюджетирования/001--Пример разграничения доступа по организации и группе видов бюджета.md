# Примеры по разграничению доступа к данным бюджетирования

## Пример разграничения доступа по организации и группе видов бюджета

Рекомендуем изучить теоретический материал по данной теме в статье [Разграничение доступа к данным бюджетирования](/db/erp25doc/bookmark/rlsbudgeting/RLSBudgeting).

Шаг 1. Во-первых, необходимо установить флаг Группы доступа видов, статей и показателей бюджетов (см. раздел НСИ и администрирование – Администрирование – Настройки пользователей и прав).

Шаг 2. Переходим по гиперссылке Группы доступа видов бюджетов и настраиваем необходимые группы доступа. Для данного примера создадим следующие группы: «Руководитель ЦФО», «Учредители и ГД», «Финансовый директор».

Шаг 3. Зайдем в виды бюджетов и укажем необходимое значение в поле Группа доступа. Затем необходимо перепровести экземпляры бюджетов по соответствующему виду бюджета, в котором была проставлена группа доступа.

Шаг 4.  Далее в настройках прав пользователей перейдем по гиперссылке Группы доступа.

В группе доступа Исполнитель бюджетного процесса (дополнительный) на закладке Участники группы выбираем пользователя.

На закладке Ограничения доступа настраиваем ограничение по группам видов бюджета и организациям.

Шаг 5. Теперь зайдем в систему под пользователем, доступ которому настроили и проверим результат.

В журнале Виды бюджетов пользователю доступны только бюджеты с группой доступа «Руководитель ЦФО».

 

В журнале Экземпляры бюджетов пользователю доступны только бюджеты с группой доступа «Руководитель ЦФО» по организации ООО «Андромеда Сервис».
