# Ввод начальных остатков расчетных показателей бюджетов

В системе есть четыре варианта получения остатков для прогнозного баланса: по фактическим начальным остаткам, по границе фактических остатков, по фиксированным значениям остатков и по плановым конечным остаткам.

Особенности формирования остатков по фактическим начальным остаткам:

■ Остатки непрерывно корректируются вплоть до закрытия текущего периода от редактирования.

■ Используется в бюджетных отчетах по умолчанию (без настройки смещения периода), а также в оборотно - сальдовой ведомости по показателям бюджетов.

Особенности формирования остатков по границе фактических остатков:

■ Остатки считаются условно фиксированными, так как период на границе фактических данных считается закрытым от редактирования.

■ Остатки корректируются до начала периода бюджета плановыми оборотами влияющих статей бюджетов от границы фактических данных до начала периода бюджета.

■ Используется только в бюджетных отчетах при настройке смещения периода «от границы фактических данных по окончанию периода бюджета» или «произвольный период» (с настройкой начала периода через границу фактических данных).

Особенности формирования остатков по фиксированным значениям остатков:

■ Теперь доступно для бюджетных отчетов с любыми настройками смещения периода и для оборотно-сальдовой ведомости по показателям бюджетов.

Особенности формирования остатков по плановым конечным остаткам:

■ Также появилась новая возможность вводить остатки по введенному в пределах года  документу Начальные остатки расчетного показателя и плановым оборотам от даты ввода остатков до текущей даты ввода остатков.

## Установка плановых начальных остатков вручную

Ввод начальных остатков расчетных показателей доступен в разделе Бюджетирование и планирование – Бюджеты – Начальные остатки расчетных показателей.

В журнале документов можно увидеть все документы по вводу остатков с указанием даты остатков, расчетного показателя и сценария. Дополнительно можно настроить отбор по дате остатков и расчетному показателю.

В шапке документа указывается месяц ввода остатков и расчетный показатель бюджетов.

В документе настраивается ввод остатков в разрезе измерений бюджетирования:

■ по конкретному сценарию или по всем сценариям;

■ по организациям или без учета организаций;

■ по подразделениям или без учета подразделений.

В табличной части документа Начальные остатки расчетного показателя формируются колонки по настройкам измерений: организаций, подразделений – и по видам аналитик выбранного показателя.

Колонки Валюта и Сумма в валюте выводятся для заполнения остатков по расчетным показателям, для которых ведется учет в валюте. Поле Валюта доступно для редактирования только в том случае, если оно по настройкам показателя не берется из значения аналитики, а указывается вручную в виде бюджета.

Для расчетных показателей бюджетов, учитывающихся по количеству, дополнительно заполняется колонка Количество.

Документ ввода начальных остатков расчетных показателей можно заполнить вручную, указав данные в столбцах: Сумма в валюте, Сумма (упр.), Сумма (регл.).

А также документ Начальные остатки расчетного показателя можно заполнить автоматически с помощью кнопки Заполнить по разным алгоритмам заполнения:

■ По фактическим начальным остаткам – на дату ввода остатков.

■ По границе фактических данных – с указанием вручную даты границы и расчетом плановых оборотов от указанной даты до даты ввода остатков.

■ По плановым конечным остаткам – по введенному в пределах года  документу Начальные остатки расчетного показателя и плановым оборотам от даты ввода остатков до текущей даты ввода остатков.

Для ввода остатков По границе фактических данных и По плановым конечным остаткам обязательно необходимо указать Сценарий.

При проведении документа формируются движения по регистру сведений Начальные остатки расчетных показателей.

При формировании оборотно - сальдовой ведомости по показателям бюджетов начальные остатки показателей выводятся по введенным плановым значениям. При этом если в разрезе организации, подразделения или аналитики остатки не заданы, то они считаются нулевыми.

## Установка плановых начальных остатков в бюджетном процессе

При настройке бюджетного процесса для ввода остатков расчетных показателей вводится этап с типом действия Установка начальных остатков расчетных показателей.

Этап с типом действия Установка начальных остатков расчетных показателей можно выполнять в автоматическом режиме или вручную пользователем.

В настройках этапа указываются расчетный показатель бюджетов, по которым формируются обороты бюджетов и измерения бюджетирования (организация, подразделение, сценарий).

В настройках для выбора доступны только показатели бюджетов с типом Расчетный.

При выполнении этапа бюджетного процесса с действием Установка начальных остатков расчетных показателей формируются документы по вводу остатков вручную или автоматически в зависимости от настроек этапа.
