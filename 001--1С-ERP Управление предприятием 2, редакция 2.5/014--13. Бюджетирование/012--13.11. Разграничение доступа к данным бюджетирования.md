# Разграничение доступа к данным бюджетирования

Рекомендуем изучить сквозной пример по настройки разграничения доступа к данным бюджетирования в статье [Пример разграничения доступа по организации и группе видов бюджета](/db/erp25doc/bookmark/examplesofdelimitingaccesstobudgetingdata/ExampleofAccessControlbyOrganizationandBudgetTypeGroup).

В совместной работе с данными, часто возникает потребность разграничить видимость одних данных одним пользователям, а других – другим. Для этого существует возможность по гибкой настройке доступа к данным бюджетирования в зависимости от установленных для пользователей прав. Для этих целей используется набор базовых профилей:

■ Администратор бюджетной модели –  позволяет редактировать НСИ бюджетов и настроек бюджетного процесса;

■ Исполнитель бюджетного процесса – позволяет создавать и редактировать данные бюджетирования;

● для редактирования экземпляра бюджета требуется наличие незавершенной бюджетной задачи по вводу бюджета;

■ Координатор бюджетирования – позволяет редактировать данные бюджетирования вне зависимости от использования бюджетных процессов. Включает, в том числе роли:

● редактирование данных бюджетирования вне процессов,

● редактирование данных бюджетирования вне дат запрета изменений.

■ Контролер бюджетирования – позволяет просматривать бюджеты и формировать отчеты.

Дополнительно в раздел НСИ и администрирование – Настройки пользователей и прав – Группы доступа включается вид доступа Группа доступа видов статей и показателей бюджетов.

В перечне Группы доступа видов бюджетов хранятся списки групп доступа для статей и показателей бюджетов, которые предназначены для управления ограничениями доступа к Видам бюджетов. В перечне Группы доступа статей и показателей бюджетов хранятся списки групп доступа для статей и показателей бюджетов, которые будут использоваться для управления ограничениями доступа к данным. При помощи данных перечней осуществляется настройка укрупненных групп доступа к соответствующим элементам и данным бюджетирования.

В момент настройки структуры бюджета, предусмотрен выбор одного из двух режимов получения данных для статей и показателей бюджетов:

■ Учитывать ограничения доступа к данным – доступны данные только по разрешенным источникам;

■ Не учитывать ограничения доступа к данным – доступны все данные. Обычно такой режим может использоваться при расчете относительных величин, например, когда требуется определить долю продаж разрешенных организаций в продажах группы компаний в целом.

В случае отсутствия полного доступа к данным для гарантированного получения целостной информации при формировании бюджетных форм (отчетов или экземпляров бюджета) в виде бюджета (на закладке Основное) присутствуют следующие режимы:

■ Формировать с неполными данными;

■ Не формировать.

В первом случае отображаются только те данные, которые доступны с учетом ограничений на уровне записей (например, данные планируемых продаж только по разрешенным организациям). В последнем случае при попытке формирования отчета или заполнении экземпляра бюджета, при наличии данных, которые недоступны пользователю, будет выведено сообщение об ошибке (например, при формировании баланса по холдингу в целом, если данные некоторых организаций недоступны, то баланс холдинга также будет недоступен).

Дополнительно изменение бюджетных данных может быть ограничено с помощью дат запрета изменений доступных в разделе НСИ и администрирование – Поддержка и обслуживание – Регламентные операции – Даты запрета изменения.

Даты запрета могут быть установлены в разрезе сценариев. Например, помесячный и поквартальный сценарии могут иметь различные даты запрета редактирования. Для этого в способах указания даты запрета необходимо установить вариант По разделам и объектам, после чего из контекстного меню необходимо добавить те сценарии бюджетирования, для которых требуется уточнить период доступности.

В случае использования бюджетного процесса  (доступность которого регулируется отдельной функциональной опцией НСИ и администрирование - Бюджетирование и планирование – Бюджетный процесс) редактирование возможно только при наличии соответствующей задачи.

При этом для бюджетных задач, как части бюджетного процесса, сохраняется право (для назначенных пользователей) на изменение данных в соответствии с указанными параметрами (измерения, аналитики и период планирования). При условии, что даты запрета не используются (все периоды запрещены, кроме тех, что указаны в задаче).

При совместном применении дат запрета и бюджетных процессов, ввод экземпляров бюджетов возможен только в периодах планирования позже даты запрета изменений и при наличии незавершенной бюджетной задачи.
