# Формирование бюджетов по правилам расчета, без открытия формы

Для быстрого расчета большого объема бюджетных данных без заполнения и проведения документов Ввод экземпляра бюджета документа Регистратор оборотов бюджетов, представленного в журнале документов Расчеты бюджетов по правилам.

Реализованы три сценария работы пользователя с документом Регистратор оборотов бюджетов:

■ Заполнение оборотов по статьям бюджетов через бюджетный процесс;

■ Заполнение оборотов по статьям бюджетов интерактивно;

■ Заполнение оборотов по связанным статьям бюджетов при проведении документа Ввод экземпляра бюджета.

После расчета бюджетных данных по любому сценарию их можно выводить в отдельном бюджетном отчете или использовать в правилах расчета связанных остатков и оборотов бюджетов в качестве источника для других бюджетных данных.

## Заполнение оборотов по статьям бюджетов интерактивно

Рассмотрим заполнение оборотов на простом примере в сравнении с расчетами привычным способом с помощью экземпляра бюджета.

Создадим вид бюджета «8 К: План продаж».

С помощью экземпляра бюджета введем план продаж.

Далее рассчитаем плановые значения себестоимости и маржинальной прибыли двумя способами с помощью экземпляра бюджета и без открытия формы.

**Первый способ с помощью экземпляра бюджета**

Сначала создадим вид бюджета для расчета плановых значений себестоимости и маржинальной прибыли.

Себестоимость и маржинальную прибыль настроим с помощью заполнения Расчет оборотов по правилам. Источником для расчетов является статья бюджетов «8 К: Выручка с НДС от реализации джинсов женских».

Сформируем экземпляр бюджета для получения плановых данных по себестоимости и маржинальной прибыли.

**Второй способ по правилам расчета, без открытия формы**

Теперь рассчитаем себестоимость и маржинальную прибыль с помощью формирования бюджетов по правилам расчета, без открытия формы и с помощью отчета выведем результат.

Создадим две статьи бюджетов «8 К: Себестоимость реализации джинсов женских, без открытия форм» и «8 К: Маржинальная прибыль от реализации джинсов женских, без открытия форм».

Себестоимость и маржинальную прибыль настроим с помощью правил расчета связанных оборотов и остатков. Источником для расчетов также является статья бюджетов «8 К: Выручка с НДС от реализации джинсов женских».

Далее сформируем документ Регистратор оборотов бюджетов, который доступен для ввода в разделе Бюджетирование и планирование – Бюджеты – Расчеты бюджетов по правилам.

Сформируем данный документ для каждого правила расчета связанных оборотов и остатков.

В документе Регистратор оборотов бюджетов укажем сценарий, организацию, подразделение, период планирования, правило расчетов. В документе отсутствуют табличные части. Расчет движений по регистру «Обороты бюджетов» происходит на основании реквизитов шапки документа при его проведении. В одном документе можно выбрать только одно правило.

Из отчета Движения документа можно просмотреть сформированные движения по регистру «Обороты бюджетов».

Расчет движений по регистру «Обороты бюджетов» происходит на основании реквизитов шапки документа при его проведении.

В журнале документов Расчеты бюджетов по правилам отображаются все реквизиты документа, по значениям которых формируются движения по регистру «Обороты бюджетов».

Далее создадим вид бюджета «8 К: Бюджет валовой прибыли, без открытия форм». Флаг Ввод плановых данных устанавливать не будем.

Сформируем отчет за 2026 год по сценарию «Основной помесячный план».

## Заполнение оборотов по связанным статьям бюджетов при проведении документа Ввод экземпляра бюджета

В настройки вида бюджета с вводом плановых данных добавлен флаг Формировать связанные обороты бюджетов, при установке которого формируются движения по регистру «Обороты бюджетов» по правилам расчета, у которых источником выступают статьи и целевые показатели бюджетов из данного вида бюджета.

Создадим вид бюджета для ввода плана продаж. На закладке Основная поставим флаг Формировать связанные обороты бюджетов и укажем период Год.

Источником оборотов выступают только те статьи бюджетов или целевые показатели бюджетов, которые заполняются в данном виде бюджета.

Для статей бюджетов по расчету себестоимости и маржинальной прибыли создадим правила.

Если наименование правила получается очень большим и сложно читаемым, его можно изменить вручную.

Далее создадим экземпляр бюджета и введем вручную план продаж.

Документы Регистратор оборотов бюджетов формируются и проводятся автоматически в фоновом режиме после проведения связанных документов Экземпляр бюджета. Документ-основание указывается на форме документа. При этом сам документ недоступен для редактирования.

В журнале Расчеты бюджетов по правилам сформировались три документа Регистратор оборотов бюджетов для трех правил расчетов. В столбце Документ-основание указывается документ Ввод экземпляра бюджета, на основании которого он был создан.

Также в документе Ввод экземпляра бюджетов по кнопке Отчеты – Связанные документы можно увидеть сформированные документы Регистратор оборотов бюджетов на основании данного документа Ввод экземпляра бюджета.

Теперь формируем вид бюджета для просмотра рассчитанных данных.

Формируем отчет по плановой себестоимости и маржинальной прибыли.

## Заполнение оборотов по статьям бюджетов через бюджетный процесс

При настройке бюджетного процесса для заполнения бюджета закупок по бюджету продаж вводится этап с типом действия Формирование оборотов бюджетов по правилам расчета.

Этап с типом действия Формирование оборотов по статьям бюджетов можно выполнять в автоматическом режиме или вручную пользователем.

В настройках этапа указываются правила расчета, по которым формируются обороты бюджетов и измерения бюджетирования: Организация, Подразделение, Сценарий.

В настройках действия для выбора доступны правила расчета по следующим условиям:

■ в правиле в качестве приемника указана статья или целевой показатель бюджетов;

■ данное правило не используется в формировании оборотов бюджетов документами подсистемы планирования.

Дополнительно указывается периодичность – она задает периодичность формирования оборотов бюджетов в рамках периода бюджетного процесса и соответствует периодичности вида бюджета для этапов с действием Ввод бюджетов.

В настройках контрольных отчетов можно настроить формирование трех видов отчетов:

■ бюджетный отчет (по виду бюджета);

■ оборотная ведомость (по статье бюджетов);

■ оборотно-сальдовая ведомость (по показателю бюджетов).

При формировании бюджетной задачи вручную на основании этапа или в рамках бюджетного процесса автоматически формируется три документа Регистратор оборотов бюджетов по одному на каждый месяц (в соответствии с периодичностью в настройках действия этапа).

Для утверждения ранее сформированных оборотов бюджетов вводится этап с действием Утверждение сформированных оборотов бюджетов.

При настройке утверждения бюджетов для выбора доступны только этапы с действием Формирование оборотов бюджетов по правилам расчета.

При формировании бюджетной задачи по этапу с действием Утверждение сформированных оборотов бюджетов автоматически подтягиваются ранее сформированные документы Регистратор оборотов бюджетов.
