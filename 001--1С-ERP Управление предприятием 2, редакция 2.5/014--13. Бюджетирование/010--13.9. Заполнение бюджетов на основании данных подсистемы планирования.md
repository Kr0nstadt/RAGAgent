# Заполнение бюджетов на основании данных подсистемы планирования

## Заполнение правил расчета связанных остатков и оборотов бюджетов для получения данных из подсистемы планирования

Рекомендуем изучить [Примеры заполнения бюджетов на основании данных подсистемы планирования](/db/erp25doc/bookmark/examplesoffillingbudgetsbasedonplanningsubsystemdata/ExamplesofFillingBudgetsBasedonPlanningSubsystemData).

В целях повышения интеграционных возможностей предусмотрено оперативное использование в бюджетировании данных подсистемы планирования.

Для этого предназначен функционал по расчету оборотов по статьям бюджетов и остатков по целевым показателям бюджетов на основании данных операционных планов.

Для настройки данного функционала необходимо в справочнике Правила расчета связанных остатков и оборотов бюджетов указать в качестве источника данные операционного планирования.

В поле Тип источника есть следующие варианты для выбора:

■ Обороты бюджетов для планирования на основе данных подсистемы Бюджетирование;

■ операционный план для получения данных с помощью оборотного регистра подсистемы планирования. Доступны для выбора следующие операционные планы: Планы продаж, Планы оплат клиентов, Планы закупок, Планы оплат поставщикам, Планы продаж по категориям, Планы производства, Планы внутренних потреблений, Планы сборки (разборки) и Планы остатков.

В поле Способ применения для выбора доступны два значения:

■ Отражать расчет в документах планирования – правило будет использоваться для расчета движений по регистру накопления «Обороты бюджетов» документов планирования;

■ Заполнять экземпляры бюджетов – правило будет использоваться в видах бюджетов для заполнения документа «Экземпляр бюджета.

В поле Источник суммы нужно выбрать ресурс (например, Сумма, Количество, Сумма НДС, Сумма предоплаты), по которому далее будут формироваться плановые данные.

Также при необходимости можно указать дополнительный отбор, коэффициент перерасчета, смещение периода и профиль распределения.

Список доступных для отбора полей определяется выбранным типом источника данных для правила расчета и соответствует измерениям соответствующего оборотного регистра.

В настройках заполнения видов аналитик приемника можно указать в качестве источника данных измерения или реквизиты (и дополнительные реквизиты) измерений соответствующего регистра подсистемы планирования.

В таблице «Типы источников правил расчета» приведено соответствие типа источника оборотным регистрам и возможные варианты для выбора источника суммы.

Внимание

Для выбора в качестве источника суммы доступны показатели Сумма предоплаты и Сумма постоплаты в тех случаях, когда авансы от покупателей выделяются отдельной статьей бюджетов.

Для значения источника суммы Количество дополнительно в качестве коэффициента перерасчета указывается денежный НФП.

Если указан источник суммы <Сумма не рассчитывается>, то рассчитываются только количественные обороты.

Если данные по одной статье формируются разными правилами по одному и тому же типу источника, но по разным источникам суммы, то статья бюджетов должна быть без учета количества, иначе количество также рассчитается с учетом нескольких правил и признака обратного знака.

Для расчета сумм НДС в настройках вида плана должна быть установлена детализация по организации.

## Настройка бюджетного процесса для заполнения бюджетов на основании подсистемы планирования

При настройке бюджетного процесса для заполнения бюджета продаж по плану продаж указывается только один этап с типом Ввод плана.

При настройке ввода плана указываются тип плана, сценарий и вид плана (статьи бюджетов больше не указываются). По типу плана определяются правила расчета для заполнения оборотов по статьям бюджетов.

При настройке бюджетного процесса для заполнения бюджета закупок по плану закупок вводятся 2 последовательных этапа с типами: Ввод плана и Ввод бюджетов.

При настройке ввода плана аналогично указываются тип плана, сценарий и вид плана

При настройке ввода бюджетов указываются вид бюджета и измерения бюджетирования, такие как организация, подразделение, сценарий.
