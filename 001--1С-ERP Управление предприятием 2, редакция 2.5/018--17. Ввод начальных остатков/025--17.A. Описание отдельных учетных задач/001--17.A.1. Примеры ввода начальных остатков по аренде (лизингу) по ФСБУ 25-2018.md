# Примеры ввода начальных остатков по аренде (лизингу) по ФСБУ 25/2018

## Пример ввода начальных остатков по договору аренды по ФСБУ 25/2018

Шаг 1. Создаем Договор аренды (лизинга).

Шаг 2. Формируем документ Ввод начальных остатков арендованных ОС (на балансе).

Шаг 3. Формируем документ Ввод остатков взаиморасчетов по аренде.

График оплат и начислений необходимо заполнить за весь период договора аренды (лизинга).

Шаг 4. Формируем документы: Списание безналичных ДС, Поступление услуг по аренде, Прекращение договора аренды.

## Пример ввода начального остатка долгосрочной задолженности по договору аренды по ФСБУ 25/2018

Создаем Договор аренды (лизинга) и далее шаги 1,2,3 аналогичны шагам в предыдущем примере.

Шаг 4. В учетной политике организации устанавливаем флаг Деление на краткосрочные/долгосрочные активы и обязательства и Длительность операционного цикла организации.  Для формирования примера Длительность операционного цикла организации устанавливаем 4 месяца. 

Шаг 5. Для учета долгосрочной задолженности по договору аренды (лизинга) создаем счет 76.07.Д. Устанавливаем флаг Предназначен для учета долгосрочных активов/обязательств.

Шаг 6. В группу настроек финансового учета расчетов с партнерами «Аренда (лизинг) по ФСБУ 25/2018» через кнопку Еще – Показать долгосрочные добавляем в поле Долгосрочные счет 76.07.Д.

Шаг 7. Создаем операцию (регламентированный учет) и формируем проводки 76.07.1 – 76.07.Д.

Шаг 8. Формируем документы: Списание безналичных ДС, Поступление услуг по аренде, Прекращение договора аренды.
