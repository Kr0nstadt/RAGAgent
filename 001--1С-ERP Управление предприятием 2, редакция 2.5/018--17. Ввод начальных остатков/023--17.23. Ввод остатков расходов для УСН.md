# Ввод остатков расходов для УСН

Для организаций, ведущих учет по УСН и в качестве объекта налогообложения применяющих вариант расчетов Доходы минус расходы, ввод остатков расходов, не признанных на дату начала ведения учета в информационной базе, выполняется с помощью документов раздела Расходы по УСН (НСИ и администрирование – Начальное заполнение – Документы ввода начальных остатков).

В раздел Расходы по УСН входят следующие документы:

■ Ввод остатков прочих расходов УСН - для ввода остатков по расходам на приобретение услуг или РБП;

■ Ввод остатков расходов УСН по материалам - для ввода остатков по расходам на приобретение материалов;

■ Ввод остатков расходов УСН по товарам - для ввода остатков по расходам на приобретение товаров.

При вводе документов ввода остатков расходов для целей учета при УСН в шапке документа указывается Организация, для которой вводятся остатки.

В табличной части документа указываются:

■ Поставщик – партнер, с которым ведутся расчеты. При расчетах между организациями выбирается значение Наше предприятие;

■ Контрагент – юридическое или физическое лицо поставщика, с которым ведутся расчеты. При расчетах между организациями выбирается организация из списка Организации;

■ Вид расходов – при вводе остатков товаров и материалов указывается, является ли расход в строке непосредственно расходом на приобретение товара (материала) или это дополнительный расход или таможенный платеж, включенный в себестоимость товара (материала). При вводе остатков прочих расходов в поле Вид расходов выбирается значение Услуги или РБП;

■ Документ возникновения расходов – Первичный документ с типом документа Приобретение у поставщика, соответствующий документу, по которому эти расходы получены от поставщика;

■ Документ поступления – Первичный документ с типом документа Приобретение у поставщика. Присутствует в документе и заполняется при вводе остатков расходов УСН по товарам и материалам. Документ поступления – это документ партии, к которой относится расход. Для расходов с видом Товары или Материалы значения в графах Документ возникновения расходов и Документ поступления совпадают. Для дополнительных расходов или таможенных платежей, включенных в себестоимость товара (материала), Документ возникновения расходов – это документ, которым отражено возникновение расхода, а Документ поступления – это документ партии, на себестоимость которой расход распределен;

■ Статья расходов – заполняется в документе Ввод остатков прочих расходов УСН. Выбирается статья расходов, по которой непризнанные расходы числятся в учете;

Суммы расходов при вводе остатков для целей УСН можно вводить в двух вариантах: или указывать только остаток суммы расходов к признанию на дату ввода остатков, или заполнять полную информацию о расходе, сформировавшуюся до даты ввода остатков. В зависимости от выбранного варианта ввода остатков сведения о расходах будут отражаться в отчете Анализ расходов по УСН.

■ Расходы к признанию – сумма расходов по документу возникновения расходов или сумма расходов, не признанных на дату начала работы в информационной базе;

■ в т. ч. НДС – сумма НДС в составе расходов, указанных как Расходы к признанию;

■ Из них оплачено – если в поле Расходы к признанию указана сумма расходов по документу возникновения расходов, тогда заполняется сумма, на которую эти расходы оплачены на дату ввода остатков;

■ Из них реализовано – заполняется в документе Ввод остатков расходов УСН по товарам, если в поле Расходы к признанию указана сумма расходов по документу возникновения расходов. Поскольку дополнительным условием признания расходов на товары является факт их продажи конечному потребителю, то указывается, какая стоимость товаров отгружена покупателю;

■ Из них признано – если в поле Расходы к признанию указана сумма расходов по документу возникновения расходов, тогда заполняется сумма, на которую эти расходы уже признаны для целей расчета налога УСН;

■ Из них не признано – указывается сумма расходов, которую принято решение не признавать для целей расчета налога УСН. Эта сумма расходов никогда признана не будет.

По указанным при вводе остатков документам поступления при дальнейшей работе в информационной базе выполняется отслеживание соблюдения условий признания расходов и включения их в книгу учета доходов и расходов для УСН.

Примечание

Ввод остатка расходов по виду **РБП** означает наличие остатка неоплаченных расходов, которые должны быть признаны после погашения задолженности перед поставщиком. Как таковых расходов будущих периодов в налоговом учете при УСН не возникает. Такие расходы не описаны в главе 26.2 НК РФ. Соответственно, все расходы при УСН признаются кассовым методом в полной сумме непосредственно после их оплаты (п. 2 ст. 346.17 НК РФ), если иное не предусмотрено главой 26.2 (например, расходы по товарам). Распределения признания таких расходов для целей УСН по периодам не предполагается.
