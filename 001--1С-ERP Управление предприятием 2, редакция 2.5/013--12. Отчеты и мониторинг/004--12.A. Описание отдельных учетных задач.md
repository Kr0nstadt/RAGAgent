[Монитор целевых показателей – инструмент визуального представления управленческой информации](/db/erp25doc/content/2011/hdoc)  

## Пример формирования дашборда монитора целевых показателей Анализ исполнения бюджета

Пример настроен по данным плановых и фактических данных собранных с помощью модели бюджетирования «Кейс по бюджетированию» за период апрель – июль 2022 года по организации ООО «Андромеда Сервис».

Сформируем в соответствии с деревом целей компании структуру целей в рабочем месте Варианты анализа целевых показателей.

Для каждой цели укажем Целевой показатель, Шаблон расчета целевого показателя, Целевой тренд.

В данном примере в поле Шаблон расчета целевого показателя выбираем значение Обороты по статьям бюджетов. Переходим по кнопке Редактировать в окно Настройка шаблона расчета целевого показателя и в поле Схема компоновки данных находим значение Обороты по статьям бюджетов.

Для каждой цели и соответствующего ей целевого показателя настроим варианты анализа.

На закладке Расчет значений показателя настроим поля:

■ Тип анализа – Динамика изменения;

■ Период укажем с апреля по июль 2022 года;

■ Периодичность расчета - Месяц;

■ Значение – Сумма упр отклонение.

Для целевого показателя  «Выполнение плана по выручке в рублях» настроим отборы:

■ Сценарий – «Основной помесячный план»;

■ Статья бюджетов – «Доход от реализации»;

■ Организация – ООО «Андромеда Сервис».

Далее перейдем по гиперссылке изменить доступность и в открывшемся окне Настройка доступности настроим права доступа.

Далее настроим данные на закладке Внешний вид и прогнозирование.

Настройка последующих вариантов анализа целевых показателей будет в данном примере отличаться отборами.

Для варианта анализа «Выполнение плана в количестве по продаже конфет «Барбарис» добавим отбор по номенклатуре.

Для варианта анализа «Выполнение плана по поступлению ДС» цели «Минимизация просрочки платежей» установим следующие отборы:

■ Сценарий – «Основной помесячный план»;

■ Статья бюджетов – «Поступление денежных средств»;

■ Организация – ООО «Андромеда Сервис».

Для варианта анализа «Выполнение плана по валовой прибыли» цели «Увеличение рентабельности продаж» установим следующие отборы:

■ Сценарий – «Основной помесячный план»;

■ Статья бюджетов – «Валовая прибыль»;

■ Организация – ООО «Андромеда Сервис».

Для варианта анализа «Выполнение плана по оплате закупок» цели «Отсутствие кассовых разрывов» установим следующие отборы:

■ Сценарий – «Основной помесячный план»;

■ Статья бюджетов – «Оплата закупок»;

■ Организация – ООО «Андромеда Сервис».

Для варианта анализа «Выполнение плана по операционным расходам» цели «Оптимизация расходов» установим следующие отборы:

■ Сценарий – «Основной помесячный план»;

■ Статья бюджетов – «Операционные расходы начисление»;

■ Организация – ООО «Андромеда Сервис».

Для варианта анализа «Выполнение плана по чистой прибыли» цели «Выполнение плана по чистой прибыли» установим следующие отборы:
