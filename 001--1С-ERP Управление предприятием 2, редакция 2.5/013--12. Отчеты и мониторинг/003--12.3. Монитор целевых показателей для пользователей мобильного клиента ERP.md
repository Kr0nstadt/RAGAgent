# Монитор целевых показателей для пользователей мобильного клиента ERP

Для пользователей мобильного клиента ERP существует возможность в удобной форме использовать Монитор целевых показателей (раздел Финансовый результат и контроллинг – Целевые показатели), а также настраивать и сохранять варианты отчетов. Для использования Монитора целевых показателей требуется установить мобильный клиент. Установки отдельного специализированного приложения «1С:Монитор ERP» для iOS и Android не требуется, и работа в этом приложении версии 2.5.10 не поддерживается. Подробнее о мобильном клиенте в ERP можно ознакомиться в статье: [Мобильный клиент](/db/erp25doc/bookmark/mobileclient/MobileClient).

## Настройка отчетов для просмотра в мобильном клиенте

В карточке списка Варианты отчета (в каждом разделе – отчеты раздела – Все отчеты…) находится реквизит Назначение со следующими вариантами выбора:

■ Десктоп;

■ Мобильный клиент;

■ Везде.

Отчеты с назначением: Мобильный клиент и Везде – доступны для просмотра в мобильном клиенте ERP.

Реквизит **Назначение** можно изменить и при сохранении варианта отчета.

**Информация для разработчиков**

Реквизит **Назначение** для внешних отчетов задается в функции СведенияОВнешнейОбработке() с помощью параметра НазначениеВариантаОтчета. По умолчанию значение реквизита **Назначение** указывается **Десктоп**.

Реквизит **Назначение** выводится в списке вариантов отчетов (раздел-отчеты раздела) по кнопке **Все отчеты…**.

В режиме **Настройка** (в каждом разделе – отчеты раздела) возможен выбор вариантов настройки отчетов в зависимости от назначения:

**Все варианты отчетов**;

**Десктоп**.

В варианте **Десктоп** доступны отчеты с назначением **Десктоп** и **Везде**.

В мобильном клиенте в режиме Настройка выбор назначения вариантов отчетов доступен с помощью переключателя Отображать для десктопа.

Если переключатель Отображать для десктопа включен, то доступны все варианты отчетов, в том числе с назначением Десктоп. Если переключатель отключен, то доступны варианты отчетов для мобильного клиента с назначением Мобильный клиент и Везде.

В отчет Монитор целевых показателей (далее - МЦП) в окне Дашборды отображаются элементы справочника Дашборды МЦП, доступные текущему пользователю.

Справочник Дашборды Монитора целевых показателей (далее – **Дашборды МЦП**) необходим для хранения настроек вывода целевых показателей МЦП.

В шапке элемента справочника Дашборды МЦП указывается название. На закладке Настройки нужно выбрать:

■ Группировку показателей:

○ По категориям;

○ По состоянию (программа анализирует значения показателей с точки зрения достижения установленных целей и группирует их по состоянию);

■ Количество колонок;

■ Размер таблиц и диаграмм;

■ Период автообновления;

■ Картинку для отображения в списке.

Количество колонок может быть от 1 до 4 или более. Доступен вариант Авто – автоматический расчет количества в зависимости от разрешения экрана.

На закладке Доступность карточки элемента справочника Дашборды МЦП находится переключатель, с помощью которого можно определять права доступа к дашборду:

■ Только автору;

■ Указанным пользователям и подобрать необходимых пользователей.

На закладке Варианты анализа карточки элемента справочника Дашборды МЦП необходимо выбрать:

■ Цель и Вариант анализа;

■ Вариант отображения:

○ Диаграмма;

○ Кратко;

■ Детали;

■ Итого.

## Просмотр отчетов в мобильном клиенте

Для того чтобы в мобильном клиенте автоматически открывался Монитор целевых показателей, необходимо в карточке элемента справочника Пользователи (раздел НСИ и администрирование – Администрирование – Настройки пользователей и прав - Пользователи) в контекстном меню выбрать пункт Настройки открытия форм при начале работы программы. Далее в карточке элемента справочника **Настройки открытия форм при начале работы программы** с выбранным значением Монитор целевых показателей в поле **Открываемая форма** установить флаг Открывать по умолчанию.

При открытии отчета МЦП в мобильном клиенте пользователю сначала необходимо выбрать дашборд из списка.

Контекстное меню появится, если, удерживая на экране палец, провести им вправо (при свайпе вправо):

■ Изменить;

■ Вверх;

■ Вниз.

Внизу экрана находится команда Добавить для добавления дашборда.

Количество колонок на экране зависит от настройки дашборда. Если ширина недостаточна, то нужно либо уменьшить значение Количество колонок, либо установить значение Авто.

Основные команды находятся в нижней командной панели:

■ Горизонтально (Вертикально) – вариант расположения ресурсов в отчете;

■ Варианты отчета – список вариантов данного отчета;

■ Настройки – основные настройки отчета;

■ Сформировать – формирование отчета.

В мобильном клиенте используется только простой вариант настройки - расширенный вариант недоступен.

В системе настроены предопределенные варианты отчетов для мобильного клиента, такие как:

■ Валовая прибыль предприятия (моб.);

■ Валовая прибыль по полной оплате отгрузок (моб.);

■ Доходы и расходы предприятия (моб.);

■ Ведомость по денежным средствам (моб.);

■ Движение денежных средств (моб.);

■ Ведомость по товарам на складах (моб.).

## Просмотр МЦП и отчетов в автономном режиме

Существует функционал по просмотру стандартных отчетов и отчета **Монитор целевых показателей** в мобильном клиенте в автономном режиме.

Данный функционал работает за счет сохранения ранее сформированных отчетов в табличный документ в формате mxl. Для этих целей добавлены соответствующие команды в форму отчета. Отчеты сохраняются для каждого пользователя в разрезе варианта дашборда МЦП.

На формах отчетов и МЦП в десктопе и мобильном клиенте есть команды для работы с офлайн-отчетами:

■ Сохранить офлайн - сохранить документ в формате mxl текущего отчета для пользователя;

■ Сохранить все офлайн - обновить сохраненные ранее документы в формате mxl с актуализацией данных;

■ Список офлайн отчетов - просмотр списка, сохраненных ранее документов в формате mxl, пользователя.

На панели отчетов в десктопе и мобильном клиенте есть 2 команды:

■ Сохранить все офлайн;

■ Список офлайн отчетов.

Просмотр отчетов в автономном режиме доступен в разделе Главное – Все отчеты.

На форме отчета находятся команды: Варианты, Начало, Назад, Вперед, Конец, Удалить.

В автономном режиме доступно только удаление документов в формате mxl.

В основном режиме можно обновить документы в формате mxl с помощью команды Сохранить все офлайн.

В автономном режиме просмотр отчета МЦП доступен в разделе Финансовый результат и контроллинг – Монитор целевых показателей.

Перед просмотром необходимо выбрать дашборд. Дашборды без сохраненного документа в формате mxl отображаются в затененном виде.

При обновлении информационной базы:

Пользовательские настройки просмотра отчета МЦП сохраняются в карточку элемента справочника Дашборды МЦП;

В карточках элементов списка Варианты отчетов устанавливается реквизит Назначение – Десктоп.
