# Мониторинг целевых показателей

Дополнительно к документации рекомендуем книги из серии «Академия ERP» (бумажная и электронная версия):

■ Управленческий учет - [https://buh.ru/books/detail.php?ID=79724](https://buh.ru/books/detail.php?ID=79724);

■ Финансовое планирование и бюджетирование - [https://buh.ru/books/detail.php?ID=63092](https://buh.ru/books/detail.php?ID=63092).

Для контроля и анализа показателей деятельности предприятия предусмотрен отчет Финансовый результат и контроллинг – Целевые показатели – Монитор целевых показателей.

Монитор целевых показателей соответствует терминам dashboard (англ.), «панель показателей» и т. п.

Использование монитора целевых показателей позволяет:

■ своевременно выявлять проблемные участки на любом этапе управления предприятием;

■ анализировать эффективность ключевых процессов предприятия с помощью показателей;

■ анализировать взаимосвязь и влияние одних показателей на другие;

■ топ-менеджерам принимать оптимальные управленческие решения по ключевым процессам на основании данных по целевым показателям предприятия.

Данная функциональность обеспечивает формирование структуры целей и целевых показателей предприятия и их мониторинг.

При этом поддерживаются следующие возможности:

■ использование различных вариантов анализа целевых показателей (способов фильтрации и представления информации);

■ индикация позитивных и негативных отклонений в достижении установленных значений целевых показателей;

■ детальный анализ любого показателя с помощью отчетов;

■ настройка состава сводного отчета (целевых показателей) и его рассылка по электронной почте.

Использование монитора целевых показателей определяется функциональной опцией НСИ и администрирование – Настройка НСИ и разделов – Финансовый результат и контроллинг – Целевые показатели – Мониторинг целевых показателей.

Для просмотра монитора целевых показателей используется профиль группы доступа Участник управления по целям.

Для добавления, изменения и просмотра целей, категорий целей, вариантов анализа целевых показателей предусмотрен профиль группы доступа Администратор.

## Категории целей

Категории целей соответствуют понятию «перспектива» «сбалансированной системы показателей» (Balanced ScoreCard).

Для настройки групп («перспектив») предусмотрен список Финансовый результат и контроллинг – Целевые показатели – Категории целей.

При первоначальном заполнении информационной базы создается несколько категорий целей:

■ Финансы,

■ Клиенты,

■ Внутренние бизнес-процессы,

■ Сотрудники и развитие и др.

Базовый состав категорий целей может быть расширен под потребности предприятия.

## Структура целей

Целевые показатели описываются в виде иерархической структуры – Структура целей. На верхнем уровне указываются цели, которых необходимо достичь в соответствии с принятой на предприятии стратегией управления и развития. Высокоуровневые цели определяются собственниками и руководством компании. В составе каждой из них можно выделить необходимое число подцелей, успешное выполнение которых обеспечит достижение вышестоящей цели.

Элемент списка Структура целей не только символизирует цель, но и определяет алгоритм расчета целевого показателя для оценки достижения цели (поле Шаблон расчета целевого показателя).

Характер работ по достижению целевого показателя определяется выбранной для него стратегией (поле Целевой тренд на форме элемента списка Цель):

■ Максимизация значения,

■ Минимизация значения,

■ Удержание в пределах допустимого диапазона.

В списке Структура целей устанавливается логическая или математическая зависимость одних показателей от других. Не связанные между собой показатели следует располагать на разных «ветках» верхнего уровня иерархии.

В общем представлении каждый элемент списка соответствует сущности Key Performance Indicator (KPI, «ключевой показатель деятельности»).

При первоначальном заполнении информационной базы создаются 25 базовых целевых показателей, состав которых может быть самостоятельно расширен пользователями. Создание новых показателей оправданно для факторов, которые могут привести к существенным достижениям.

### Шаблон расчета целевого показателя

Для упрощения создания целевых показателей поставляется частично настроенный шаблон расчета (макет системы компоновки данных), требующий заполнения набора данных для анализа. Показатели могут создаваться копированием существующих элементов с последующей модификацией шаблона расчета.

Для того чтобы выбрать шаблон необходимо перейти по кнопке Редактировать.

В поле Схема компоновки данных можно выбрать нужный шаблон.

#### Шаблон расчета целевого показателя по данным бюджетирования

Для настройки целевых показателей по данным бюджетирования в карточке элемента справочника Структура целей необходимо выбрать шаблон расчета целевого показателя Обороты по статьям бюджетов.

Ограничение

Для анализа данных «план – факт» в суммовом и количественном выражении  по статьям бюджетов в правилах получения фактических данных по статьям бюджетов должен быть включен флаг Хранить результат выполнения правила. Без установки этого флага фактические данные выводиться не будут.

При использовании шаблона расчета целевых показателей Обороты по статьям бюджетов возможны следующие действия:

■ выводить плановые значения статей бюджетов;

■ проводить анализ «план-факт» статей бюджетов;

■ сравнивать плановые и фактические значения между разными периодами.

При формировании варианта анализа целевого показателя можно настроить отбор, заполнив в окне Настройка отборов параметры: Настройка, Вид сравнения, Значение.

## Варианты анализа целевых показателей

Для каждого целевого показателя может быть указано неограниченное количество вариантов анализа, которые настраиваются в списке Финансовый результат и контроллинг – Целевые показатели – Варианты анализа целевых показателей.

Использование вариантов анализа позволяет быстро настраивать план-фактный анализ для поддерживающих плановые значения показателей, проводить анализ структуры показателей в динамике, настраивать стандартный вариант отображения показателя в мониторе.

При создании новой базы автоматически загружается поставляемая модель показателей. Для загрузки новой поставляемой модели целевых показателей в ранее созданную информационную базу предусмотрена команда НСИ и администрирование – Настройка НСИ и разделов – Финансовый результат и контроллинг – Целевые показатели – Восстановить поставляемую модель показателей. В результате восстановления стандартных настроек создаются или перезаписываются настройки поставляемых категорий целей, целевых показателей, вариантов анализа и целевых значений.

Новая поставляемая модель загружается в отдельную группу показателей Поставляемая модель показателей. Существующие показатели, не входящие в поставляемую модель, остаются без изменений.

Список вариантов анализа целевых показателей разделен на две части:

■ в левой части списка показывается структура целей;

■ в правой части для каждой цели (целевого показателя) показывается список вариантов, предназначенных для анализа. Создание варианта анализа целевого показателя выполняется по команде Создать вариант анализа.

Настройки варианта анализа целевого показателя выполняются в форме Вариант анализа целевого показателя на соответствующих закладках.

На закладке Расчет значений показателя указываются:

■ Тип анализа в зависимости от сути целевого показателя:

○ Динамика изменения – применяется в том случае, если необходимо проанализировать изменения показателей за определенный период. Для данного типа анализа указываются: период, за который необходимо контролировать динамику изменения, периодичность расчета, значение целевого показателя;

○ Покомпонентное сравнение (структура) – применяется, если необходимо произвести сравнительный анализ данных по объектам анализа (организация, партнер, менеджер, вид номенклатуры и т. д.) или различным значениям показателя. Для данного типа указываются: период анализа, значение целевого показателя, объект анализа или дополнительное значение показателя;

○ Покомпонентное сравнение (динамика) – применяется в том случае, если необходимо произвести сравнительный анализ изменения данных с течением времени по объектам анализа (организация, партнер, менеджер и т. д.) или различным значениям показателя. Для данного типа указываются: период анализа, периодичность расчета, значение целевого показателя, объект анализа;

○ Сравнение с прошлым периодом – применяется, если необходимо сравнить состояние целевого показателя в текущем периоде с данными предыдущего периода (предыдущий месяц, аналогичный период прошлого года и т. д.). В варианте анализа устанавливаются текущий период анализа и период, с которым будут сравниваться данные. При анализе данных текущего и прошлого периода используется одна и та же периодичность расчета;

○ Измерение текущего состояния – показывает индикатор текущего состояния показателя, то есть насколько текущее состояние показателя близко к намеченной цели. В индикаторе наглядно показывается положение стрелки на шкале: насколько велико отклонение от намеченной цели (позитивное или негативное отклонение).

■ Период и периодичность. Информация о том, за какой интервал времени следует анализировать данные для расчета целевого показателя, определяется в поле Период. Если в соответствии с типом анализа необходимо произвести сравнение с предыдущим периодом, то дополнительно задается информация о периоде, за который необходимо анализировать данные для расчета целевого показателя в предыдущем периоде (поле Период сравнения). Период сравнения задается произвольным образом. При этом для получения данных необходимо следить, чтобы основной период и период сравнения не пересекались и чтобы период сравнения был расположен на оси времени раньше, чем основной период. Для определения тенденции изменения целевого показателя (рост значения показателя, снижение значения показателя, значение показателя не изменилось) задается периодичность расчета (поле Периодичность расчета). Сравнение происходит с предыдущим значением, рассчитанным в соответствии с заданной периодичностью. Для каждого целевого показателя необходимо настроить периодичность расчета в соответствии с сутью данного показателя.

Пример

Анализ остатков наличных денежных средств в кассах целесообразно проводить ежедневно (Периодичность расчета – «День»), а сравнительный анализ продаж в удаленных розничных магазинах следует производить с периодичностью «Неделя», так как магазины отчитываются за проданные товары еженедельно. При анализе остатков в кассах будет анализироваться рост денежных средств по сравнению с прошлым днем, а при анализе данных по магазинам будет происходить сравнение данных о продажах товаров с данными о продажах прошлой недели. Периодичность расчета определяет шаг расчета данных при использовании типов анализов Динамика изменений и Покомпонентное сравнение (динамика).

■ Источник значения:

○ Значение – значение показателя, определяющее вариант, который применяется при расчете показателя. Для одного и того же показателя могут применяться различные варианты расчета. При создании нового варианта анализа показателя значение показателя потребуется уточнить только в том случае, если для показателя предусмотрено несколько вариантов расчета значений. Если вариант расчета значений показателя один, то поле Значение будет заполнено автоматически;

○ Дополнительное значение – дополнительное значение целевого показателя, используемое в тех случаях, когда для одного и того же показателя могут применяться разные варианты расчета и выбраны типы анализа Покомпонентное сравнение (динамика) и Покомпонентное сравнение (структура). Дополнительное значение доступно при режиме сравнения Значение с доп. значением;

○ Объект анализа – используется для сравнения данных в разрезе различных объектов, т. е. определения доли каждого объекта в целевом показателе. Выбор объекта анализа доступен при установленных типах анализа Покомпонентное сравнение (структура), Покомпонентное сравнение (динамика) и режиме сравнения Значения объектов анализа.

■ Метод расчета. Для целевого показателя можно применять один из методов расчета (поле Метод расчета значений):

○ Сумма – значение показателя определяется в каждой точке расчета в соответствии с установленной периодичностью расчета;

○ Сумма нарастающим итогом – значение показателя определяется с учетом ранее накопленных значений. Данный вариант расчета доступен для ограниченного числа показателей, где имеет смысл нарастающий итог. Например, для суммового показателя Остатки денежных средств нарастающий итог не имеет смысла, а для суммового показателя Количество проданных единиц продукции он может иметь смысл.

Пример

1 января было продано товаров на сумму 100 тысяч рублей, а 2 января – на сумму 200 тысяч рублей. Если используется метод расчета Сумма нарастающим итогом, то 2 января сумма выручки будет рассчитана как 300 тысяч рублей.

■ Точность расчета:

○ Кратность значений – при больших суммах (количествах) рекомендуется выражать значение показателей в тысячах или миллионах;

○ Дробная часть – позволяет определить количество знаков после запятой (0, 1, 2, 3).

Пример

В монитор целевых показателей необходимо вывести сумму 120 миллионов 140 тысяч руб. В этом случае в поле Кратность значений следует установить значение В миллионах, в поле Дробная часть – 2 знака после запятой. В мониторе целевых показателей сумма будет показана как 120,14 миллиона.

На этапе создания шаблона расчета значений показателя можно ограничить объем данных, участвующих в расчете, а также обеспечить работу с целевыми показателями пользователей, имеющих ограниченный доступ к данным, на основании которых выполняется расчет значения. Для этого предлагается перечень допустимых полей отборов по гиперссылке настроить реквизита Отборы.

Например, отбор по менеджеру позволяет рассчитать персональный показатель для этого менеджера и вывести его в персональный монитор. Отдельный вариант анализа на основании данных по всем менеджерам используется для вывода на монитор руководителя предприятия.

Можно настроить доступность варианта анализа для конкретного пользователя. Только варианты с настроенным доступом будут доступны в мониторе. Настройка делается в форме Настройка доступности, доступ к которой осуществляется по гиперссылке Изменить доступность.

Скорость работы монитора зависит от количества выводимых вариантов анализа. Для существенного ускорения визуализации информации используется алгоритм временного хранения рассчитанных данных. Длительность их хранения определяется для каждого варианта анализа в поле Период актуальности расчета.

На закладке Внешний вид и прогнозирование указываются:

■ Внешний вид:

○ Тип диаграммы – графическое представление данных целевого показателя. Предусмотрены различные типы диаграмм.

○ Настройка оформления – настройка цветового оформления целевого показателя, диаграммы и шкалы значений. Можно изменять визуальное представление показателя, добиваясь оптимального результата (гиперссылка Настроить оформление).

○ Настройка демо-данных – данные значений показателя, которые используются для отображения в демонстрационном режиме «Монитора целевых показателей». Для моделирования можно не только использовать демонстрационные данные, но и вводить произвольные данные в таблицу. При этом будет автоматически изменяться представленная диаграмма. С помощью кнопки Заполнить по данным ИБ можно оценить, как будет выглядеть представление показателя на реальных данных, имеющихся в информационной базе.

■ Прогнозирование – позволяет спрогнозировать вероятные значения целевого показателя на заданное количество периодов расчета. Доступно при установленных типах анализа Динамика изменений и Сравнение с прошлым периодом. Для расчета прогнозных значений необходимо:

○ установить флажок Рассчитывать прогноз;

○ указать количество периодов расчета, за которые будут анализироваться данные для составления прогноза (Глубина);

○ указать количество периодов, кратных периодичности расчета, за которые система рассчитывает вероятные прогнозные значения показателя (Горизонт).

Пример

Необходимо составить прогноз по объему продаж на следующий день, анализируя данные текущего дня. Периодичность расчета установлена – «день». В этом случае в поле Глубина устанавливаем значение «30 дней» (месяц), а в поле Горизонт – «1» (день).

Точность прогноза зависит от того периода, за который анализируются данные. Чем больше глубина прогноза по сравнению с горизонтом, тем более точный прогноз можно получить. Прогнозирование вероятных значений показателя проводится на основании динамики данных прошлых периодов. Прогнозы строятся на основании математических моделей, приближающих фактические данные к одной из математических функций: полиномиальной (степени 1 и 2), экспоненциальной и логарифмической.

Точность расчета прогноза измеряется в процентах – от 0 до 100 %.

Об удовлетворительном качестве моделирования можно говорить, если адекватность модели больше 80–90 %. В противном случае рекомендуется пересмотреть период анализа, периодичность расчета и параметры прогноза для выбранного варианта анализа.

## Настройки отчетов для расшифровки вариантов анализа

Список отчетов для расшифровки варианта анализа целевого показателя определяется на этапе заполнения «Варианта анализа целевого показателя» (гиперссылка настроить отчеты на закладке Расчет значений показателя в форме Вариант анализа целевого показателя). По нажатию данной гиперссылки будет показано диалоговое окно, в котором на выбор доступны варианты типовых отчетов, имеющихся в информационной базе (форма Настройка отчетов для расшифровки).

Отчеты, отмеченные флажком, будут доступны для дополнительного анализа данных по целевым показателям.

При настройке списка отчетов для расшифровки доступны дополнительные возможности:

■ просмотр выбранных отчетов (команда Только выбранные отчеты);

■ включение/выключение доступности отдельных отчетов.

Расшифровка варианта анализа показателя с помощью отчетов выполняется в рамках «Монитора целевых показателей» (команда Отчеты).

Данные в отчете для расшифровки будут представлены за период, соответствующий периоду, который указан в варианте анализа целевого показателя.

Установленные в варианте анализа отборы и показатели передаются в отчет только в том случае, если поля в отчете для расшифровки и в шаблоне расчета варианта анализа совпадают.

## Установка целевых значений вариантов анализа показателей

Целевые значения вариантов анализа используются для указания диапазона значений целевого показателя, в пределах которого подразумевается достижение поставленных целей.

Установка целевых значений (диапазонов) выполняется в рамках варианта анализа целевого показателя (команда Целевые значения (диапазоны) на форме Вариант анализа целевого показателя).

Заполнение значений показателя зависит от того, какой целевой тренд (достижение цели) установлен для показателя (поле Целевой тренд в форме цели).

В соответствии с этим определяются вид целевого значения (значение или диапазон) и способы его заполнения:

■ Если целью является стремление к получению максимального или минимального значения, то указывается определенное целевое значение (поле Целевое значение).

■ Если целью является удержание значения в определенном диапазоне (поля Целевой диапазон максимум и Целевой диапазон минимум), то позитивное отклонение (поле Граничное позитивное отклонение) указывается по отношению к максимальному значению диапазона, а негативное отклонение (поле Граничное негативное отклонение) – по отношению к минимальному значению диапазона.

Отклонения можно указывать как в абсолютном виде, так и в относительном (процентном соотношении) – поле Вид отклонения от целевого значения в форме целевого значения (диапазона).

Например, выручка предприятия в течение недели может колебаться в пределах от 100 до 200 тысяч рублей. Снижение выручки до 40 тысяч рублей является критичным, и необходимо принять соответствующие меры. Для решения этой задачи необходимо заполнить параметры целевого значения (диапазона):

■ Вид отклонения от целевого значения – «Абсолютное»;

■ Целевой диапазон максимум – «200»;

■ Целевой диапазон минимум – «100»;

■ Граничное позитивное отклонение – устанавливается значение больше максимального целевого диапазона, например «500»;

■ Приведенное отклонение – рассчитывается автоматически. Будет установлено значение «700» (200 + 500);

■ Граничное негативное отклонение – устанавливается значение меньше минимального целевого диапазона, например «60»;

■ Приведенное отклонение – рассчитывается автоматически и определяет то критичное значение, которое будет контролироваться. Будет установлено значение «40» (100 – 60).

Проконтролировать достижение поставленной цели можно в «Мониторе целевых показателей».

Для каждого целевого показателя показывается маркер достижения цели – при условии, что заданы целевые значения:

■ Если текущее значение целевого показателя соответствует введенному значению (диапазону), то состояние будет Цель достигнута и цвет маркера будет зеленым (по умолчанию).

■ Если текущее значение целевого показателя находится в пределах отклонений, которые указаны для показателя, то состояние будет Приемлемое значение и цвет маркера будет оранжевым (по умолчанию).

■ Если текущее значение целевого показателя имеет негативное отклонение больше допустимого, то состояние будет Неприемлемое значение и цвет маркера будет красным (по умолчанию).

■ Если допустимые или текущие значения целевого показателя не определены, то состояние будет Состояние не определено.

## Настройка произвольных показателей

В конфигурации поставляется шаблон СКД, на основе которого создаются новые показатели.

Рассмотрим на примере показателя Рост выручки и поставляемой схемы Выручка предопределенный создание оборотных показателей (объем продаж, поставок и т. п.).

Особенности создания оборотных показателей (типичный пример):

■ «ведущим» является набор данных Таблица периодов;

■ в шаблоне необходимо создать новый набор данных Данные для анализа с целью выборки данных из системы (это может быть запрос или объединение запросов);

■ набор данных должен быть связан с набором Таблица периодов по параметрам периодов;

■ для одного показателя достаточно одного ресурса (как правило);

■ ресурс должен быть описан в конструкторе в двух вариантах:

○ для периода – Рассчитывать по Период;

○ для аналитик (покомпонентное сравнение) – Рассчитывать по <Аналитика>;

■ ресурс должен быть добавлен в выбранные поля;

■ структура должна быть со следующей вложенностью:

○ любая из доступных аналитик – Период.

Перед расчетом прикладное решение выполняет следующие проверки:

■ Есть ли набор данных ТаблицаПериодов.

■ Есть ли набор данных ЦелевыеЗначения.

■ Есть ли набор данных ДанныеДляАнализа.

■ Установлены ли связи «ТаблицыПериодов» и наборов ЦелевыеЗначения и ДанныеДляАнализа.

■ Выбраны ли служебные поля: целевые значения и служебные измерения (Период и некоторые другие).

■ Есть ли хотя бы одно неслужебное измерение для анализа (например, Организация).

■ Есть ли хотя бы один неслужебный ресурс (например, Выручка).

## Настройки и рассылка монитора целевых показателей

Графическое представление вариантов анализа целевых показателей реализовано в «Мониторе целевых показателей».

Монитор целевых показателей можно настроить в соответствии со своими предпочтениями – в форме Персональные настройки, вызываемой по команде Еще – Настроить на форме монитора целевых показателей. Персональные настройки позволяют:

■ Задать группировку показателей (на закладке Настройки):

○ по категориям целей предприятия;

○ состоянию. Система анализирует значения показателей с точки зрения достижения установленных целей и группирует их по состоянию. Все показатели будут разбиты на следующие группы: неприемлемое состояние, приемлемое состояние, цель достигнута, состояние не определено, рассчитанные с ошибкой.

■ Указать количество колонок монитора (поле Выводить показатели в…).

■ Определить размер диаграмм (поле Размер диаграмм и таблиц).

■ Установить период автообновления – частоту проверки потребности в обновлении показателей открытого монитора. Обновляются только показатели, у которых данные на момент проверки устарели (поле Период автообновления).

■ Указать уникальный состав используемых вариантов анализа в рамках предоставленного пользователю доступа (на закладке Варианты анализа).

■ Выбрать формат вывода показателя (текст, таблица или диаграмма).

Для моделирования внешнего вида монитора целевых показателей предусмотрен Демонстрационный режим.

Демонстрационные данные могут применяться:

■ в начале внедрения системы, когда данных слишком мало для отображения, но требуется принять решение об использовании подсистемы целевых показателей;

■ при разработке собственных шаблонов расчета и проектировании состава монитора целевых показателей. Внешний вид показателей можно согласовать с заинтересованными пользователями до начала разработки шаблонов расчета;

■ при освоении настроек вариантов анализа – в частности, для изучения типов анализа и возможностей визуализации показателей.

Использование демонстрационного режима позволяет оценить возможности монитора целевых показателей без предварительного ввода информации. Для включения демонстрационного режима предусмотрена команда Еще – Демонстрационный режим на форме монитора целевых показателей.

Отобразить и проанализировать детальную информацию по каждому целевому показателю можно по команде Анализ показателей. Результатом выполнения данной команды является формирование отчета по данным целевого показателя (цель, параметры анализа, ответственный и т. д.).

Использование печатной формы Монитор целевых показателей позволяет:

■ Проанализировать большое количество целевых показателей, представленных на одной странице: на первую страницу печатной формы выводятся целевые показатели с краткими результатами. Для каждого показателя, представленного в печатной форме, выводится страница, на которой можно посмотреть детальное описание состояния показателя и диаграмму.

■ Проанализировать детальную информацию по каждому показателю предприятия – выводится информация об установленных целях, фактических значениях, ответственных.

■ Сохранить печатную форму в виде файла в одном из форматов: PDF, Excel, Word и т. д. (кнопка Сохранить документ ).

■ Отправить отчет по электронной почте (кнопка Отправить сейчас) – письмо будет доставлено на указанный адрес электронной почты. Отправка отчета возможна в форматах PDF, Excel, Word и т. д.

■ Комбинировать информацию о целевых показателях (KPI) с другими управленческими отчетами – возможна рассылка совместно с другими управленческими отчетами по кнопке Включить в существующую рассылку отчетов, обеспечивающей доступ к списку существующих рассылок отчета. Отчет по монитору целевых показателей можно добавить в уже существующую рассылку, при необходимости отредактировать рассылки (изменить расписание, в соответствии с которым осуществляется рассылка, изменить адреса получателей, которым осуществляется рассылка ключевых показателей).

■ Произвести настройки для автоматической рассылки показателей сводного отчета (кнопка Создать рассылку отчетов):

○ добавить отчет по монитору целевых показателей и/или любой другой управленческий отчет (по кнопке Подобрать на закладке Отчеты).

○ настроить состав получаемой информации при помощи соответствующих отборов на закладке Отчеты раздела Настройки отчета;

○ настроить расписание (на закладке Расписание), в соответствии с которым будет осуществляться автоматическая рассылка ключевых показателей по электронной почте, что позволяет вовремя и быстро проинформировать топ-менеджера о данных целевых показателей предприятия. Например, можно задать расписание, согласно которому рассылка отчета будет осуществляться ежедневно в 7:30;

○ задать адреса доставки на закладке Доставка (эл. почта). На этой закладке указывается имя отправителя писем, в качестве которого можно указать пользователя (например, менеджера, от имени которого осуществляется отправка данных по целевым показателям). Также указываются имена получателей писем, которым будет осуществляться рассылка ключевых показателей сводного отчета. В качестве получателей могут выступать пользователи, организации, партнеры, контрагенты, физические лица, зарегистрированные в информационной базе, и для этих пользователей обязательно должны быть заданы электронные почтовые адреса, на которые будет осуществляться рассылка;

○ изменить формат данных отчета на закладке Дополнительно (по умолчанию устанавливается формат HTML).

Для этого необходимо открыть настройку отчета по монитору целевых показателей Варианты анализа в форме Рассылка отчетов и отредактировать варианты анализа целевых показателей (валовая прибыль, продажи, план-факт списания ДС и т. д.).
