# Форма подбора товаров и складов из заказа

Для подбора товаров в табличную часть заказа предусмотрена форма подбора товаров. В форме подбора можно установить различные фильтры для ограничения области поиска товаров: по иерархии номенклатуры, по виду номенклатуры, по товарам другого качества. В соответствии с выбранным вариантом отбора будет показан список групп номенклатуры, список видов номенклатуры или поле для выбора товара исходного качества.

В левой части формы отображается перечень товаров, принадлежащих указанной в правой части группе номенклатуры, виду или товару другого качества. Товары, для которых есть товары другого качества, отмечены в списке коричневой черточкой.

Для номенклатуры, по которой ведётся учёт по сериям, предусмотрены возможности указания серий, распределения количества среди выбранных серий, для серий для которых используется сроки годности - распределение по FEFO.

Нераспределенные по складам и вариантам обеспечения товары будут добавляться в корзину с незаполненным складом и/или вариантом обеспечения.

Когда перераспределено не все количество или были подобраны разные серии, при переносе в табличную часть осуществляется автоматическое разбиение строк с подобранной номенклатурой.

Для каждого товара показываются цены по тому виду цены, который указан  в выбранном в документе соглашении, и остатки товаров на том складе, который указан в документе.

Для просмотра других цен по товару предназначена команда Цены в форме подбора товаров (команда доступна нажатием правой кнопки мышки).

Если не используются соглашения с заданным видом цены и в информационной базе зарегистрирован только один вид цены, используемый при оптовой продаже, то в помощнике подбора товаров отображается цена по этому виду цены.

Подбор товаров производится установкой курсора на товар и нажатием клавиши ENTER, двойным кликом по позиции товара или перетаскиванием в список подобранных позиций. Если для товара используются характеристики, то произойдёт переход к списку характеристик, где необходимо отобрать конкретную характеристику.

Резервирование товаров производится из общего доступного остатка по складу. Если на складе находится товар нескольких организаций, то можно настроить схему «Интеркампани». Если товары другой организации продаваться не должны, то можно разделить склады разных организаций.

Для работы с формой подбора предусмотрено сворачивание/разворачивание списка подобранных позиций (гиперссылки Всего подобрано позиций (показать)/Всего подобрано позиций (скрыть)).

Для переноса подобранных позиций в документ используется команда Перенести в документ.

В случае, когда включена настройка Запрашивать количество и цену или Запрашивать количество (команда Еще – Настройки в форме подбора товаров), при выполнении подбора номенклатуры открывается форма, в которой предусмотрен подбор количества, вида цены, установка скидки или наценки.

Остатки в форме подбора товаров отображаются всегда на текущую дату.

В форме ввода количества по умолчанию отображаются остатки товаров на складе, который указан в документе (по умолчанию установлен флаг «Только склад»).

В форме ввода количества для отображения остатков по всем складам необходимо снять флаг «Только склад».

Для отображения доступного обособленного количества товаров в форме ввода количества необходимо установить флаг «Обособленно».

Если в шапке заказа указана группа складов, то в форме ввода количества отображаются остатки по всем складам данной группы.

Если заказ оформлен на группу складов, то в форме ввода количества, открываемой из формы подбора товаров, на закладке В наличии – колонка Доступно можно получить информацию о свободных остатках товаров на всех складах, входящих в группу склада.

На закладке В наличии или ожидается - колонка Доступно можно получить информацию как о свободных остатках товаров на всех складах, входящих в группу склада, так и об ожидаемых поступлениях.

## Информация о резервах

При подборе товаров в заказ в момент ввода количества можно просмотреть информацию о резервах. При подборе форма ввода количества доступна при настройке «Запрашивать количество» или «Запрашивать количество и цену» (команда Еще – Настройки в форме подбора товаров).

В форме ввода количества информация о резервах доступна на закладке В наличии в колонке В резерве. В этой колонке отображается информация о количестве товара, зарезервированного по другим заказам. Это позиции товара, для которых в строках других заказов установлено действие «Резервировать по мере поступления», «Резервировать на складе».

Предусмотрена расшифровка резерва в отдельной форме. При расшифровке колонки В резерве открывается форма с информацией по резервам по необособленным заказам.  Из формы резервов по необособленным заказам можно открыть заказ.

Если заказ оформлен на группу складов, то в табличной части заказа при подборе склада открывается форма Подбор склада для необособленного обеспечения, в которой доступна информация о резервах.

Из формы подбора склада для необособленного обеспечения предусмотрена расшифровка резерва в отдельной форме.

Также информация о резервах доступна в форме, открываемой при подборе серий в заказ.
