# Настройка ТСД через универсальный драйвер

В данном разделе приведены настройки в случае использование ТСД с установленным мобильным клиентом 1С. В этом случае обработка сканируемых кодов выполняется непосредственно в соответствующем мобильном рабочем 1С на ТСД. Для конфигурации 1С в этом случае ТСД используется так же, как и обычный сканер штрихкодов. Функция обмена с ТСД в этом случае не используется.

## Описание параметров подключения экземпляра оборудования.

Для настройки параметров пролистайте карточку параметров подключения и тапните на свернутую группу «Общие, Клавиатура, Com порт, Broadcast, Лог»:

### Режим Клавиатура.

Настройте параметры подключения как показано на скриншотах:

Обратите внимание:

■ Тип устройства должен быть Клавиатура

■ Тип выходных данных: Строка

■ Переключатель «Обрабатывать все типы сообщений» должен быть включен.

■ Суффикс должен совпадать с тем, который указан в настройках устройства. Рекомендуется использовать auto CRLF.

■ Кодировка COM-порта должна совпадать с той, которая указана в настройках оборудования. Рекомендуется использовать UTF-8.

Далее откройте настройки сканера на устройстве и настройте сканер ТСД как на скриншотах (обязательные значения настроек выделены):

Обратите внимание:

■ Тип клавиатуры может быть установлен в значение «Аппаратная клавиатура»,

■ Action key character должен совпадать с указанным в параметрах подключения экземпляра оборудования, рекомендуется использовать CRLF.

■ Тип кодировки должен совпадать с указанным в параметрах подключения экземпляра оборудования, рекомендуется использовать UTF-8
