# 14.3. Отчеты по международному финансовому учету

_Source: about:srcdoc_

# Отчеты по международному финансовому учету

Отчеты по международному учету включают в себя:

■ Комплект настраиваемых форм финансовой отчетности на Видах финансовых отчетов:

○ Отчет о финансовом положении,

○ Отчет о совокупном доходе,

○ Отчет об изменениях в капитале,

○ Отчет о движении денежных средств,

○ Примечания к финансовой отчетности и прочая пояснительная информация.

■ Стандартные отчеты финансового учета:

○ Оборотно-сальдовая ведомость,

○ Обортно-сальдовая ведомость по счету (с детализацией до субконто),

○ Оборотно-сальдовая ведомость с корреспонденцией,

○ Отчет по проводкам,

○ Карточка счета,

○ Анализ счета,

○ Анализ субконто.

■ Дополнительные отчеты для анализа и сверки данных:

○ Анализ взаиморасчетов контрагентов по договорам,

○ Шахматная ведомость,

○ Сводные проводки,

○ Сверка оборотов международного и регламентированного учетов,

○ Использование счетов и субконто в настройках,

○ Соответствие счетов международного и регламентированного учета.

В стандартных отчетах по международному финансовому учету есть возможность расшифровки данных при помощи другого отчета по аналогии со стандартными бухгалтерскими отчетами регламентированного учета. Расшифровка возможна по определенным связям между отчетами.

**Схема связей отчетов с возможностью расшифровки**

На форме плана счетов можно выбрать вариант формирования проводок «с корреспонденций» или «без корреспонденции». В случае выбора варианта «без корреспонденции» проводки по дебетуемым и кредитуемым счетам формируются отдельными записями с контролем сохранения баланса на уровне документа. Набор стандартных отчетов при использовании проводок с корреспонденцией следующий:

Стандартные бухгалтерские отчеты, ориентированные на корреспонденцию счетов, недоступны для планов счетов «без корреспонденции». Такие отчеты выделены на схеме серым цветом.

Для отчетов, где нужна корреспонденция, доступен выбор только соответствующих планов счетов.

При использовании только проводок без корреспонденции набор стандартных отчетов следующий:

■ Анализ субконто;

■ Карточка счета;

■ Оборотно-сальдовая ведомость по счету;

■ Оборотно-сальдовая ведомость. Пробный баланс;

■ Отчет по проводкам.
