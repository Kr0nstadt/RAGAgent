# Ведение учета для подготовки отчетности по МСФО

## Настройки учета

Перед началом работы с подсистемой нужно ее настроить в НСИ и администрирование – Международный финансовый учет.

Определить, будет ли использоваться Несколько планов счетов.

По плану счетов нужно выбрать источник Функциональной валюты (управленческий или регламентированный учет) и задать Валюту представления.

Далее необходимо выбрать, по каким источникам будут формироваться проводки:

■ Проводки по данным оперативного учета;

○ Настройка по объектам учета и их корреспонденциям;

○ Настройка по хозяйственным операциям;

■ Проводки по данным регламентированного учета.

Для новых внедрений рекомендуется использовать опцию Настройка по объектам учета и их корреспонденциям.

При инициализации новой информационной базы доступен только режим Настройка по объектам учета и их корреспонденциям. В базах, где ранее велся МФУ по данным оперативного учета, опция Настройка по хозяйственным операциям включена и доступна. Загрузка в базу модели МФУ, содержащей настроенные шаблоны проводок по хозяйственным операциям, также сделает опцию доступной.

Дальнейшая поддержка механизма трансляции по оборотным регистрам Настройка по хозяйственным операциям будет ограничена. Не будут поддерживаться отражение новых хозяйственных операций, добавляемых при развитии системы, и исправление текущих исторических ограничений (мест, где не хватало оборотных регистров), которые покрываются возможностями нового подхода.

Работа в разделе Международный финансовый учет начинается с настройки плана счетов в разделе Настройки и справочники. План счетов «Международный» настраивается в соответствии с планом счетов, принятым на предприятии (рекомендуемым аудиторами).

Далее на основании принятой на предприятии учетной политики необходимо настроить Использование международного учета в организациях в Международный финансовый учет – Настройки и справочники, создать Настройку формирования проводок и указать период ее действия для каждого из используемых планов счетов.

Одна настройка формирования проводок может использоваться для нескольких организаций. Переход по гиперссылке открывает рабочее место настроек по оперативному учету, либо по регламентированному, если трансляция по оперативным данным отключена.

По контекстной команде Открыть можно перейти к форме Настройка формирования проводок, а по команде Создать – создать новую запись справочника настроек.

В настройке формирования проводок настраиваются особенности учетной политики в части учета корректировок. Есть два варианта формирования проводок по исправлениям «на уменьшение»:

■ Сторно – положение счетов сохраняется, суммы с «-»;

■ Реверс – счета дебета и кредита меняются местами, суммы при этом остаются положительными.

Такие проводки могут формироваться механизмом исправления ошибок в финансовых документах, а также документами Корректировка реализации, Корректировка приобретения, Отражение прочих доходов и расходов и некоторыми другими.

После настройки механизмов формирования проводок международного учета осуществляется настройка структуры отчетности в генераторе финансовых отчетов:

■ создание новых (или изменение поставляемых моделью) видов отчетов;

■ уточнение структуры показателей отчетности;

■ объединение отчетов в комплекты отчетности.

После того, как ввод в систему и проверка документов оперативного учета завершены, в течение каждого отчетного периода по ним выполняется автоматическое формирование проводок международного учета в рабочем месте Международный финансовый учет – Отражение документов в международном учете.

Ручной ввод бухгалтерских проводок осуществляется с использованием:

■ отдельно выбранных документов оперативного учета в момент их поштучного отражения в международном финансовом учете при установке флажка Ручная корректировка проводок;

■ документов Операция (международный учет).

Документ Операция (международный учет) может использоваться, например, для отражения в учете резервов и начисления прочих сумм.

Возможны следующие способы его заполнения:

■ ручной ввод корреспонденции счетов и суммы проводки;

■ загрузка данных из табличного документа, например, из таблицы Excel;

■ формирование сторнировочных записей на основании проводок международного учета в закрытом периоде;

■ формирование сторнировочных проводок на основании перечня выбранных документов или другого документа Операция (международный учет);

■ использование ранее сохраненной типовой операции.

На форме плана счетов можно выбрать вариант формирования проводок «с корреспонденций» или «без корреспонденции». В случае выбора варианта «без корреспонденции» проводки по дебетуемым и кредитуемым счетам формируются отдельными записями с контролем сохранения баланса на уровне документа. При добавлении проводки в документ Операция (международный учет) сумма заполняется автоматически, чтобы баланс соблюдался.

## Совместное использование режимов формирования проводок

Режимы Проводки по данным оперативного учета и Проводки по данным регламентированного учета могут использоваться совместно.

Трансляции будут работать одновременно, и это приведет к задвоению проводок, поэтому нужно использовать настройки исключения и документ отражать в МФУ по данным только одного учета.

В случае применения опции Настройка по хозяйственным операциям есть возможность добавить в исключения (игнорирование при формирования проводок) операцию целиком или шаблона по ней. Для этого используются команды Исключить хозяйственную операцию и Исключить шаблон проводки.

Трансляция из регламентированного учета имеет настройку Исключить соответствие счетов и Исключить соответствие оборотов.

Использование исключений позволяет часть операций отражать по данным оперативного учета, а часть по данным регламентированного.

В случае применения опции Настройка по объектам учета и их корреспонденциям объекты учета отражаются в учете всегда, исключить из отражения можно только корреспонденции. Для этого в корреспонденции объектов учета используется флаг Не отражается на счетах.

В случае совместного использования отражения в МФУ по объектам учета и по данным регламентированного учета нужно настроить в исключения все счета регламентированного учета на закладке Соответствие счетов  и использовать только настройки корреспонденций на закладке Соответствие оборотов, настроив исключения для таких проводок по корреспонденции объектов учета.

## Настройка трансляции по объектам учета и их корреспонденциям

### Источники данных

Механизм формирования проводок по хозяйственным операциям оперативного учета использует в качестве источника данных оборотные регистры.

Оборотные аналитические регистры являются производными от остаточных, как движение пары остаточных регистров с основной аналитикой для них, и обеспечивают корреспонденцию по аналогии с бухгалтерскими проводками.

Настройка отражения проводок в МФУ по хозяйственным операциям сопряжена с указанием всех возможных и используемых в учете операций. Подход дает гибкость настройки в части использования дополнительных отборов и нескольких шаблонов на одну операцию, но на практике такая настройка трудоемка. Источники данных МФУ по оборотам сложны в поддержке на стороне разработки новых документов и актуализации оборотной аналитики при развитии конфигурации и детализации данных в остаточных регистрах, как первичных для документов и финансового контура учета в целом.

Механизм формирования проводок на базе остаточных финансовых регистров оперативного контура является альтернативным механизму трансляции по оборотным регистрам. Совместное одновременное использование двух подходов не поддерживается.

Используется тот же план счетов и регистр бухгалтерии, поэтому возможен переход на новый механизм с любого периода после настройки правил трансляции. Доступно и обратное переключение на трансляцию по хозяйственным операциям. Меняется механизм отражения данных оперативного учета внутри того же плана счетов.

В качестве источника данных транслятора в МФУ по объектам учета используются первичные остаточные финансовые регистры оперативного учета. Подход реализует более простую настройку счетов для большинства операций, но при этом имеет расширенные возможности настройки по корреспонденции  для особых случаев.

Это дает гибкость подхода от хозяйственных операций с большей простотой настройки, по аналогии с настройкой счетов по группам финансового учета для регламентированного учета.

Каждая финансовая операция в системе отражается в паре остаточных финансовых регистров (один регистр дебетуется, другой кредитуется) и проводка может быть сформирована, если обеспечить связь движений в обоих регистрах. Таким образом, пара остаточных регистров заменяет один оборотный.

При этом расширено использование в учете статей активов и пассивов, которые задействованы в формировании проводок международного финансового учета. Статьи активов и пассивов – учитываемые в балансовых регистрах активы и пассивы, сгруппированные по однородному экономическому содержанию. Данные одного балансового регистра могут относиться к одной или нескольким статьям активов и пассивов. Состав статей активов и пассивов определяется реализованными в системе возможностями ведения учета. Состав статей расширяется при реализации новых учетных подсистем.

Балансовые регистры оперативного учета реализуют учет активов и пассивов предприятия в суммовом выражении. Любая хозяйственная операция, которая приводит к изменению состава или структуры активов и пассивов отражается в этих регистрах с использованием принципа двойной записи.

Подробнее о балансовых регистрах оперативного учета и их составе см. [Описание остаточных и оборотных регистров оперативного учета](/db/erp25doc/bookmark/analiticalregistersdescriptionforbuggeting/AnaliticalRegistersDescriptionForBuggeting). Также см. статью [Статьи активов и пассивов, описывающие данные балансовых регистров («план счетов» оперативного учета)](/db/erp25doc/bookmark/assetsandliabilities/AssetsAndLiabilitiesOperationalAccounting).

Связь регистров обеспечивается с помощью двух реквизитов:

■ Идентификатор фин. записи – уникальный идентификатор строки документа, по которой формируются движения, как идентификатор документа или объекта расчетов, в рамках которого формируются движения, сгенерированный в расчетном механизме.

■ Настройка хозяйственной операции – ссылка на справочник хозяйственных операций, заполняется исходя из сути операции, является аналогом хозяйственной операции в оборотном регистре.

Например, источником формирования проводок для документа Внутреннее потребление товаров в новом механизме является пара регистров Себестоимость товаров и Прочие расходы. Такая связка заменяет собой регистр Движения Номенклатура – Доходы/Расходы и предоставляет полную аналитику оперативного контура для проводок.

В качестве источника данных для проводок выступают следующие финансовые регистры (в скобках указаны счета регламентированного плана счетов для понимания аналогии с финансовым учетом):

В регистре бухгалтерии МФУ есть реквизит Идентификатор фин. записи. Данный реквизит заполняется при формировании проводок из регистров-источников и обеспечивает связь записей дебетуемого и кредитуемого регистра с проводками. Это упрощает задачу сверки бухгалтерского и оперативного контура при анализе движений документа  – каждая проводка МФУ может быть сопоставлена с записями остаточных регистров по полям:

■ Настройка хозяйственной операции;

■ Идентификатор фин. записи.

### Настройка проводок

Настройка счетов учета происходит в рабочем месте Международный финансовый учет – Настройки и справочники – Настройка проводок по данным оперативного учета.

В отборах формы задаются:

■ Организация – указанная или по всем;

■ План счетов – используемый для настройки план счетов, если включена опция нескольких планов счетов;

■ Настройка – действующая для организации в этом периоде схема отражения проводок.

Настройка проводок выполнятся в двух вариантах:

■ По объектам учета - в разрезе групп финансового учета (ГФУ), организаций, складов и подразделений. Позволяет быстро настроить отражение операций на планах счетов целиком для всего объекта учета (статьи активов/пассивов). Настройка осуществляется балансовым методом – сразу для всех мест по дебету и кредиту.

■ По корреспонденциям объектов учета  - с произвольными отборами по измерениям регистров. Обеспечивает аналогичную гибкость настройки, как по хозяйственным операциям.

Подход уточнений по корреспонденции работает совместно с настройкой по объектам учета: позволяет большую часть проводок настроить по объектам учета (статьям активов/пассивов), а небольшую часть уточнить через трансляцию отдельных корреспонденций.

Возможности настройки корреспонденций:

■ могут быть сформированы проводки на специальных счетах, как исключения из общих правил;

■ обороты могут быть совсем исключены из трансляции;

■ могут быть сформированы дополнительные проводки, более чем одна проводка по одной хозяйственной операции (например, для движений через промежуточный счет);

■ проводки могут быть помечены к ручному уточнению в закрытии месяца;

■ знак суммы может быть инвертирован, а счета Дт и Кт поменяны местами (позволяет делать сторно или реверс).

Закладка Просмотр настроек по плану счетов рабочего места позволяет проанализировать план счетов и его настройки разноски по каждому счету и уточнить их.

### Закладка «По объектам учета»

В этом режиме настройки с левой стороны представлен список Объекты учета (активы и пассивы), где выводится фиксированный перечень требующих настройки учетных сущностей. Колонка с иконкой Требуется настройка счетов справа от наименования объекта учета выводит количество ГФУ, по которым требуется настройка.

Подробнее о замене объектов учета на статьи активов и пассивов можно прочитать в статье [Замена объектов учета на статьи активов и пассивов](/db/erp25doc/bookmark/ifrsreporting/AccountingObjectReplacementByActivePassiveItems).

Отбор сверху списка Показать: Все / Требующие настройки  позволяет фильтровать список объектов, оставляя только ненастроенные места. Фильтр Требуется настройка счетов покажет список объектов учета, по которым есть документы, и отразить которые не получилось, а не весь список ГФУ системы, по которым еще нет настройки.

Счетчик требующих настройки ГФУ заполняется при попытке отразить документы в международном учете (из рабочих мест Закрытие месяца, Отражение документов в международном учете или по кнопке из формы проводок DrCr - Отразить). С правой стороны выводится список ГФУ (если они предусмотрены для объекта) или иной детализации, свойственной объекту учета, для указания счета учета.

Кнопка Заполнить счет учета позволяет указать один общий счет учета нескольким выделенным строкам.

Для повышения информативности счета представлены в виде кода и наименования.

У большинства объектов учета, где есть ГФУ, группа фин. учета одна, но статьи расходов являются исключением. Там есть возможность разной настройки распределения расходов для управленческого, бухгалтерского и налогового учетов, поэтому в статье расходов три ГФУ: для УУ и МФУ, БУ и НУ.

Несмотря на то, что источником функциональной валюты МФУ может быть как управленческий, так и регламентированный учет, для настроек разноски в МФУ всегда используется ГФУ упр. учета и МФУ, даже если функциональная валюта настроена на источник регламентированного учета.

В текущей реализации не поддерживается сценарий настройки счетов международного учета непосредственно в группах финансового учета. Такой сценарий работы будет добавлен в рамках развития системы.

По гиперссылке Исключения – Настроить можно перейти в режим уточнения счета учета в разрезе организаций, подразделений, складов и прочей аналитики, доступной для объекта учета.

Исключения можно просмотреть, переключив режим списка тумблером Исключения. По кнопке Создать можно указать счет учета для конкретной аналитики. Исключения при трансляции применяются с большим приоритетом, чем общие настройки.

■ Автоматически из регистра;

Система автоматически заполняет субконто на счетах учета из доступных измерений регистра для объекта учета.

Если же нужно указать фиксированное значение или в качестве субконто использовать реквизиты аналитики объекта учета, то такая возможность есть в пользовательской настройке.

Клик по гиперссылке в столбце Заполнение субконто открывает форму просмотра и настройки заполнения субконто.

Способ заполнения субконто на счете учета:

■ Из регистра – выбор измерения или его реквизита из источника данных;

■ Указанное значение – выбор значения из справочников, являющихся типом данных для субконто;

■ Не заполнять – оставлять пустым.

Если система не может автоматически заполнить субконто, то надпись Настройка заполнения субконто (Х) станет красной с припиской количества проблем в скобках. А в столбце Заполнение субконто у таких счетов будет Требуется пользовательская настройка.

Можно донастроить субконто выбрав из реквизитов аналитики регистра-источника объекта учета или указать явное значение, оставить субконто пустым. Либо выбран не тот счет учета или на нем нужно настроить иной набор субконто.

Для объектов учета несобственных ценностей могут быть указаны только забалансовые счета международного учета. Забалансовые счета не могут быть указаны для объектов учета собственных ценностей.

### Закладка «По корреспонденциям»

В этом режиме настраиваются особые исключения из общих правил – явные корреспонденции объектов учета между собой и шаблоны проводок Дт-Кт счетов для них.

Список корреспонденций может быть представлен в двух видах:

■ Общим списком – все корреспонденции, доступны сортировки по столбцам общего списка;

■ С отбором по объектам учета – можно анализировать и создавать корреспонденции от Дт или Кт объектов учета.

Кнопками Создать или Копировать создается новая настройка корреспонденции.

Указываются объекты учета для Дт и Кт по аналогии с бухгалтерской проводкой, но по данным оперативного контура.

Настройка счетов по корреспонденциям упрощена: настраивать счет отражения корреспонденции можно только по дебету или по кредиту, а вторую половину корреспонденции можно отражать по настройкам объекта учета.

Это позволяет уменьшить количество настроек корреспонденций и затраты на их ввод и поддержку в том случае, если счета учета, которые не должны измениться при отражении корреспонденций, в настройках по объектам учета имеют зависимости от ГФУ или исключения.

В форме настройки отражения корреспонденции указываются признаки необходимости настройки счетов учета дебета и кредита, для сохранения настройки отражения корреспонденции в ней надо настроить один или оба счета учета.

В примере на рисунке ниже настраивается счет учета кредита, а счет дебета определяется настройкой по объектам учета.

Если счет учета в корреспонденции не требует настройки, на его месте выводится информационная надпись со счетами учета, настроенными для соответствующего объекта учета. Данный список счетов открывается по гиперссылке.

В списке настроек отражения корреспонденций выводится надпись <не изменен> для счетов учета, настройка которых не требуется.

Настройки отражения корреспонденций, у которых не настроен один из счетов, показываются в списке настроек по счету вместе с настройками по соответствующему объекту учета.

Применение данного функционала упрощения настройки корреспонденций ограничено планами счетов международного учета с вариантом формирования проводок С корреспонденцией.

Оборот по корреспонденции объектов учета может не отражаться в финансовом учете на плане счетов. Для этого в настройку корреспонденции нужно установить отметку Не отражается на счетах.

Знак суммы можно инвертировать, используя отметку Изменять знак операции при отражении в учете. Эта опция совместно с перестановкой местами счетов Дт и Кт позволяет делать реверсирующие или сторнирующие проводки.

Опция Ручное уточнение проводки позволит получить запрос на уточнение проводок любых документов с такими корреспонденциями в закрытии месяца в рабочем месте Отражение документов в международном учете.

Субконто для указанных счетов Дт и Кт подбираются автоматически из доступных измерений регистра-источника объекта учета, но могут быть уточнены пользовательской настройкой аналогично уточнению субконто для счетов по всему объекту учета.

Для объектов учета, участвующих в корреспонденции, можно задать дополнительные отборы и уточнить тем самым оборот, который будет делать проводку в Дт и Кт конкретных счетов.

Полями отбора могут быть измерения регистра-источника объекта учета или их реквизиты. Например, можно делать отборы по группам статей расходов или объектов учета, группируя таким образом пул корреспонденций для уточнения счетов Дт и Кт в проводке.

При формировании проводок по корреспонденции объектов учета заданные шаблоны проводок применяются последовательно с учетом приоритета и дополнительных отборов. После того как применилась настройка с правилом применения Не применять корреспонденция считается отраженной и другие настройки не применяются.

В случае выбора Применять в формировании проводок могут участвовать настройки с более высоким значением из поля Порядок применения. Это позволяет делать несколько проводок по одной корреспонденции.

Рассмотрим на примере использование настроек корреспонденций. В оперативном учете комиссионное вознаграждение отражается:

■ Дт объекта учета Себестоимость продаж (ресурсы доп. расходов регистра Выручка и себестоимость продаж)

■ Кт объекта учета Задолженность перед поставщиками (ресурсы долга регистра Расчеты с поставщиками по срокам)

Если использовать простую настройку проводок «по объектам учета», то будет сформирована одна проводка (для наглядности проводки будут на примере регламентированного плана счетов):

Дт 90.02 – Кт 60.01

При этом желаемым является отражение двумя проводками через промежуточный счет:

Дт 44.02 – Кт 60.01 – отражение расходов по вознаграждению

Дт 90.07 – Кт 44.02 – списание расходов на фин. результат

Задача решается настройками отражения корреспонденций.

Добавляется первая настройка для формирования проводки Дт 44.02 – 60.01 с порядком применения «1».

По корреспонденции требуется сформировать еще вторую проводку, поэтому указывается Применять для последующих настроек.

На 44 счете есть субконто Статьи расходов. В регистрах оперативного контура такого поля нет. Поэтому требуется выполнить настройку субконто вручную.

Для формирования проводки Дт 90.07 – Кт 44.02 добавляется настройка с порядком применения «2».

После применения настройки проводки по корреспонденции полностью сформированы, поэтому устанавливается Не применять последующие настройки.

По гиперссылке Все настройки по корреспонденции из формы настройки шаблона проводки можно открыть список настроенных корреспонденций и изменить порядок стрелками сортировки. Выводится список всех настроек с отбором по объектам учета Дт и Кт. Для настроек с одинаковыми отборами по объектам учета Дт и Кт требуется анализ и управление порядком применения шаблонов проводок.

Режим настройки корреспонденции С отбором по объектам учета позволяет использовать фильтр Показать: Все / С настройками. Можно анализировать и настраивать корреспонденции со стороны объекта учета по Дт или Кт. В форме списка корреспонденций показано в Дт или Кт используется объект учета.

По гиперссылке из столбца Порядок применения можно перейти к форме настройки приоритета применения шаблонов проводок с одинаковыми объектами учета.

Данные оперативного учета операций с несобственными ценностями в большинстве случаев не имеют двойной записи. Поэтому объекты учета несобственных ценностей исключены из настроек счетов учета по корреспонденциям. Проводки международного учета, отражающие операции с несобственными ценностями на забалансовых счетах учета, всегда формируются без корреспонденций.

Отчет Анализ корреспонденций открывает отчет-шахматку, в котором можно проанализировать корреспонденции за период. В отчете выводятся отраженные в учете корреспонденции.  Это позволяет проанализировать, как документы оперативного учета отражаются по объектам учета для более точной настройки шаблонов проводок по корреспонденции объектов.

Из отчета кнопкой Создать настройку можно оформить нужный шаблон отражения корреспонденции. Шаблон создается контекстно от курсора в отчете на пересечении объектов учета по Дт и Кт.

Из отчета возможна расшифровка до хозяйственной операции и регистратора.

### Закладка «Просмотр настроек по плану счетов»

Закладка Просмотр настроек по плану счетов позволяет проанализировать план счетов и его настройки разноски по каждому счету и уточнить их.

Слева представлен список счетов плана счетов, а справа – настройки его использующие.

В списке настроек отображаются признаки настроек для этого счета:

■ Тип настройки – По корреспонденции или Общая по объекту учета;

■ Объект учета – для которого используется счет или пара объектов для корреспонденции;

■ Информация по настройке  - группа финансового учета или иной признак уточнения счета учета для объекта учета.

По кнопке Открыть настройку или по двойному клику в списке можно просмотреть и отредактировать настройку, можно скопировать или удалить настройку через команду Еще.

### Форма просмотра проводок и настройка счетов из нее

Документы после проведения в оперативном учете требуют отражения в международном финансовом учете. Отражение делается в одном из этапов помощника Закрытие месяца, из рабочего места Отражение документов в международном учете или контекстно из формы просмотра проводок DrCr кнопкой Отразить в международном учете.

В результате отражения формируются проводки МФУ, а при нехватке настроек формируется текст сообщения об ошибке и список необходимых для разноски правил отражения.

Текст с проблемой можно просмотреть в форме проводок в поле Комментарий автоматического отражения документа в международном учете. По кнопке Проверить правила отражения вызывается список объектов учета без настройки счетов.

При переходе из списка необходимых правил отражения к форме настройки курсор позиционируется на проблемном месте, где требуется настройка.

После настройки обнаруженных проблем можно нажать кнопку Обновить и проверить настройки еще раз. Если все счета указаны, то будет сообщение, что все хорошо и можно отразить документ в учете.

В форме просмотра проводок по кнопке Анализ корреспонденций вызывается отчет, показывающий пары регистров для объектов учета, связанных через идентификатор фин. записи и хозяйственные операции со счетами учета, которые настроены для разноски. Если счет не настроен для объекта учета или корреспонденции, то в отчете будет пустой счет учета.

Если в системе после обновления на новую версию конфигурации в исторических данных нет связи регистров через идентификатор фин. записи, то в отчете такие места разрывов будут выделены цветом, как проблемные.

В таких документах движения были сформированы до появления алгоритма генерации идентификаторов записи и связи по ним регистров.

Такие документы при попытке отражения в учете выдадут ошибку Нарушена двойная запись в финансовых регистрах.

Документ с проблемами двойной записи нужно перепровести, это сделает присвоение идентификатора в регистрах и восстановит связи между ними.

Такую проверку на целостность двойной записи по отражаемым в международном учете за период документам система делает автоматически в Закрытии месяца и исправляет движения документов перед формированием проводок.

На форме плана счетов можно выбрать вариант формирования проводок «с корреспонденций» или «без корреспонденции». В зависимости от выбора проводки записываются в разные регистры бухгалтерии, так как вариант проводок определяется на уровне метаданных. В случае выбора варианта «без корреспонденции» проводки по дебетуемым и кредитуемым счетам формируются отдельными записями с контролем сохранения баланса на уровне документа. При этом сформированные проводки «с корреспонденцией» перед записью «разрезаются» на отдельные записи и сворачиваются по измерениям, субконто и реквизитам.

При добавлении проводки сумма заполняется автоматически, чтобы баланс соблюдался.

Все механизмы (загрузка проводок, регламентные операции, закрытие периода и др.) работают, как с регистром бухгалтерии «с корреспонденцией», так и с регистром «без корреспонденции».

Изменение варианта формирования проводок на используемых планах счетов не рекомендуется. В случае изменения потребуется повторное отражение документов в учете.

### Замена объектов учета на статьи активов и пассивов

Объекты финансового учета, реализованные в настройках проводок по данным оперативного учета в виде одноименного перечисления, заменяются на статьи активов и пассивов, описывающие данные балансовых регистров оперативного учета. Термин **Объекты учета** сохранен в международным финансовом учете как способ настройки счетов и формирования проводок.

Состав статей активов и пассивов разработан на основе существующего классификатора объектов финансового учета с внесением следующих изменений:

■ изменены наименования статей и групп для большего соответствия плану счетов бухгалтерского учета;

■ изменено объединение статей в группы для большего соответствия плану счетов бухгалтерского учета и учета экономического содержания статей;

■ объекты финансового учета Товары, принятые на хранение на складах и Товары, принятые на хранение к оформлению списания объединены в одну статью активов и пассивов Товары, принятые на хранение на складах;

■ объекты финансового учета Материалы, принятые в переработку на складах и Материалы, принятые в переработку к оформлению списания объединены в одну статью активов и пассивов Материалы, принятые в переработку на складах.

Регистры учета настроек счетов, настроек заполнения субконто и настроек отражения корреспонденций для старых объектов финансового учета помечены в системе как неиспользуемые.

Созданы новые регистры учета настроек формирования проводок, в которых роль объектов учета исполняют статьи активов и пассивов.

Реализован автоматический перенос настроек формирования проводок из старых регистров в новые.

Из-за изменения состава статей активов и пассивов относительно объектов финансового учета есть небольшая вероятность, что некоторые настройки счетов и субконто по изменившимся объектам учета не будут автоматически перенесены.

Настройки отражения корреспонденций, в которых со стороны дебета или кредита указан объект финансового учета **Прочие активы и пассивы** без указания дополнительного отбора по пользовательской статье активов и пассивов, тоже не будут автоматически перенесены в новый регистр, так как без дополнительного отбора невозможно определить, к какой статье относится настройка.

В рабочее место **Настройка счетов международного учета** на закладку **По объектам учета** добавлены информационные сообщения о наличии неперенесенных настроек счетов и настроек заполнения субконто.

По гиперссылкам **настройки счетов учета** и **настройки заполнения субконто** из информационного сообщения можно перейти к спискам необработанных при переходе на новую функциональность счетов и настроек субконто. В карточку настройки счетов международного учета по объектам добавлен признак **Не обработана автоматически** и указание статьи активов/пассивов, на которую заменяется объект финансового учета в новых настройках.

В рабочее место **Настройка счетов международного учета** на закладку **По корреспонденциям** добавлено информационное сообщение о наличии неперенесенных настроек отражения корреспонденций. По гиперссылке **настройки отражения корреспонденций** из информационного сообщения можно перейти к списку необработанных настроек отражения корреспонденций. В карточку настройки отражения корреспонденций в международном учете добавлен признак **Не обработана автоматически**.

При нажатии на гиперссылки в информационных сообщениях открываются старые регистры с настройками, перенос которых не был выполнен автоматически. Восстановление необработанных настроек выполняется вручную в рабочем месте для настройки счетов международного учета на соответствующих закладках. Нет единого правила восстановления всех настроек. Можно руководствоваться следующим:

■ настройки устаревшего учета, по которым уже не будет новых данных, а существующие данные находятся в закрытом периоде, можно не переносить;

■ если в старой настройке не заполнено поле со статьей активов и пассивов, возможно объект финансового учета нетиповой и ему не найдена на замену типовая статья. Для переноса следует использовать типовую статью или реализовать в классификаторе статей новую статью и использовать ее для переноса настройки;

■ если это настройки объектов финансового учета **Товары, принятые на хранение к оформлению списания** или **Материалы, принятые в переработку к оформлению списания**, которые в статьях активов и пассивов вошли в состав принятых товаров и материалов на складах, то для переноса следует использовать статьи **Товары, принятые на хранение на складах** и **Материалы, принятые в переработку на складах** с указанием исключений по местам учета в настройках счетов;

■ если это настройка отражения корреспонденций, в которой со стороны дебета или кредита указан объект финансового учета **Прочие активы и пассивы** без дополнительного отбора на равенство статье, необходимо определить состав статей активов и пассивов, на которые должна действовать эта настройка, и воспроизвести ее в рабочем месте для каждой статьи.

При нажатии на гиперссылку **Больше не показывать это сообщение** информационные сообщения о наличии неперенесенных настроек скрываются. Сообщения на разных закладках скрываются независимо друг от друга. Сообщения скрываются сразу для всех пользователей.

Если в информационной системе есть устаревшие настройки счетов международного учета по объектам финансового учета, их можно открыть в любое время из меню **Еще** рабочего места **Настройка счетов международного учета**.

### Настройка счетов учета прочих операций

Под прочими операциями понимаются операции, которые отражаются в финансовом учете в корреспонденции с прочими активами/пассивами. Для этого используется справочник Статьи  активов и пассивов, должна быть включена опция НСИ и администрирование – Финансовый результат и контроллинг – Финансовый результат – Учитывать прочие активы и пассивы.

В оперативном контуре при разноске документа формируются движения по оборотному регистру накопления Движения прочие активы и пассивы. Данный регистр участвует в построении корреспонденций с другими финансовыми регистрами и является источником для проводок.

См. статью [Статьи активов и пассивов, описывающие данные балансовых регистров («план счетов» оперативного учета)](/db/erp25doc/bookmark/assetsandliabilities/AssetsAndLiabilitiesOperationalAccounting).

В карточке статьи актива/пассива по гиперссылке Настройка счетов учета статьи в документах по умолчанию указывается счет и субконто для него для всех используемых планов счетов (если настроено несколько планов счетов международного учета).

Настройки по умолчанию при выборе статьи активов/пассивов наследуются в документ и могут быть изменены там для каждого из планов счетов по клику на гиперссылку Счет учета. В открывшейся форме указываются счета и субконто, по кнопке Загрузить счета из статьи можно восстановить счета по умолчанию.

Статьи активов и пассивов, созданные пользователями, при использовании объектов финансового учета транслируются в один объект учета **Прочие активы и пассивы**. Это накладывает несколько ограничений на возможности настройки счетов:

■ счета учета для пользовательских статей активов и пассивов возможно указать только в местах использования этих статей в документах;

■ при настройке счетов отражения корреспонденций при выборе в корреспонденции объекта учета **Прочие активы и пассивы** требуется указание дополнительного отбора, чтобы создаваемая настройка не действовала на корреспонденции со всеми пользовательскими статьями активов и пассивов.

После начала использования статей активов и пассивов в настройках проводок, статьи, созданные пользователями, будут иметь такие же возможности настройки счетов, как и статьи, описывающие данные балансовых регистров оперативного учета. В статьях активов и пассивов, создаваемых пользователем, есть переключатель **Счета международного учета** с возможными значениями **Указываются в документах** и **Указываются в настройках проводок**.

В пользовательской статье в любой момент может быть установлен новый признак указания счетов в настройках проводок. Если статья до этого уже использовалась в документах, то счета в проводках по этой статье будут соответствовать тем, которые указаны в документах. В новых документах указывать счета международного учета по статье будет не нужно, при формировании проводок они будут определяться из настроек статьи. В пользовательской статье после установки переключателя указания счетов учета в настройках проводок пропадает возможность указания счетов по умолчанию для международного учета. Настройка остается только для регламентированного учета, а если такой учет не ведется, то гиперссылка исчезает совсем.

У пользовательских статей нет разрезов настройки счетов.

Группа **Прочие активы и обязательства** присутствует в списке объектов учета при наличии пользовательских статей активов и пассивов со способом указания счетов **Указываются в настройках проводок**.

### Закрытие месяца и отражение документов

Обязательным условием для работы механизма формирования проводок по объектам учета является отсутствие нарушений двойной записи по идентификаторам фин. записей в оперативном контуре.

Поддерживается переход на новый механизм формирования проводок с любого периода. При этом заполнение идентификаторов фин. записей в регистрах поддержано только в редакции 2.5. По историческим данным, введенным в версии 2.4, после перехода на 2.5 двойной записи и связи регистров не будет.

При попытке сформировать проводки по документу с нарушением корреспонденции в регистре сведений Отражение документов в международном учете будет присвоен специальный статус отражения Нарушена двойная запись в финансовых регистрах.

Если перепроведение документа проблему не решает и не восстанавливает двойную запись, то это текущее ограничение или ошибка в конфигурации.

В рабочем месте Отражение документов в международном учете документы с ошибками двойной записи выводятся отдельным пунктом Документы не отраженные в учете из-за нарушения двойной записи в финансовых регистрах.

По таким документам с нарушением двойной записи проводки могут быть сформированы вручную, установкой отметки Ручная корректировка проводок в форме проводок DrCr.

### Долгосрочные активы и обязательства

Поддерживается деление активов и обязательств на краткосрочные и долгосрочные при отражении документов и операция реклассификации активов и обязательств при смене срочности в закрытии месяца.

Выделение долгосрочных активов и обязательств возможно только при формировании проводок по данным оперативного учета с опцией Настройка по объектам учета и их корреспонденциям.

Требования из стандартов МСФО:

■ п. 60 МСФО (IAS) 1 «Представление финансовой отчетности»: В своем отчете о финансовом положении организация должна раздельно представлять оборотные и внеоборотные активы, а также краткосрочные и долгосрочные обязательства.

■ п. 69 МСФО (IAS) 1 «Представление финансовой отчетности»: Организация должна классифицировать обязательство как краткосрочное, когда:

■ (a) она предполагает урегулировать это обязательство в рамках своего обычного операционного цикла;

■ (b) она удерживает это обязательство преимущественно для целей торговли;

■ (c) это обязательство подлежит урегулированию в течение двенадцати месяцев после окончания отчетного периода; или

■ (d) у нее нет безусловного права отсрочить урегулирование обязательства по меньшей мере на двенадцать месяцев после окончания отчетного периода.

■ Организация должна классифицировать все прочие обязательства как долгосрочные.

В учетной политике организации фиксируется длительность операционного цикла.

Значение Длительность операционного цикла организации используется для выделения долгосрочных активов и обязательств в регламентированном и международном учетах.

Опция Деление на краткосрочные/долгосрочные активы и обязательства в учетной политике включает такое деление только для регламентированного учета.

Опция Деление на краткосрочные и долгосрочные активы и обязательства для международного учета находится в Международный финансовый учет – Настройки и справочники – Настройки формирования проводок.

Долгосрочные активы и обязательства выделяются на отдельных счетах. В рабочем месте Настройка счетов международного учета отдельно указываются краткосрочный и долгосрочный счета по объектам учета, где такое деление поддерживается.

Выделение долгосрочных активов и обязательств поддерживается для разделов учета:

■ Расчеты с клиентами;

■ Расчеты с поставщиками;

■ Расчеты по кредитам, займам и депозитам;

■ Расчеты по аренде (лизингу).

Определение счетов для проводок производится по данным оперативного контура на основании плановой даты погашения обязательства или выбытия актива. Плановая дата погашения/выбытия может содержаться в движениях учетных регистров или фиксироваться в виде графиков в отдельных регистрах.

При настройке корреспонденции объектов учета поддерживается выделение долгосрочных активов и обязательств через переключатель  указания срочности. Что позволяет задать счета дебета и кредита для объектов учета с делением на краткосрочные и долгосрочные.

Тип срочности пишется в списке корреспонденций в полях Объект учета Дт/Кт, Срок обращения.

На закладке Просмотр настроек по плану счетов для объектов учета, поддерживающих выделение долгосрочных активов и обязательств, в списке настроек в полях Объект учета Дт/Кт уточняется срочность, к которой относится настройка.

В конце каждого месяца на плане счетов формируются проводки по реклассификации долгосрочной задолженности/актива в краткосрочную регламентной операцией Реклассификация долгосрочных активов и обязательств в рабочем месте Закрытие месяца в группе этапов Международный учет.

Особенности алгоритма:

■ По данным финансовых регистров оперативного учета формируются проводки по переносу задолженностей с долгосрочных счетов на краткосрочные. При этом остатки регистра бухгалтерии не анализируются, в регистрах оперативного учета никаких движений не формируется.

■ Реклассификации в краткосрочную задолженность подлежат остатки, срок планового погашения которых на конец текущего месяца стал меньше длительности операционного цикла организации.

■ Для разделов учета Расчеты по кредитам, займам и депозитам и Расчеты по аренде производится реклассификация сумм поступлений с краткосрочных счетов на долгосрочные по данным графиков оплат. Реклассификации в долгосрочную задолженность подлежат поступления, срок планового погашения которых согласно графикам на момент поступления превышает длительность операционного цикла организации.

Особенности выделения долгосрочной части для аренды, кредитов, займов и депозитов:

■ Все движения всех документов по регистру Расчеты по финансовым инструментам отражаются изначально на краткосрочных счетах. Это ограничение из-за отсутствия в регистре даты планового.

■ Если актуальные графики оплаты поступивших в текущем периоде финансовых инструментов содержат платежи со сроками, превышающими длительность операционного цикла организации, то соответствующая часть поступления будет перенесена на долгосрочные счета регламентной операцией.

■ Выделение долгосрочных частей поступлений по графикам происходит независимо для каждого типа суммы расчетов по финансовым инструментам. Под поступлением финансовых инструментов подразумевается поступление предмета аренды, получение кредита, открытие депозита, выдача или получение займа.

■ Изменение графиков оплаты в процессе использования финансового инструмента не автоматизировано. Если такое изменение произошло и остаток на долгосрочном счете стал расходиться с данными графика, необходимо вручную выполнить перенос между долгосрочным и краткосрочным счетами документом Операция (международный учет).

Переход к раздельному учету по срочности активов и обязательств:

■ При установке в настройках формирования проводок признака деления активов и обязательств по срочности для уже существующих активов и обязательств будут формироваться проводки по долгосрочным счетам и выполняться операции реклассификации остатков в закрытии месяца. Начальные остатки для них потребуется ввести вручную документами Операция (международный учет).

■ Для того чтобы после начала деления активов и обязательств по срочности выделять на разных счетах только новые активы и обязательства, для них необходимо ввести в систему новые группы финансового учета (ГФУ) и указать в настройках разные счета учета долгосрочной и краткосрочных частей. Для уже существующих ГФУ, используемых в существующих активах и обязательствах, необходимо в настройках указать счета учета долгосрочных частей совпадающие с краткосрочными.

### Проводки по выручке

Для каждого плана счетов МФУ обеспечена возможность выбора варианта формирования проводок по выручке с НДС или без НДС.

Таким образом, возможны следующие варианты проводок по выручке (для удобства используются счета, аналогичные счетам регламентированного плана счетов):

Выручка / прочая выручка с НДС:

Дт 62.01 – Кт 90.01 – Сумма с НДС                     Дт 62.01 – Кт 91.01 – Сумма с НДС

Дт 90.03 – Кт 68.02 – Сумма НДС             Дт 91.02 – Кт 68.02 – Сумма НДС

Выручка / прочая выручка без НДС:

Дт 62.01 – Кт 90.01 – Сумма без НДС                 Дт 62.01 – Кт 91.01 – Сумма без НДС

Дт 62.01 – Кт 68.02 – Сумма НДС             Дт 62.01 – Кт 68.02 – Сумма НДС

В настройках формирования проводок указывается вариант формирования проводок по выручке с НДС или без НДС на конкретном плане счетов.

В рабочем месте по настройке счетов международного учета в зависимости от выбранной настройки формирования проводок скрываются неиспользуемые объекты учета выручки и НДС.

Все существующие настройки формирования проводок обеспечивают формирование проводок по выручке с НДС. При создании новых настроек формирования проводок устанавливается формирование проводок по выручке без НДС.

**Ограничение реализации**: Описываемая функциональность используется только при формировании проводок международного учета по данным оперативного учета с настройкой по объектам учета и их корреспонденциям.

При включении данного транслятора в элементе справочника Настройки формирования проводок становится доступен реквизит Проводки по выручке без НДС.

При выборе варианта настройки «Выручка без НДС» доступны объекты учета выручки без НДС, при этом объекты учета НДС с выручки отсутствуют.

При выборе варианта настройки «Выручка с НДС» доступны объекты учета выручки с НДС и НДС с выручки.

Ниже приведены примеры проводок документов по выручке без НДС:

■ Реализация с отложенным переходом права собственности.

■ Возврат товаров от клиента.

### Переход к трансляции по объектам учета из других способов

Если ранее в системе уже использовался международный финансовый учет, то имеются действующие настройки отражения по оперативному учету по хозяйственным операциям или (а возможно и совместно) по соответствиям счетов и оборотов международного и регламентированного учетов.

В настройке трансляции по объектам учета используется тот же план счетов, что и в других способах настройки формирования проводок, поэтому переход на новый транслятор возможен с ближайшего открытого периода. Даты перехода в настройках опций нет, поэтому вносить изменения в закрытые периоды не рекомендуется.

Для перехода на новый механизм формирования проводок в информационной базе не должны использоваться устаревшие механизмы:

■ Партионный учет 2.1;

■ Учет ВНА 2.2;

■ Производство 2.1;

■ Офлайн расчеты с партнерами.

Документы будут отражаться по новым правилам, что при итерациях уточнений настроек может дать изменение финансового результата, который был ранее, если переотражать операции прошлых периодов. Также нужно учесть, что по прошлым периодам может не быть в системе двойной записи оперативных регистров, необходимой для трансляции по объектам учета. Закрытие месяца предпринимает попытку восстановления двойной записи, но срабатывает восстановление не всегда, и могут быть ситуации, когда нужно будет перепроводить документы.

Если уже использовалась настроенная модель по соответствиям счетов международного и регламентированного учетов, можно начать настройку уточнения счетов по группам финансового учета для объектов учета, ориентируясь на настройку счетов регламентированного учета в ГФУ, и указывать счета МФУ из соответствий счетов.

В случае использования шаблонов проводок по хозяйственным операциям можно проверять уточнение счетов по ГФУ.

В общем случае при настройке счетов полезно использовать отборы по типу субконто при выборе счета и поиск счетов по части наименования. Обычно у счетов плана счетов смысловые названия, на которые также можно ориентироваться при заполнении настроек отражения по объектам учета.

Если после указания счетов в настройке отражения по объектам учета система не может заполнить субконто автоматически, то возможно нужно уточнить состав субконто на счете, либо уточнить заполнение субконто по гиперссылке Настройка заполнения субконто.

Отражение в учете по новым правилам требует заполнения идентификаторов записи в оперативных регистрах. Это заполнение работает, начиная с редакции 2.5. При переходе на нее с редакции 2.4 по историческим данным этой информации нет. Переход на новый режим отражения в МФУ может быть только с текущих периодов, в которых можно документы переотразить в учете, либо, возможно, учет уже ранее велся в редакции 2.5, и связи регистров заполнялись.

Дальнейшая поддержка механизма трансляции по оборотным регистрам Настройка по хозяйственным операциям будет ограничена. Не будут поддерживаться отражение новых хозяйственных операций, добавляемых при развитии системы, и исправление текущих исторических ограничений (мест, где не хватало оборотных регистров), которые покрываются возможностями нового подхода.

В текущей реализации трансляции по объектам учета сохраняются ограничения формирования проводок, которые ранее были при трансляции в МФУ по хозяйственным операциям. Двойная запись в финансовых регистрах не поддерживается в блоках:

■ Переданная и принятая возвратная тара;

■ Подарочные сертификаты («старая» версия);

■ «Сложный» учет НДС (включение/исключение НДС из стоимости товаров). При распределении НДС двойная запись поддерживается.

Такие документы не будут отражены в учете автоматически – потребуется ручное формирование проводок. После ручного отражения документов, у которых нет двойной записи регистров оперативного учета, в МФУ такие документы пропадут из перечня ошибок при проверке закрытия месяца, и период будет считаться закрытым.

Если по какой-то причине требуется перезакрыть прошлые периоды, в которых не было двойной записи в оперативном учете, где невозможно выполнить полноценное перепроведение документов для восстановления парности регистров, но уже включено отражение в МФУ по объектам учета, то следует переключить отражение в МФУ обратно на старые режимы, закрыть прошлые периоды по старым правилам МФУ и включить отражение по объектам учета для будущих периодов.

**Важно**: Настройка трансляции по объектам учета и их корреспонденциям является единственно возможным способом для ведения учета операций аренды и лизинга, а также некоторых операций производства по данным оперативного учета.

## Настройка трансляции по хозяйственным операциям оперативного учета

### Настройка по хозяйственным операциям

Настройка шаблонов проводок проводится в рамках рабочего места Международный финансовый учет – Настройки и справочники – Настройка шаблонов проводок (международный учет). Настройка осуществляется в двух режимах:

■ От хозяйственной операции к шаблонам проводок с дальнейшим указанием счетов. При этом можно создать новый шаблон проводки, а также возможны дополнительные действия:

○ включение/исключение шаблона из учетной политики;

○ исключение/включение хозяйственной операции в учетную политику.

■ От плана счетов к шаблонам проводок и далее к уточнению в шаблоне хозяйственной операции и корреспонденции счетов. При этом нельзя создать новый шаблон проводки, но можно включить/исключить существующий шаблон из учетной политики. В данном режиме при помощи фильтра можно отобрать несбалансированные настройки проводок, когда для выбранного счета созданы шаблоны для движений только по дебету или только по кредиту.

В процессе работы из раздела с настройками учета по хозяйственным операциям можно осуществить:

■ переход в отчеты об ошибках при настройке шаблонов проводок;

■ просмотр исключенных из обработки хозяйственных операций.

Настройка конкретного шаблона проводки состоит из следующих основных действий:

■ указание счета по умолчанию для дебета и кредита проводки;

■ указание источника уточнения счетов;

■ указание источника заполнения поля Подразделение;

■ выбор источника направления деятельности;

■ указание источника валютной суммы;

■ указание источника количества;

■ выбор источника суммы для проводки;

■ установка дополнительных отборов к данным по хозяйственной операции в качестве условий применения шаблона.

Шаблоны проводок, настроенные по одной хозяйственной операции, могут быть объединены в группы с установленными дополнительными отборами и вариантом их совместного применения:

■ применять первый в порядке следования в группе шаблон, удовлетворяющий критериям дополнительных отборов;

■ применять все шаблоны, входящие в группу.

Такой подход позволяет, например, разделить настройку проводок по учету движений комиссионного и собственного товара.

Далее производится настройка уточнения счетов по группам финансового учета, проверить которую можно с помощью отчета Ошибки уточнения счетов. Отчет показывает шаблоны проводок, в которых могут быть неверно указаны уточняющие счета.

Процесс настройки шаблонов проводок состоит из нескольких этапов:

■ формирование списка шаблонов проводок по хозяйственным операциям;

■ проверка целостности (сбалансированности) настройки счетов, используемых в шаблоне по умолчанию;

■ проверка счетов, уточняемых в шаблоне с помощью групп финансового учета, и других настроек.

Работа начинается в рабочем месте Настройка шаблонов проводок (международный учет) (Международный финансовый учет – Отражение документов в международном учете – Настроить шаблоны проводок). В режиме По хозяйственным операциям осуществляется основная настройка шаблонов проводок в зависимости от той или иной выбранной хозяйственной операции. Сортировка и отбор по признаку настроенных шаблонов позволяют выявить те операции, где еще требуется настройка.

Хозяйственные операции, по которым настройка шаблонов не требуется, маркируются как исключенные из учетной политики. Иначе такие хозяйственные операции будут попадать в журнал ошибок в момент формирования проводок как не имеющие настроенных шаблонов проводок.

Режим По плану счетов используется для анализа и уточнения настроек.

Удобно вести настройку шаблонов по замкнутой цепочке процессов, например «продажа – оплата – возвраты».

По мере задания счетов по умолчанию в шаблонах при необходимости также настраиваются опции уточнения счетов через группу финансового учета. Справочники групп финансового учета пополняются в зависимости от необходимости добавления в настройку шаблона уточняющих счетов.

Сценарий работы в форме Шаблон проводки:

■ Указание счетов дебета и кредита проводки по умолчанию.

■ Выбор источника уточнения счетов дебета и кредита.

■ Выбор источника балансовой суммы.

■ Выбор источника заполнения подразделения для дебета и кредита.

■ Выбор источника валютной суммы для счетов, имеющих признак валютного учета.

■ Выбор источника количества для счетов, на которых ведется количественный учет.

■ Переход к уточнению счетов по группе финансового учета с возможностью:

○ уточнения счета по списку групп финансового учета в справочнике;

○ создания новой группы финансового учета в справочнике;

○ перехода к форме Настройка уточнения счета для шаблона проводки, выбора какой-либо группы финансового учета и просмотра списка всех шаблонов проводок, использующих данную группу в своих настройках.

■ Установка флажка Ручное уточнение проводки (при необходимости).

■ Настройка дополнительных отборов (при необходимости).

■ Установка флажка Изменять знак операции при отражении в учете – в том случае, если проводку по данному шаблону следует отражать в учете с обратным знаком.

■ Указание соответствия субконто счетов данным оперативного учета или фиксированным значениям на закладке Заполнение субконто (при необходимости).

■ Установка флажка Не отражается в международном учете в случае необходимости исключить из учета не всю хозяйственную операцию целиком, а один из настроенных шаблонов, разделяемых дополнительными отборами.

■ Использование поля Описание для записи произвольных комментариев.

После завершения настройки шаблонов проводок, относящихся к ряду взаимосвязанных хозяйственных операций, необходимо проанализировать логику и целостность сделанных настроек.

Для этой цели предусмотрен отчет Ошибки настройки шаблонов проводок, в котором для сужения фокуса анализа можно применять отборы по группам финансового учета и счетам по умолчанию, а также использовать возможности отбора по иерархии справочников. Система информирует об ошибке, когда при каком-либо счете (как выбранном по умолчанию, так и уточненном через группу финансового учета) созданы шаблоны, отражающие движение только по дебету или только по кредиту данного счета.

Отчет Ошибки уточнения счетов показывает предполагаемые ошибки, допущенные в шаблонах проводок при работе с группами финансового учета. Отчет имеет дополнительные критерии отбора по счету и группе. Система информирует об ошибке настройки счетов, когда в разных шаблонах проводок, созданных при одном счете по умолчанию, для одной группы финансового учета по-разному настроены уточняющие счета.

Итерации ввода шаблонов и уточнения счетов по группе финансового учета повторяются до полного ввода шаблонов проводок.

По окончании настройки шаблонов проводки международного учета могут быть сформированы следующим образом:

■ в автоматическом режиме по списку документов после запуска алгоритма отражения проводок в рабочем месте Международный финансовый учет – Отражение документов в международном учете;

■ в отдельно выбранном документе оперативного учета в следующей последовательности: Проводки международного учета – Отразить в международном учете.

При этом алгоритм формирования проводок выявляет хозяйственные операции, для которых шаблоны проводок не созданы или требуют исправления.

Далее из списка документов, требующих настройки шаблонов, можно перейти в форму Настройка шаблонов проводок либо построить отчеты по выявленным ошибкам.

### Ограничения трансляции по хозяйственным операциям

В текущей реализации трансляции по хозяйственным операциям есть ограничения формирования проводок для операций по учету:

■ производства;

■ передачи в переработку;

■ аренды (лизинга) по ФСБУ 25/2018 «Бухгалтерский учет аренды».

Рекомендуется отражать данные операции методами трансляции по объектам учета и их корреспонденциям или по данным регламентированного учета.

Дальнейшая поддержка механизма трансляции по оборотным регистрам Настройка по хозяйственным операциям будет ограничена. Не будут поддерживаться отражение новых хозяйственных операций, добавляемых при развитии системы, и исправление текущих исторических ограничений (мест, где не хватало оборотных регистров), которые покрываются возможностями способа формирования проводок по объектам учета и их корреспонденциям. Рекомендуется переходить на данный способ учета.

### Примеры настройки шаблонов проводок МФУ по данным оперативного учета

Настройка осуществляется при помощи рабочего места Международный финансовый учет - Настройки и справочники - Настройка формирования проводок по данным опер. учета - Настройка шаблонов проводок (международный учет) или Международный финансовый учет – Отражение документов в международном учете – Настроить шаблоны проводок - Настройка шаблонов проводок (международный учет).

Настройка выполняется на закладке По хозяйственным операциям формы рабочего места Настройка шаблонов проводок в зависимости от той или иной выбранной хозяйственной операции. При помощи кнопки  табличной части Хозяйственные операции при выборе команды Настроить список можно осуществить сортировку и отбор по признаку настроенных шаблонов, что позволяет выявить операции, где еще требуется настройка.

Хозяйственные операции, по которым настройка шаблонов проводок не требуется, маркируются как исключенные из учетной политики кнопкой  Исключить хозяйственную операцию из учетной политики. При необходимости исключенную из учетной политики хозяйственную операцию можно включить снова кнопкой  Включить хозяйственную операцию в учетную политику.

При формировании проводок МФУ по данным оперативного учета субконто заполняются из подходящих значений источника (регистра) автоматически. Для "ручного" указания соответствия субконто счетов данным оперативного учета в форме шаблона проводки есть закладка Заполнение субконто (Автоматически). Необходимо включить Расширенную настройку заполнения субконто и указать правила заполнения субконто.

**Настройка шаблонов проводок по хозяйственной операции «Оплата поставщику»**

Рассмотрим в качестве примера создание двух шаблонов проводок (далее ШП) Оплата аванса поставщику и Оплата поставщику для хозяйственной операции Оплата поставщику.

В форме Настройка шаблонов проводок находим при помощи поиска данных в списке хозяйственную операцию Оплата поставщику и создаем на основании хозяйственной операции шаблон проводки при помощи кнопки Создать.

В заголовке новой формы шаблона проводки указываем наименование Оплата поставщику, название хозяйственной операции Оплата поставщику задается в шаблоне автоматически.

Затем в форме ШП указываем счета, которые будут использоваться по умолчанию для дебета и кредита проводки. Счетов по умолчанию бывает недостаточно для правильного формирования проводок, так как один и тот же ШП может использоваться в разных ситуациях, например: покупка товара у внутригрупповой компании или у внешнего поставщика, или оплата товара наличными или безналичными денежными средствами. Для таких случаев в качестве источников уточнения счетов в шаблоне проводки выбираются Группы финансового учета (далее ГФУ).

Группы финансового учета - это классификация активов, обязательств, доходов, расходов для цели отражения в бухгалтерском (финансовом) учете. Существует пять видов ГФУ:

■ Группы финансового учета денежных средств;

■ Группы финансового учета расчетов;

■ Группы финансового учета доходов/расходов;

■ Группы настроек финансового учета номенклатуры;

■ Группы финансового учета внеоборотных активов.

Все ГФУ находятся в разделе Международный финансовый учет – Настройки и справочники – Группы финансового учета, кроме Групп финансового учета внеоборотных активов, которые находятся в разделе Внеоборотные активы – Настройки и справочники.

В настраиваемом для примера ШП Оплата поставщику мы выбираем для дебета группу финансового учета расчетов и для кредита группу финансового учета денежных средств.

Для уточнения счетов после сохранения шаблона проводки нужно пройти по гиперссылкам Настроить уточнение счета Дт и Настроить уточнение счета Кт и выбрать из списка группы финансового учета в справочнике, либо создать новую ГФУ при необходимости.

Группы финансового учета определяют счета проводок международного финансового учета, что проиллюстрировано ниже на схеме с примером.

При оплате поставщику основного средства в документе Списание безналичных денежных средств указывается в качестве Объекта расчетов документ Приобретение услуг и прочих активов, в котором выбрана группа финансового учета расчетов ОС и объекты капитального строительства.

В форме банковского счета организации можно выбрать ГФУ Безналичные ДС на расчетных (транзитных) счетах в банках.

Таким образом, при формировании проводки МФУ используются счета, соответствующие выбранным группам финансового учета:

Дт 57510 Расчеты по покупке основных средств

Кт 28520 Счета в банках.

Проводки МФУ могут формироваться в проведенном документе оперативного учета в любой момент времени независимо от регламентированного учета при помощи кнопки Отразить в международном учете в форме просмотра проводок Проводки международного учета. Если требуется предварительный расчет себестоимости, то проводка сформируется в рамках регламентной процедуры закрытия месяца.

В данную форму можно перейти по кнопке  из документа, или с использованием рабочего места Международный финансовый учет - Отражение документов в международном учете.

Отразить документы в МФУ можно в произвольное время, в заданное по расписанию время или в конце месяца в составе регламентных операций по закрытию месяца в международном учете.

Также при настройке ШП Оплата поставщику можно выбрать Источник подразделения для дебета и кредита.

Для счетов, имеющих признак валютного учета, настраиваем Источники валютной суммы.

Также есть возможность настроить Источник направления деятельности для дебета и кредита.

Затем выбираем Источник балансовой суммы, который будет определять сумму проводки. При покупке товара возможны различные варианты оплаты. ШП Оплата поставщику будет использоваться для отражения в МФУ оплаты после поступления товара, поэтому выбираем из списка Сумму постоплаты.

Поле Описание можно использовать для записи произвольных комментариев.

Завершающим шагом в настройке шаблона проводки является включение его в учетную политику. Данное действие необходимо, если в форме настройки шаблонов проводок не была выбрана учетная политика. Иначе шаблон включится в выбранную учетную политику автоматически при сохранении.

В рабочем месте Настройка шаблонов проводок появляется включенный в учетную политику ШП Оплата поставщику (об этом говорит значок  напротив ШП) . Далее при необходимости можно исключить шаблон из учетной политики кнопкой  Исключить из учетной политики или включить снова кнопкой  Включить в учетную политику.

Общий порядок настройки шаблона проводки по оплате аванса поставщику такой же, как и порядок настройки шаблона проводки по оплате поставщику.

Ниже приведены особенности настройки ШП Оплата аванса поставщику.

Выбираем другой счет по умолчанию для дебета проводки 22031 Краткосрочные авансы выданные – третьи лица и уточняем счета учета при необходимости.

Выбираем Источник балансовой суммы. Использование в настройках разных источников балансовой суммы позволяет создавать для одной хозяйственной операции несколько шаблонов проводок с разной корреспонденцией счетов. Данный ШП будет использоваться для отражения в МФУ оплаты до поступления товара (предоплаты), поэтому выбираем из списка Сумму предоплаты.

На основании ШП формируется проводка по оплате аванса поставщику.

В данном примере мы рассмотрели возможность настройки двух шаблонов проводок на основании одной хозяйственной операции при помощи выбора разных источников балансовой суммы.

**Настройка шаблонов проводок по хозяйственной операции «Перечисление налога»**

При необходимости уточнения условий применения шаблона в ШП можно устанавливать дополнительные отборы к данным по хозяйственной операции. Рассмотрим в качестве примера создание разных шаблонов проводок по хозяйственной операции Перечисление налога.

Настроим семь шаблонов проводок по уплате налогов. В данном случае количество шаблонов определяется количеством субсчетов, открытых к счету 54000 Краткосрочные обязательства по налогам на Международном плане счетов (Международный финансовый учет – Настройки и справочники).

В форме настройки шаблона проводки Оплата задолженности по НДФЛ на закладке Настройка счетов выбираем счета для дебета и кредита:

Дт 54060 Краткосрочные обязательства по Налогу НДФЛ

Кт 28520 Счета в банках

Эти счета заданы по умолчанию и настраивать их уточнение не требуется. Выбираем Источник балансовой суммы – Сумма. Источник подразделения для дебета и кредита заполняется по умолчанию – Хозяйственная операция. Счет 28520 имеет признак валютного учета, поэтому выбираем Источник валютной суммы для кредита – Сумма в валюте.

В форме шаблона на закладке Дополнительный отбор добавляем новый элемент Статья движения денежных средств с Видом сравнения Равно и выбираем из справочника статью движения денежных средств Оплата НДФЛ.

Данная статья движения денежных средств выбирается в документе Списание безналичных денежных средств.

По настроенному шаблону формируется проводка МФУ.

Таким же способом можно создать остальные шаблоны проводок по уплате налогов и взносов, используя Дополнительный отбор по Статье ДДС.

Есть возможность также шаблоны объединить в группу, где можно задать вариант совместного применения шаблонов:

■ Первый в порядке следования шаблон проводки, удовлетворяющий условиям дополнительного отбора;

■ Все шаблоны проводок, входящие в группу.

Для нашего примера подходит второй вариант совместного применения шаблонов. Также дополнительный отбор можно установить на уровне группы.

Данные по оплате налогов и взносов отражаются в отчете Оборотно-сальдовая ведомость. Пробный баланс (международный учет) с необходимой детализацией по субсчетам МФУ (Международный финансовый учет – Отчеты по международному учету).

## Настройка трансляции операций из регламентированного учета

Помимо настройки по данным оперативного учета проводки в международном финансовом учете могут быть получены путем трансляции данных регламентированного учета.

Данный способ ведения учета заключается в настройке соответствий счетов и оборотов регламентированного учета счетам и оборотам международного учета, которые представляют собой правила трансляции данных, и последующем отражении проводок в международном финансовом учете согласно созданным правилам.

Форма Настройка соответствия счетов и оборотов становится доступной из рабочего места Отражение документов в международном учете – Настроить соответствие счетов и оборотов или раздела Международный финансовый учет – Настройки и справочники – Настройка формирования проводок по данным регл. учета после установки функциональной опции Проводки по данным регламентированного учета в разделе НСИ и администрирование – Настройка НСИ и разделов – Международный финансовый учет.

При создании правил трансляции существует возможность настройки:

■ соответствий счетов и субконто регламентированного учета счетам и субконто международного учета;

■ соответствий оборотов по корреспонденциям счетов одного учета оборотам другого учета с указанием дополнительных отборов по субконто;

■ группировок соответствий оборотов, а также способа их совместного применения при отражении проводок.

Следует отметить, что правила соответствия оборотов имеют более высокий приоритет, чем правила соответствия счетов. Это означает, что к проводке, для которой задано соответствие оборотов, не будут применяться правила соответствия счетов. Кроме того, существует возможность игнорировать (не транслировать) выбранные счета или обороты регламентированного учета при отражении данных в международном учете.

В настройке соответствия счетов регламентированного и международного учетов установлена связь счетов по значению реквизита Забалансовый. Нельзя указать и записать настройку соответствия счетов с различающимися значениями этого реквизита.

В настройке соответствия оборотов регламентированного и международного учетов установлена связь счетов по значению реквизита Забалансовый. Нельзя указать и записать настройку соответствия оборотов с различающимися значениями этого реквизита. Для забалансовых счетов не обязательно указание корреспондирующего счета.

При установке функциональной опции Проводки по данным регламентированного учета необходимо соблюдение последовательности отражения документов: сначала формирование проводок в регламентированном учете, а потом – в международном. Иначе документы будут помечаться как ожидающие проведения в регламентированном учете и в международном учете не отразятся.

При трансляции данных из оперативного управленческого контура в качестве источника данных может выступать сумма по управленческому учету. Если установлена опция Управленческий учет на плане счетов регламентированного учета, то для трансляции используется сумма управленческого учета. Если опция не установлена, то для трансляции используется сумма регламентированного учета, пересчитанная в управленческой валюте на дату операции.

Использование механизма трансляции операций не исключает возможности работы с документами оперативного учета. Таким образом, проводки в международном учете могут быть получены как по шаблонам, настроенным для хозяйственных операций, так и с применением правил трансляции. Во избежание конфликтных ситуаций при использовании сразу двух режимов необходимо настроить игнорирование хозяйственных операций для оперативного учета или игнорирование оборотов регламентированного учета. В противном случае возможно «задвоение» проводок в международном учете.

## Учет внеоборотных активов по данным оперативного учета

Поддерживается учет внеоборотных активов по данным оперативного учета, когда на основании одного документа движения ОС и НМА в оперативном учете можно сформировать проводки по правилам РСБУ и МСФО. Таким образом, удается избежать двойного ввода документов в случае сближения регламентированного и международного учетов.

В разделе Внеоборотные активы доступны все документы для отражения движения и учета внеоборотных активов в регламентированном, международном и управленческом видах учета.

Подробнее об учете ОС и НМА можно прочитать в главе [Внеоборотные активы](/db/erp25doc/bookmark/capitalassets/CapitalAssets).

Внеоборотные активы принимаются к учету документами Принятие к учету ОС и Принятие к учету НМА, при этом сохраняется возможность независимого принятия к учету: активы могут быть приняты (или не приняты вовсе) в разные периоды, иметь разный срок полезного использования и режим начисления амортизации

Кроме принятия к учету документы позволяют отражать в международном учете следующие действия с объектами основных средств и нематериальных активов:

■ изменение параметров учета,

■ начисление амортизации,

■ перевод основных средств в состав инвестиционного имущества и обратно,

■ модернизация ОС,

■ проведение переоценки (дооценки и уценки) ОС,

■ перемещение объектов,

■ списание объектов,

■ объединение ОС,

■ разукомплектация ОС,

■ ввод остатков внеоборотных активов.

Учет капитальных затрат по приобретению или самостоятельному созданию (разработке) объектов ОС и НМА осуществляется при помощи документов оперативного учета:

■ Приобретение товаров и услуг с хозяйственной операцией Закупка у поставщика;

■ Внутреннее потребление товаров с хозяйственной операцией Списание на расходы/активы;

■ Приобретение услуг и прочих активов.

При капитализации затрат на ОС и НМА суммы, фиксируемые в регламентированном и управленческом учетах, могут отличаться за счет различной трактовки затрат и себестоимости потребляемых материалов.

При отражении в учете капитальных вложений, связанных с приобретением (созданием) объектов ОС или НМА, в справочниках Основные средства/Нематериальные активы и расходы на НИОКР задаются основные реквизиты соответствующих объектов учета. В частности, одним из таких реквизитов является Группа ОС (Группа НМА/НИОКР) для целей международного финансового учета.

При принятии к учету ОС или НМА в документах с одноименным названием на вкладке Параметры учета указываются следующие параметры учета объекта:

■ порядок учета (начислять амортизацию, не начислять амортизацию, амортизация начислена, не принимать к учету, включить в расходы);

■ параметры начисления амортизации: метод начисления, срок полезного использования в месяцах;

■ группа финансового учета.

На вкладке Основные средства указываются предварительная первоначальная стоимость и ликвидационная стоимость, на закладке Отражение расходов нужно указать статью расходов для начисления амортизации и аналитику расходов.

Указанные выше параметры учета по выбранным объектам основных средств или нематериальных активов могут быть изменены специальными документами Изменение параметров ОС (НМА). При этом действие новых параметров начинается с даты документа и продолжается до вновь созданного изменения параметров учета или выбытия (списания) объектов (если выбрана соответствующая опция в учетной политике финансового учета).

Для расчета и отражения в учете суммы амортизационных отчислений по принятым к учету ОС и НМА используются документы Амортизация ОС (НМА).

В ситуации, когда организацией планируется использование объектов основных средств, относящихся к группе земельных участков и зданий, для получения арендного дохода или дохода в виде прироста балансовой стоимости объектов, такая недвижимость должна быть отнесена к категории инвестиционного имущества. С этой целью в документе Принятие к учету ОС нужно выбрать соответствующую Группу финансового учета.

Перевод земельных участков и зданий из категории инвестиционного имущества в состав основных средств и наоборот, выполняется документом Изменение параметров ОС также при помощи выбора необходимой Группы финансового учета.

Перемещение объектов ОС или НМА между подразделениями организации и их списание отражаются в учете документами Перемещение ОС (НМА) и Списание ОС (НМА) соответственно.

В оперативном учете есть два независимых ресурса для регистрации сумм в управленческой и регламентированной валютах. Валюты могут совпадать или отличаться. Суммы в управленческой и регламентированной валютах могут отличаться даже при совпадающей валюте из-за разных правил распределения (признания) расходов.

Проводки МФУ могут формироваться по данным оперативного или регламентированного учетов разными способами по объектам учета и их корреспонденциям, при помощи настроенных шаблонов проводок (данный способ не является рекомендуемым, см. статью [Переход к трансляции по объектам учета из других способов](/db/erp25doc/bookmark/ifrsreporting/AccountingObjectInit)) или шаблонов соответствий счетов/оборотов. Это накладывает ограничение на выбор валюты для функциональной валюты МФУ.

В общем случае в документах ОС и НМА могут вестись три учета:

■ регламентированный;

■ управленческий;

■ по МСФО.

Но только два учета могут вестись одновременно, так как существуют всего два ресурса для учета. Какие-то два учета должны совпадать:

■ регламентированный и международный вместе + управленческий независимо (в таком случае учет ВНА в регламентированном и международном учетах будет совпадать);

■ регламентированный независимо + международный и управленческий вместе (при таком использовании в МФУ возможен независимый учет внеоборотных активов).

В разделе НСИ и администрирование – Настройка НСИ и разделов – Международный финансовый учет при настройке плана счетов необходимо выбрать функциональную валюту и валюту представления. Валюта представления может быть любой, без ограничений. Функциональная валюта может совпадать с валютой регламентированного или управленческого учетов.

Если нужен отдельный учет ОС и НМА по МСФО, то в поле Функциональная валюта должно быть выбрано значение В валюте упр. учета и необходимо использовать рубли, как национальную валюту, для управленческого учета.

Таким образом, особенностью реализации в МФУ является ограничение на выбор ресурса для функциональной валюты:

■ Если включена функциональная опция НСИ и администрирование – Настройка НСИ и разделов – Международный финансовый учет – Проводки по данным оперативного учета, то для функциональной валюты будет доступен выбор: В валюте регламентированного учета организаций или В валюте управленческого учета.

■ Если включена функциональная опция НСИ и администрирование – Настройка НСИ и разделов – Международный финансовый учет – Проводки по данным регламентированного учета, то доступен один вариант при выборе функциональной валюты – В валюте регламентированного учета организаций.

■ Если включены обе опции, то для функциональной валюты будет доступен выбор: В валюте регламентированного учета организаций или В валюте управленческого учета.

При этом:

■ Если использовать валюту управленческого учета, то внеоборотные активы будут вестись независимо от регламентированного учета (регламентированный независимо + международный и управленческий вместе).

■ Если использовать валюту регламентированного учета организаций, то независимого учета внеоборотных активов по МСФО не будет, так как для МФУ будет использоваться ресурс сумм регламентированного учета (регламентированный и международный вместе + управленческий независимо).

Также валюта управленческого учета, а не регламентированного учета организаций может выбираться из-за разных правил признания расходов в управленческом и регламентированном учетах.

Бухгалтерские проводки МФУ формируются в отложенном режиме документами ОС и НМА на определенном этапе закрытия месяца или при помощи соответствующего регламентного задания.

В разделе Внеоборотные активы – Настройки и справочники есть справочник Группы финансового учета внеоборотных активов, по которым можно уточнять счета для МФУ.

**Ограничение**: способ формирования проводок по объектам учета и их корреспонденциям является единственно возможным для ведения учета операций аренды и лизинга.

## Закрытие месяца

Закрытие месяца осуществляется в рабочем месте Финансовый результат и контроллинг – Закрытие месяца.

Используя помощник закрытия месяца, есть возможность:

■ контролировать наличие документов оперативного учета, ожидающих отражения в международном учете;

■ проверять ранее выполненные и создавать новые регламентные операции по расчету курсовых разниц, закрытию счетов учета доходов и расходов и формированию финансового результата.

Этапы для МФУ сгруппированы и идут в конце списка этапов закрытия месяца после всех операций закрытия оперативного и регламентированного учетов.

Происходит отражение документов в учете. Подробнее см. [Отражение документов в учете](/db/erp25doc/bookmark/ifrsconcepts/ReflectionPapersInAccounting).

Далее формируются проводки по курсовым разницам, возникшим по валютным счетам.

Настройка счетов, на которых в проводках по курсовым разницам в функциональной валюте будет отражаться прибыль (убыток) от операций, осуществляется в левой части формы Настройка учета курсовых разниц, доступной в Настройке формирования проводок или по ссылке из рабочего места настройки проводок по данным оперативного или регламентированного учета.

Следует отметить, что при необходимости валютные счета могут быть исключены из расчета курсовых разниц. Для этого в плане счетов «Международный» для выбранного счета требуется установить флажок Исключить из расчета курсовых разниц в функциональной валюте. Данный счет автоматически добавится в список счетов, исключаемых из переоценки в рабочем месте Настройка учета курсовых разниц. И наоборот: если добавить данный счет в список исключаемых из переоценки счетов в рабочем месте, то в карточке счета флажок установится автоматически. При этом данное исключение будет применено для всех существующих настроек формирования проводок. Если же добавить счет в список счетов, исключаемых из переоценки в валюте представления, то данное исключение будет применено только к данной настройке формирования проводок. Область применения настроек исключений из расчета курсовых разниц ограничивается только регламентными операциями МФУ Расчет курсовых разниц в функциональной валюте и Расчет курсовых разниц в валюте представления и не распространяется на операции расчета курсовых разниц в оперативном учете.

Следующим этапом закрытия месяца по МФУ является закрытие оборотов счетов учета доходов и расходов, которое выполняется в два шага:

■ Закрытие счетов доходов и расходов от продолжающихся операций (группы 60000 и 70000) в два итоговых счета учета прибыли или убытка до налогообложения (67500 и 77500).

■ Формирование финансового результата, включающее закрытие счетов учета:

○ прибыли (убытка) от продолжающихся операций до налогообложения (67500 и 77500);

○ прибыли (убытка) от прекращаемой деятельности (68500, 78500);

○ операций по налогу на прибыль (78010 и 78020) в счет нераспределенной прибыли (убытка) текущего периода (31010).

Подбор соответствующих счетов и вариантов их закрытия осуществляется в перечне Настройка закрытия периода из Настройки формирования проводок.

 

Или по ссылке из рабочего места настройки проводок по данным оперативного или регламентированного учета.

Форма настройки счетов закрытия периода.

Результатом выполнения регламентной операции Закрытие счетов учета доходов и расходов является создание одноименного документа, отражающего проводки по формированию финансового результата текущего периода.

Организациям, функциональная валюта которых отличается от валюты представления отчетности, необходимо на заключительном этапе закрытия месяца выполнить перевод активов и обязательств, а также результатов своей работы в валюту представления. Для этого в помощнике закрытия месяца в международном учете предусмотрена регламентная операция Расчет курсовых разниц в валюте представления.

Созданные закрытием месяца документы доступы в списке Международный финансовый учет – Финансовый учет – Регламентные документы.

По завершении процесса закрытия месяца установка даты запрета формирования проводок возможна непосредственно из помощника закрытия месяца или в рабочем месте Международный финансовый учет – Отражение документов в международном учете.

## Проверка финансовых документов

В системе есть возможность формировать проводки международного учета только после проверки документа. Проверка включается на панели Финансовый результат и контроллинг, а для цели МФУ – при настройке управления параметрами международного финансового учета.

При использовании проверки «с запретом редактирования» после проверки документ блокируется для изменения.

В журнале документов МФУ можно управлять статусом проверки документов.

По ссылкам открывается журнал документов с соответствующими отборами по организации и периоду.

## Контроль ведения учета и формирование отчетности

Контроль ведения учета осуществляется с помощью стандартных отчетов финансового учета: оборотно-сальдовых ведомостей, карточек счетов и т. п.

В конце отчетного периода производится обновление немонетарных показателей на их актуальные значения.

После завершения отражения всех операций в учете проводится формирование финансовой отчетности в соответствии с настроенным комплектом отчетов.

Подробнее про отчеты см. разделы [Отчеты по международному финансовому учету](/db/erp25doc/bookmark/ifrsreports/IFRSReports) и [Генератор финансовых отчетов](/db/erp25doc/bookmark/financialreportsgenerator/FinancialReportsGenerator).
