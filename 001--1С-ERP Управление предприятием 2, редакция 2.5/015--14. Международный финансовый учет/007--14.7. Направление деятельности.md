# Направление деятельности

В международном финансовом учете есть возможность вести учет по направлениям деятельности доходов, затрат, внеоборотных активов, денежных средств, обособлению товаров и работ. Для этого необходимо:

■ установить функциональную опцию НСИ и администрирование – Настройка НСИ и разделов – Финансовый результат и контроллинг – Финансовый результат – Финансовый результат по направлениям деятельности;

■ в элементах списка Финансовый результат и контроллинг – См. также – Направления деятельности разрешить ведение учета хотя бы по одному из разделов.

Измерение Направление деятельности заполняется в проводках МФУ значениями одноименного справочника при помощи трансляторов оперативного и регламентированного учетов.

В карточке счета международного плана счетов есть признак учета по направлениям деятельности.

Заполнение направления деятельности по данным регламентированного учета дополнительных настроек не требует и будет перенесено в МФУ их бухгалтерских проводок регламентированного учета по соответствию сторон Дт и Кт счетов.

При трансляции данных из оперативного учета при использовании настроек по объектам учета и их корреспонденции для заполнения направлений деятельности не нужны настройки, направление будет заполняться автоматически из данных оперативного учета, если по объекту учета ведется учет по направлениям деятельности.

Для трансляции данных в МФУ по хозяйственным операциям требуется настройка источника направления данных. В форме шаблона проводки нужно выбрать источник заполнения проводок МФУ данными по направлению деятельности.

В результате проводки сформируются с указанием данного измерения.

В генераторе финансовых отчетов для видов финансовых отчетов есть возможность использования измерения Направление деятельности для настройки отчетов по данным обоих планов счетов: бухгалтерского и международного учетов. При формировании отчета можно настроить отбор по направлениям деятельности.

В стандартных отчетах по международному финансовому учету также настраиваются отборы и группировки по данному измерению.

В подсистеме Бюджетирование и планирование при создании Правила получения фактических данных по статьям бюджетов есть возможность использовать аналитику Направление деятельности для настройки дополнительных отборов, если при этом используется раздел источника данных Международный учет.
