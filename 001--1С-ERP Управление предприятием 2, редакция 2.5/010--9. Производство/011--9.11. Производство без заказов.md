# 9.11. Производство без заказов

_Source: about:srcdoc_

# Производство без заказов

Документ Производство без заказа предназначен для отражения производства продукции или работ и списания материалов с баланса складов и цеховых кладовых, а также работ с баланса подразделений, и их отнесения на выпущенную продукцию.

Помимо материалов и работ в документе указываются выполненные работы сотрудников (трудозатраты), которые требуется включить в себестоимость продукции. Документ является распоряжением на оформление документа выработки сотрудников.

Все затраты, отраженные документом, включаются в себестоимость выпущенной продукции в месяце отражения (не поддерживаются производственные циклы, переходящие через границу месяца).

## Применимость производства без заказов

Данная форма выпуска может применяться во всех производственных подразделениях, в том числе параллельно с использованием позаказного производства.

Производство без заказов можно использовать для отражения производственных процессов, выполняющихся несколькими подразделениями.

При выпусках без заказов обеспечивается поддержка расчета себестоимости нескольких выходных изделий, принимаемых к учету по расчетной или фиксированной стоимости.

Особенности выпуска без заказов:

■ оценка доступности производственных мощностей для исполнения не производится;

■ трудозатраты исполнителей фиксируются документами Выработка сотрудников;

■ расчет себестоимости выполняется на выпущенные изделия;

■ материальные затраты и трудозатраты на изделия, у которых на конец отчетного периода не завершен полный цикл обработки, подлежат распределению в следующих отчетных периодах по факту оформления выпуска.

## Закладка Основное

### Группировка затрат

В поле Группировка затрат описывается способ распределения затрат, указанных в документе, на выпущенную продукцию:

■ Затраты не указываются – в документе указывается только объем выпуска, Скрываются закладки Материалы и работы и Трудозатраты и табличная часть выпуска по фиксированной стоимости. Затраты на выпуск продукции можно отнести через Распределение материалов и работ и Распределение расходов между партиями производства.

■ По продукции – израсходованные материалы и трудозатраты указываются отдельно для каждой продукции (с уникальной характеристикой и серией при наличии);

■ По продукции (без серий) – аналогично предыдущему варианту, но серии не учитываются - одинаковая продукция разных серий образует одну группу затрат;

■ По продукции и назначениям – калькулируется продукция с уникальной характеристикой в разрезе назначений и серий (если используется учет по сериям);

■ По продукции и назначениям (без серий) – аналогично предыдущему варианту, но серии не учитываются – одинаковая продукция одного и того же назначения с разными сериями образует одну группу затрат;

■ По спецификациям продукции – вариант позволяет отдельно учесть затраты, связанные с разными вариантами изготовления одной продукции, или зарегистрировать затраты на выпуск группы одновременно производимой продукции (спецификация описывает одновременный выпуск нескольких позиций). Этим способом можно отразить разделочные процессы;

■ По спецификациям продукции и назначениям – предыдущий вариант дополняется возможностью выделить затраты в разрезе указанных назначений;

■ По документу – все указанные в документе Производство без заказа материалы и трудозатраты подлежат распределению на весь состав продукции данного документа. Пропорция распределения для продукции задается в поле Доля стоимости в табличной части Продукция по рассчитываемой стоимости на закладке Продукция.

При выборе варианта группировки затрат По документу появляется поля Распределять затраты на изделия и Переработка для (только в ERP).

В поле Распределять затраты на изделия выбирается вариант распределения из перечисленных: по долям стоимости, по плановой стоимости, по весу, по объему.

Флажок и поле Переработка для используется для отражения ситуации внутренней переработки, при которой производственный процесс выполняется одной организацией для другой в рамках единой управленческой структуры.

## Продукция

Закладка содержит списки продукции по рассчитываемой стоимости и побочного выпуска по фиксированной стоимости с обязательным указанием количества и направления выпуска. В качестве направления выпуска для продукции с типом номенклатуры товар указывается выпуск на склад или списание на статью расходов. При выпуске на склад приходование выпущенной продукции на указанном складе осуществляется самим документом производства без заказа и не требует каких-либо дополнительных документов отражения выпуска (за исключением использования ордерной схемы, при которой потребуется оформить ордер для приемки).

Для продукции можно указать спецификацию, по которой она произведена. Заполнение спецификации обязательно, если выбрана группировка затрат со спецификацией. Указанная спецификация может использоваться для заполнения остальных табличных частей по нормативам.

## Материалы и работы

Содержит список материалов и работы, затраченных на производство продукции.

В поле Склад указывается склад, либо цеховая кладовая. При проведении документа материалы списываются с указанного склада. При этом осуществляется контроль остатков в соответствии с настройками контроля остатков по складам и по товарам организаций. При заполнении материалов по спецификации склад может быть заполнен автоматически в соответствии с настройками схемы обеспечения материала.

В поле Подразделение затрат для материалов указывается подразделение, которое выступает получателем затрат (для цеховых кладовых устанавливается равным подразделению, указанному в карточке цеховой кладовой). Для работ указывается исполнитель работ, затраты которого должны быть списаны на данную партию.

Стоимость материалов распределяется в себестоимость продукции в соответствии с выбранной группировкой затрат.

Для интерактивной работы со списком материалов предусмотрены следующие команды:

-   Дополнить по спецификации - предназначена для получения нормативов расхода материалов по спецификациям, указанным в табличной части Продукция, их приведению к количеству продукции в документе, подбору обособленных под назначение продукции остатков нормативных материалов и помещения результата в табличную часть Материалов и работ. Расчет количества материалов делается с учетом настроек кратности запуска в спецификации.
-   Дополнить обособленными остатками - предназначена для получения обособленных под выпущенную продукцию остатков материалов и помещения этих остатков в табличную часть Материалов и работ.
-   Заполнить группу затрат - предназначена для выбора и заполнения группы затрат в выделенных строках.
-   Заполнить статью калькуляции - предназначена для выбора и заполнения статьи калькуляции в выделенных строках.

### Применение аналогов материалов

на закладке Материалы командой Заполнить – Показать аналоги включается видимость колонки, в которой отображается наличие разрешений на замену, допускающих применение аналогов. По команде Заполнить – Подобрать аналоги открывается диалог “**Замена материалов аналогами**”, в котором можно осуществить замену.

Аналоги подбираются на том же складе, который был указан в строчке с исходным материалом. Информация из схемы обеспечения игнорируется при этом действии.

## Трудозатраты

Содержит список выполненных работ сотрудников по производству продукции. Окончательное включение трудозатрат в себестоимость продукции выполняется при расчете себестоимости. В качестве исполнителей видов работ могут быть выбраны бригады или работники.

Команды заполнения:

-   Дополнить по спецификации - предназначена для получения нормативов трудозатрат по спецификациям, указанным в табличной части Продукция, их приведению к количеству продукции в документе и помещения результата приведения в табличную часть Трудозатраты.
-   Заполнить группу затрат - предназначена для выбора и заполнения группы затрат в выделенных строках.
-   Заполнить статью калькуляции - предназначена для выбора и заполнения статьи калькуляции в выделенных строках.

В заголовке закладок по мере заполнения документа показывается информация о количестве строк табличных частей.

## Модель расчета себестоимости

При материальном выпуске в рамках одного календарного месяца документы Производство без заказа позволяют сформировать партии (группы) продукции для расчета себестоимости. В один документ Производство без заказа можно объединить:

■ все выпуски одной продукции – себестоимость рассчитывается на весь объем выпуска, цена позиции усредняется. Например, выпуск продукции оформляется посменно, а затраты заданы в целом на весь объем выпуска. Для их регистрации в целях расчета себестоимости используется один документ Производство без заказа. Это позволяет существенно снизить трудоемкость процедуры отнесения затрат;

■ выпуски одного вида продукции – для позиций продукции применяется один вариант распределения затрат, рассчитанная цена уникальна. Например, при выпуске ученических тетрадей разные номенклатурные позиции продукции отличаются только количеством страниц (12, 18, 24 листа в тетради). Затраты регистрируются в целом по виду продукции и относятся на группу. Распределение затрат на продукцию внутри группы выполняется по весовым коэффициентам, учитывающим общее количество страниц по каждому виду продукции;

■ выпуски разнородной продукции, имеющие одинаковый вариант настройки распределения затрат.

Доступны следующие варианты формирования стоимости выпуска (задаются в форме Настройка модели формирования стоимости):

■ выпуск продукции по рассчитываемой стоимости (Продукция);

■ выпуск продукции по фиксированной стоимости (Возвратный отход).

Работа с возвратными отходами описывается в разделе [Версия 2.2. Распределение общих возвратных отходов](/db/erp25doc/bookmark/productionaccount/RecyclableMaterialDistribution22)

При установленном флажке Отражать затраты на выпуск продукции в документе «Производство без заказа» отнесение затрат на продукцию, выпускаемую по рассчитываемой стоимости, возможно непосредственно в документах Производство без заказа. Использованные материалы указываются на закладке Материалы и работы, трудозатраты – на закладке Трудозатраты. При расчете себестоимости выпуска из стоимости затрат исключается стоимость возвратных отходов, указанных в табличной части Побочный и промежуточный выпуск по фиксированной стоимости на закладке Продукция.

Поддерживается нормативное списание затрат на основании спецификации, выбранной для продукции при настройке модели (поле Спецификация формы Настройки модели формирования стоимости).

Если в изготовлении продукции были задействованы несколько подразделений (без регистрации выпуска ими отдельных полуфабрикатов), то в документе Производство без заказа можно указать затраты всех подразделений и учесть их при формировании стоимости выпуска. Все затраты выпуска аккумулируются на выпускающем подразделении.

Например, на закладке Материалы и работы указываются использованные в других подразделениях материалы. Материалы списываются из цеховых кладовых, указанных в поле Отправитель. При выборе к списанию номенклатуры с типом Работа в поле Отправитель выбирается подразделение, в котором эта работа была зарегистрирована. На закладке Трудозатраты можно задать подлежащие списанию трудозатраты.

Также в составе затрат, учитываемых при расчете себестоимости, могут быть учтены оформленные в подразделении постатейные расходы и стоимость материалов, распределяемая отдельно. Для этого необходимо дополнительно оформить документы Производство – Внутрицеховой учет – Распределение материалов и работ и Распределение расходов между партиями производства . Документы Производство без заказа являются партиями выпуска, на которые распределяются затраты.

Если флажок Отражать затраты на выпуск продукции в документе Производство без заказа в форме Настройка модели формирования стоимости снят, то затраты на выпуск продукции относятся только документами Распределение материалов и работ и Распределение расходов между партиями производства. Это соответствует варианту «котлового» распределения затрат.

## Отражение выпуска продукции в регламентированном учете

Все производственные затраты, определяющие себестоимость выпуска продукции, аккумулируются на выпускающем подразделении.

По затратам, изначально зарегистрированным на выпускающем подразделении, документы Производство без заказа проводок по бухгалтерскому учету не делают.

В случае переноса затрат из других подразделений, участвовавших в выпуске, по документам Производство без заказа после закрытия месяца формируются проводки вида «Дт 2Х (Выпускающее подразделение) Кт 2Х (Подразделение – участник производства)».

По документам Передача продукции из кладовой изначально в количественной оценке формируются проводки вида «Дт 43 (Склад готовой продукции) Кт 2Х (Выпускающее подразделение)». После расчета себестоимости проводки дополняются стоимостной оценкой.

При производстве без заказов можно учитывать затраты по направлениям деятельности. При этом направления деятельности можно указать:

■ Для производимой продукции (построчно в табличных частях Продукция и Побочный выпуск по фиксированной стоимости, определяется по Назначению).

■ Для производственных затрат  - направление деятельности для учета затрат в подразделении  (реквизит Направление деятельности на закладке Дополнительно)

■ Для материалов и работ (построчно в табличной части Материалы и работы, определяется по Назначению).

При производстве без заказа при любых группировках затрат выпускаемая продукция может приходоваться под разные направления деятельности, в том числе отличные от направления деятельности затрат или отдельных материалов / работ. В этом случае действуют следующие правила перераспределения по направлениям деятельности:

## Оформление выпуска работ

В течение месяца оформляется потребление работ производственных подразделений. Подтверждение выпуска потребленных работ производственных подразделений оформляется с помощью  выпуска работ без заказов. Документами Производство без заказа регистрируется выпуск работ и определяются затраты на их выполнение. Настройки модели формирования стоимости и оформление выпуска для работ без заказов схожи с выпуском продукции без заказов На основании документов Производство без заказа оформляются документы Акт выполненных внутренних работ, что позволяет отразить следующие операции:

■ передача работ между подразделениями;

■ передача работ между подразделениями, выделенными на отдельный баланс (между филиалами).

Вариант регистрируемой операции определяется на закладке Основное в поле Операция. Описание работ выполняется на закладке Работы и содержит информацию о наименованиях и количестве выполненных работ, назначении выпуска, подразделении-получателе, группе (виде) продукции, в интересах которой были выполнены указанные работы.

Поддерживаются сценарии:

■ Документы выпуска работ оформляются по факту выполнения работ, на основании документа Производство без заказа формируются Акт выполненных внутренних работ;

■ Акты выполненных внутренних работ оформляются оперативно, подтверждение выпуска потребленных работ производственных подразделений оформляется с помощью  выпуска работ без заказов в рабочем месте Оформления производства без заказов.

Реализация работ сторонним покупателям может оформляться как с выпускающего подразделения, так и с выделенного подразделения.

При реализации с выделенного подразделения работа с выпускающего подразделения сначала адресуется этому подразделению, формируются проводки, отражающие передачу результатов работы другому подразделению. Документы реализации оформляются с выделенного подразделения, оно же будет фигурировать в проводках вида «Дт 90.02 Кт 2Х (Выделенное подразделение)» после расчета себестоимости.

В случае реализации с выпускающего подразделения документами Производство без заказа регистрируется выпуск работ без формирования проводок. После расчета себестоимости по документам реализации будут созданы проводки вида «Дт 90.02 Кт 2Х (Выпускающее подразделение)».
