# Заказы на производство

Документ Заказ на производство служит для регистрации потребности к производству и управления исполнением этой потребности в производстве.

Все созданные заказы на производство вне зависимости от их текущего статуса представлены в списке Производство – Межцеховое управление – Заказы на производство.

Форма заказа на производство:

## Статусы заказа

Жизненный цикл заказа определяется полем Статус, которое может иметь значения: Формируется, К производству, Закрыт.

Статус Формируется соответствует черновику заказа. По такому заказу не строится динамическая структура, заказ не подлежит обеспечению и планированию.

Статус К производству – основной рабочий статус, который обозначает, что заказ находится в зоне ответственности ПДО и начинается его подготовка к запуску в производство. При переводе в этот статус заказ уже считается заполненным и подлежащим исполнению. По такому заказу строится динамическая структура (при соответствующей настройке системы).

Статус Закрыт предназначен для обозначения заказов, по которым завершена работа. При переводе в этот статус система может проверить, что по заказу не осталось невыполненной работы.

## Приоритет

Определяет очередность планирования заказа и влияет на распределение ресурсов. Заказы с более высоким приоритетом могут вытеснять менее приоритетные заказы как при загрузке ВРЦ, так и при распределении запасов.

## Подразделение-диспетчер

Подразделение-диспетчер, отвечающее за исполнение заказа в целом.

## Операция

Хозяйственная операция заказа. Возможны варианты Собственное производство и Производство из давальческого сырья. Второй вариант применяется для изготовления продукции для давальца.

## Продукция

 Закладка содержит список продукции, которая должна быть произведена по заказу на производство. Для продукции в заказе указывается количество, спецификация, по которой она должна быть произведена, назначение выпуска, получатель - склад, на который ее нужно выпустить (для товарной номенклатуры). Если производится работа, то в качестве получателя вместо склада указывается подразделение – получатель работы.

Существует возможность отменять строки заказа на производство с указанием причины отмены. Для этого используется колонка Отменено по причине. Но важно понимать, что отмена строки продукции в заказе не отменяет производство по уже запущенным партиям.

Под списком продукции указываются даты Начать не ранее и Желаемая дата выпуска. Эти даты используются при построении графика производства. Желаемая дата выпуска может быть задана как целиком на заказ, так и построчно для продукции.

## Создание заказов на производство

Заказы на производство создаются в рабочем месте Производство – Межцеховое управление – Заказы на производство. Заказы можно создать вручную или с помощью помощников формирования заказов по кнопкам Создать – По плану… и Создать – По потребностям.

Помощник формирования заказов на производство по потребностям также доступен по гиперссылке Формирование заказов в рабочем месте Производство – Межцеховое управление – Управление очередью заказов.

Использование помощников предполагает выполнение нескольких шагов.

## Формирование заказов на производство по потребностям

В помощнике формирования заказов на производство по потребностям на первом шаге задаются условия для отбора продукции, для выпуска которой планируется сформировать заказы на производство. Отбор возможен по свойствам потребностей в продукции (склад, назначения, категория и др.) и по параметрам способа обеспечения (подразделение, тип и источник обеспечения). Есть возможность задать произвольные отборы по условиям пользователя. Следующие шаги помощника:

■ 2 из 5. Настройка способов обеспечения – для формирования заказов требуется отметить флажками необходимые способы обеспечения. Для отмеченных способов обеспечения указываются виды продукции, которые следует включать в заказы:

○ Достигшие точки заказа – продукция, потребности в которой обеспечены не далее срока исполнения заказа, установленного способом обеспечения, т. е. если данную продукцию не заказать сегодня, то ее могут не успеть изготовить;

○ Все, плановое формирование заказа – все виды продукции, поставляемые данным способом. Количество к заказу будет предложено для обеспечения всех потребностей до «Даты следующей поставки», которую необходимо заполнить при выборе данного варианта.

■ 3 из 5. Поддержание запасов – третий шаг пропускается, если нет потребности, сформированной по правилам поддержания запасов.

■ 4 из 5. Обеспечение заказов к отгрузке.

■ 5 из 5. Уточнение сформированных заказов.

## Формирование заказов на производство по планам

Рабочее место предназначено для формирования заказов на производство на основании данных ранее утвержденных планов производства.

На первом шаге выбирается сценарий планирования, в рамках которого будет происходить формирование заказов.

Дополнительно требуется указать подразделение-диспетчер, по которому созданы планы. Если подразделение не указано - будут выбраны планы без детализации по подразделению (общие планы по всей компании). Если отбор по подразделению-диспетчеру не используется, будут выбраны планы как с детализацией, так и без. отбор идет по подразделению-диспетчеру и периодам запуска или выпуска продукции. Расчет периода запуска заказов выполняется с учетом нормативной длительности производства, которая определяется по данным ресурсной спецификации для продукции.

Режим расчета потребностей по плану позволяет управлять учетом перевыполнения/недовыполнения планов. В режиме расчета раздельно по периодам (запуска/выпуска) потребности разделены по периодам как и в исходных планах. Перевыполнение/недовыполнение плана заказами в каком-либо периоде не сказывается на следующих периодах. Если выбран режим расчета нарастающим итогом за период, тогда количество к заказу рассчитывается за весь период, начиная от заданной даты по текущий период планирования. В таком режиме можно учесть перевыполнение/недовыполнение планов по заказам.

Флажок Формировать заказы по актуальным спецификациям (новое в 2.5.11) влияет на расчет количества к заказу и на заполнение спецификации в формирующихся заказах. Если флажок не установлен, то заказы будут формироваться с использованием спецификаций, указанных в плане, а при расчете количества к заказу учитывается количество в уже сформированных заказах только по спецификации, заданной в плане. То есть если в плане требуется 10 штук по спецификации А, в заказах на производство уже сформировано 3 штуки, но по более свежей и актуальной спецификации Б, количество к заказу будет равно 10, и формироваться они будут по спецификации А. Если же флажок Формировать заказы по актуальным спецификациям установлен, то количество к заказу будет считаться без учета спецификаций, то есть в приведенном примере будет 10-3=7 штук. А новые заказы будут заполняться актуальной спецификацией, выбираемой по тем же принципам, что и при ручном вводе заказа на производство. Независимо от того, какая спецификация указана в плане.

На втором шаге в верхней таблице показываются данные планов, соответствующие указанным отборам. Количество рекомендуемое к заказу рассчитывается на основании количества, зафиксированного на период в планах производства за вычетом ранее созданных заказов на производство за этот же период. В таблице можно отметить флажком позиции к заказу. При отметке позиций к заказу в нижнем  списке появляются Заказы к оформлению - будущие заказы на производство, которые будут сформированы при переходе на Шаг 3 путем нажатия кнопки Создать заказы.

На третьем шаге показывается список сформированных заказов. Можно убедиться в корректности формирования или увидеть сообщения об ошибках, возникших при формировании, провести или отменить проведение заказов. Можно вернуться на шаг назад. При этом сформированные заказы будут отмечены на удаление.

## Структура заказа на производство

Структура заказа – это информационная структура, описывающая древовидный состав заказа с указанием всех производимых по заказу узлов (полуфабрикатов).

По команде Структура заказа выводится форма, предназначенная для показа структуры заказа на производство, образованной как сформированными в рамках заказа партиями производства, так и записями динамической структуры.

Кроме информации о самой структуре, выводятся данные из графика производства о датах запуска, информация об обеспеченности. Кроме того, если по какой-либо позиции есть остатки на других складах, система об этом тоже информирует:

Для индикации наличия используются цветные стрелки разных цветов, которые означают, в  зависимости от цвета:

-   Зеленая – наличие свободного остатка на текущем складе или ненужный остаток под другим назначением на текущем складе.
-   Оранжевая – остаток под другим назначением на текущем складе.
-   Красная – остаток на другом складе.

Внизу формы гиперссылка расшифровывает эту информацию по выбранной позиции. По гиперссылке откроется отчет Остатки и доступность с предустановленным отбором по выбранной позиции:

Используя эту информацию, можно предпринимать какие-либо действия по ручному дообеспеченнию заказов. Например, перемещать недостающие позиции с других складов или забирать путем корректировки назначения.

Команда Развернуть подчиненные элементы приводит к полному разворачиванию структуры. Важно иметь в виду, что структура заказа отображается динамически, ветки структуры подгружаются в форму только по мере раскрытия узлов пользователем. Это позволяет очень быстро выводить форму структуры даже для очень сложных изделий, содержащих десятки тысяч узлов. Если требуется в сложной структуре найти какую-то позицию, то лучше это делать не ручным раскрытием всей структуры, а поиском по номенклатуре. ### Контроль производства по заказу

Отчет предназначен для контроля хода производства по заказу, выявления излишков продукции и полуфабрикатов, образующихся по заказу. Отчет работает только с заказами с динамической структурой. Особенно полезен в тех случаях, когда по заказу возникают излишки в процессе производства. Это может быть обусловлено различными причинами. Например, кратность запуска по спецификации не соответствует количеству, требуемому в заказе. Изменения в используемых спецификациях, перераспределение запасов, отмена строк продукции – все эти ситупции тоже могут вызвать то, что запущенные или запланированные к запуску полуфабрикаты станут не нужны заказу.

## Управление очередью заказов на производство

Для работы сотрудников ПДО, выполняющих в управлении производством функции главного диспетчера, предназначено рабочее место Производство – Межцеховое управление – Управление очередью заказов. В нем в табличной части отображаются все заказы в статусе К производству; заказы, находящиеся в статусе Формируется, доступны по гиперссылке Формирующиеся заказы.

Рабочее место Производство – Межцеховое управление – Управление очередью заказов предназначено для управления очередью заказов на производство, формирования этапов производства, построения графика производства и контроля выполнения заказов.

В табличной форме отображается список документов Заказ на производство в статусе К производству.

В рабочее место попадают заказы только в статусе К производству. По гиперссылкам <B>Формирующиеся заказы (кол-во)</B> и <B>Закрытые заказы</B> можно перейти к отдельному списку заказов в соответствующих статусах.

Заказы в рабочем месте отсортированы по приоритету и очередности выполнения в рамках одного приоритета. В рамках одного уровня приоритетности возможно ручное задание положения заказа в списке кнопками .

В списке заказов предусмотрены отборы, позволяющие выделить для работы заказы, относящиеся к зоне ответственности конкретного пользователя:

■ Приоритет,

■ Подразделение-диспетчер,

■ Ответственный.

Мониторинг заказов на производство основан на контроле состояния исполнения заказов, которое отображается пиктограммами в первых полях табличной части:

■  Состояние выполнения этапов:

○ <пусто> – созданы все необходимые документы Этап производства, этапы переданы к выполнению, график рассчитан и находится в актуальном состоянии, диспетчеризация не требуется;

○  Сформировать этапы – требуется создать документы Этап производства;

○  Передать этапы к выполнению – по заказу есть этапы, которые необходимо передать к выполнению;

○  Проверить этапы – по заказу есть этапы, имеющие ошибки заполнения;

○  Планировать график – график не рассчитывался или потерял актуальность, требуется новый расчет графика производства.

■  Обеспечение материальными ресурсами:

○ <пусто> – сложности с обеспечением этапов материалами отсутствуют;

○  Требуется обеспечение – есть этапы, для которых не обеспечены все необходимые материальные ресурсы.

■  Состояние выпуска продукции:

○ <пусто> – срок выпуска продукции еще не наступил;

○  Нарушена дата потребности – по графику ожидается опоздание производства всей или части продукции относительно желаемой даты выпуска;

○  Все произведено – произведена вся продукция заказа.

Отбор заказов по стадиям исполнения происходит путем наложения одноименных фильтров. Для удобной работы со списком заказов фильтры располагаются на командной панели, расположенной в правой части экрана (с возможностью сворачивания).

Выполнить требующееся действие можно двойным щелчком левой кнопкой мышки по пиктограмме в строке заказа или по кнопке Действия в шапке формы:

■ Сформировать этапы производства – для выбранных заказов на производство будут сформированы документы Этап производства в соответствии с выбранными для продукции и полуфабрикатов спецификациями. Для позиций, по которым спецификации отсутствуют, этапы созданы не будут. Для формирования этапов необходимо выбрать спецификации и повторить создание этапов или оформить документы Этап производства вручную;

■ Передать этапы к выполнению – к выполнению передаются этапы, у которых отсутствуют невыполненные предшествующие этапы. Если есть необходимость заранее установить статус К выполнению всем этапам, включая те, у которых есть невыполненные предшественники, можно воспользоваться формой для диспетчеризации этапов;

■ Пометить на удаление этапы производства - помечаются на удаление все этапы производства, относящиеся к заказу.

■ Планировать текущий – для текущего заказа открывается форма Планирование графика производства. При планировании текущего заказа желательно наличие актуального графика производства по всем стоящим выше в очереди заказам, иначе их перепланирование может сделать неактуальным график рассматриваемого заказа;

■ Планировать выбранные – расчет графика производства будет выполнен для выбранной группы заказов на производство. Настройки планирования задаются в краткой форме Планирование графика производства и применяются для планирования всех указанных заказов. При планировании желательно наличие актуального графика производства по всем стоящим выше в очереди заказам, иначе их перепланирование может сделать неактуальным график рассматриваемых заказов:

■ Планировать очередь по текущий (заказ) – расчет графика производства будет выполнен для текущего заказа на производство и всех заказов, требующих актуализации и имеющих приоритет исполнения выше, чем текущий.

■ Перенести желаемые даты обеспечения – выполняется согласование желаемых дат обеспечения материалами с графиком этапов. Это позволяет сократить случаи преждевременного обеспечения материалами этапов, выполнение которых начнется еще не скоро. В рамках формы Перенос желаемых дат обеспечения этапов производства можно проанализировать список материалов, имеющих желаемую дату обеспечения раньше даты начала этапа. Даты обеспечения материалами в этапах можно изменить вручную, или по кнопке Перенести даты обеспечения можно сдвинуть желаемые даты обеспечения к датам начала этапов по графику. При этом следует учитывать, что этапы, запланированные далеко в будущем из-за других ограничений (загрузка рабочих центров, сроки выполнения предыдущих этапов), и для которых было сдвинуто обеспечение материалами на более поздние даты, впоследствии может не получиться перепланировать на более ранние сроки уже из-за ограничений по материалам.

■ Закрыть заказ – для выбранных заказов устанавливается статус Закрыт. Перед применением команды для списка заказов можно установить отбор по условию Все произведено, что позволяет осуществить косвенную проверку готовности заказов к завершению. При использовании функциональной опции НСИ и администрирование – Производство – Производство – Контроль выполнения закрытия заказов на производство закрытие заказов, по которым еще не все произведено, будет заблокировано.

■ Диспетчирование этапов - команда отрывает форму диспетчирования этапов производства с установленным отбором по выбранному заказу.

■ Структура заказа - открывает форму структуры заказов для выбранных заказов на производство. Позволяет в одном окне увидеть структуру нескольких заказов.

■ Формирование заказов - Гиперссылка используется для формирования заказов на производство полуфабрикатов, обеспечиваемых отдельно. По этой команде открывается рабочее место Формирование заказов по потребностям с предустановленным типом обеспечения Собственное производство.

■ Обеспечение цеховых кладовых материалами - гиперссылка используется для формирования заказов обеспечивающих потребности цеховых кладовых. По этой команде открывается рабочее место Формирование заказов по потребностям с предустановленным отбором по типу склада Кладовая цеха.

При расчете обеспечения может возникнуть ситуация, когда некоторый заказ на производство обеспечивает более приоритетный заказа на производство. С логической точки зрения это является ошибкой. Для устранения ошибки следует в очереди поместить обеспечивающий заказ выше обеспечиваемого. Для индикации таких случаев в рабочем месте Управление очередью заказов предусмотрен индикатор и отчет-расшифровка.
