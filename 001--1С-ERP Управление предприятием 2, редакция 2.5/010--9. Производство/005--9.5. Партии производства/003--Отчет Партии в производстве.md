# Партии производства

Партия производства в общем смысле - совокупность одинаковых изделий, запускаемых в производство одновременно или непрерывно в течение определенного времени. В 1С:ERP партия производства представлена последовательностью этапов производства, сформированных по одной ресурсной спецификации. Партия производства является котлом расчета себестоимости и должна обязательно завершаться выпуском продукции по рассчитываемой стоимости.

## Формирование партий производства

Доступно при использовании динамической структуры заказа на производство.

Рабочее место предназначено для формирования партий производства по данным динамического плана, образованного заказами на производство. В общем виде может вызываться по команде Производство – Сервис – Формирование партий производства. Кроме того, рабочее место может быть вызвано контекстно из Управления очередь заказов по команде Действия – Сформировать партии, либо из Структуры заказа по команде из контекстного меню выбранного узла структуры.

Рабочее место представляет из себя пошаговый помощник.

### Шаг 1 – настройки и отборы

На первом шаге устанавливаются отборы, по которым выбираются позиции динамического плана для формирования партий.

Там же можно задать параметры формирования этапов партий:

Можно включить **укрупнение партий** при запуске в производство изделий разных назначений или разных заказов на производство.

Для запуска укрупненной партии по данным дин.плана нескольких заказов система формирует служебный заказ на производство, к которому будет относиться сформированная объединенная партия.

Укрупнение работает только для полуфабрикатов структуры изделия. Запуск производства самой продукции заказов укрупнению не подлежит – партии производства конечной продукции будут формироваться отдельно, в рамках исходных заказов.

Настройка Дата начала выполнения определяет плановые даты запуска формирующихся партий.  Может быть взята Текущая дата – если предполагается досрочный запуск партии, либо Взять из графика – дата будет проставлена из графика производства. Это влияет на последующее построение графика производства по таким партиям.

Флажок Предварительный просмотр включает 3-ю необязательную страницу.

### Шаг 2 – определение состава и объема запуска

На втором шаге показывается так называемый номенклатурный план запуска – перечень позиций номенклатуры, требующих изготовления по данным динамического планирования.

Номенклатурный план может отображаться как простой таблицей по датам запуска, так и в развернутом виде кросс-таблицей с периодами в колонках.

Можно увидеть требуемое количество, маршрут изготовления (последовательность кодов цехов), состояние обеспеченности партии входящими компонентами. Обеспеченность отображается пиктограммами и количеством изделий, производство которых полностью обеспечено. Есть возможность отобрать позиции по обеспеченности.

По гиперссылке Детальная информация раскрывается нижний список, в котом показывается позаказная детальная расшифровка выбранной в верхнем списке строчки.

В верхнем списке можно выбрать позиции К запуску, расставив флажки и откорректировав при необходимости количество. Можно изменить спецификацию, по которой будут сформированы этапы партии.

### Шаг 3 – предварительный просмотр

Это опциональный шаг, который может быть выключен в настройках. Предварительный просмотр показывает, какие партии будут сформированы. В этот момент еще никакие документы не сформированы, можно вернуться назад и изменить состав запускаемых партий. Шаг может полезен в тех случаях, когда выбор к запуску разных позиций осуществляется из большого списка, который невозможно охватить взглядом без скроллинга. Кроме того, на этом шаге можно вручную откорректировать плановую дату начала партии:

При нажатии на этом шаге Далее уже будут формироваться партии.

### Шаг 4 – просмотр сформированных партий

На этом шаге уже отображается перечень запущенных партий, под которыми показываются сформированные этапы производства.

Отсюда можно при необходимости открыть сформированные этапы для уточнения каких-то данных в них. Можно сразу распечатать Лист сопровождения партии. Можно перейти в диспетчирование этапов или в структуру заказа на выбранную партию.

При нажатии Назад система пометит на удаление сформированные документы.

## Изменение партии производства

Рабочее место Изменение партии можно открыть:

■ Из структуры заказа

■ Из рабочего места Диспетчирование этапов командой Изменить партию в контекстном меню

Рабочее место Изменение партии позволяют выполнить следующие действия над партиями производства (цепочками этапов):

■ Разделить на несколько партий

■ Отразить брак

■ Сократить (увеличить) производство

■ Отменить производство, оформить выпуск

■ Оформить промежуточный выпуск и продолжить обработку

Рабочее место имеет вид, изменяющийся в зависимости выбранного действия.

### Сократить (увеличить) производство

Действие применяется в тех случаях, когда дальнейшее выполнение партии должно продолжиться уже над другим количеством. Такое может потребоваться, например, при выявлении неисправимого брака обрабатываемых изделий, при изменении потребности. Необходимо указать новый размер партии. При этом изменяемые этапы могут быть либо перезаполнены по исходной спецификации, либо пересчитаны по коэффициенту из данных, указанных в этапе. Пересчет по коэффициенту может быть полезен в тех случаях, когда в партию вносились какие-то отклонения от нормативов из ресурсной спецификации.

### Отменить производство, оформить выпуск

Действие применяется при необходимости прекращения производства партии. В поле После этапа указывается последний этап, который выполняется для этой партии. В этом этапе будет оформлен выпуск того, что получилось. Для этого необходимо выбрать номенклатуру, получателя и указать количество. Этот промежуточный результат может быть как выпущен на склад, так и списан на расходы.

Последующие этапы будут удалены.

Дополнительно смотрите видеоурок [Как отменить заказ на производство на разных стадиях выполнения](/video/erp_production_cancellation).

### Разделить на \_\_\_ партии

Используется для разделения дальнейшего выполнения на несколько независимых партии. В этом случае оформляется промежуточный выпуск, для которого надо указать номенклатуру. Этот выпуск будет разбит на части с заданным способом распределения затрат между ними.

По каждой из образовавшихся партий можно выбрать дальнейшую судьбу: продолжить обработку, положить на склад или списать на расходы. Кроме того, промежуточная номенклатура тоже может отличаться для разных партий.

При продолжении обработки будут сформированы этапы оставшейся обработки. При этом для продолжения обработки можно указать другие спецификации, даже разные для отдельных партий.

Переход к заполнению данных каждой партии осуществляется по гиперссылкам Партия 1, Партия N, которые возникают на форме в зависимости от заданного количества партий.

Проверить результат заполнения можно по гиперссылке Все партии.

Действие может применяться в различных случаях. Например, если забракована часть партии. Или если от большой партии, которая будет долго обрабатываться, надо отделить небольшое количество, которое срочно надо обработать до конца.

### Оформить промежуточный выпуск и продолжить обработку

Действие может применяться в том случае, когда процесс описан бесполуфабрикатным многоэтапным способом, но вдруг потребовалось, например, временно положить текущее состояние выполнения на склад.

Это же действие позволяет продолжить дальнейшую обработку партии уже по другой спецификации, или по той же спецификации, но с произвольного этапа. Например, чтобы повторить какие-то ранее выполненные этапы или пропустить ставшие ненужными.

После выполнения любого из этих действия открывается окно со списком измененных документов, в котором можно увидеть, какие этапы удалены, какие новые партии и этапы образовались.

Этап, выбранный в поле После этапа, будет сделан выпускающим этапом и завершит текущую партию, если он еще не завершен и у него нет параллельных этапов. В противном случае после выбранного этапа будет создан "технический" выпускающий этап.

Если после выбранного этапа есть начатые или завершенные этапы, или есть ветвление процесса, менять партию нельзя.

## Отчет Партии в производстве

Отчет предназначен для анализа состояния запущенных в производство партий. Партия считается запущенной и попадает в отчет, если у нее есть этап в статусе Начат, либо если часть этапов завершена, а часть еще не начата.

Колонка Подразделение указывает, в каком цеху сейчас находится партия. В группе колонок Текущий этап описывается состояние выполнения, в том числе информация о текущей операции, на которой находится партия, если используется управления с помощью операций.

Если в партии одновременно несколько этапов имеют статус Начат, то такая партия в отчете отобразится несколькими строчками.

В колонке Ход выполнения отражается % завершения, который рассчитывается с использованием нормативной длительности этапов. Строка отчета может быть расшифрована отчетом Контроль движения продукции и материалов по партии производства.
