# Настройки подсистемы производства

Настройка раздела производства вызывается через НСИ и администрирование – Настройка НСИ и разделов – Производство.

## Производство

Использовать производство - включение функциональности собственного производства.

Использовать разрешения на замену материалов - включение функциональности разрешений на замену, позволяющих описать [аналоги материалов](/db/erp25doc/bookmark/productionnsi/UsingAUniqueMaterial).

Использовать согласование разрешений на замену – включение функциональности согласований разрешений на замену.

Использовать параметры назначения спецификаций - включение использования и настройка перечня [параметров назначения](/db/erp25doc/bookmark/productionnsi/SpecificationAssignmentParameters), по которым система автоматически подбирает спецификации.

Использовать наборы в производстве  -  разрешить использовать в производстве [наборы](/db/erp25doc/bookmark/productionnsi/ProductionKit). Способ задания состава набора указывается в настройке Состав определяется. Доступны варианты: спецификациями, спецификациями или вариантами комплектации, вариантами комплектации.

Динамическая структура заказов на производство – при включении этой опции структура заказа формируется автоматически до формирования этапов. Динамически перестраивается при изменении запасов, приоритетов, заказов. Этапы формируются по мере запуска партий в производство. Если не включать, то структура заказа определяется только сформированными документами Этап производства. Автоматически не перестраивается. По заказу формируются сразу все требующиеся этапы производства.

Для динамической структуры доступны настройки:

Распараллеливать расчет — задает максимальное количество потоков расчета структуры.

Повторное использование структуры изделий — позволяет кэшировать структуру изделий для более быстрого расчета последующих заказов.

Оптимизировать запись изменений - результат расчета записывать как разность между прошлым и текущим состоянием с последующим сворачиванием по заданному расписанию.

Полуфабрикаты внутри заказа запускать в производсво обособленно – если включена эта настройка, полуфабрикаты будут запускаться в производство обособленно независимо от настройки обособления номенклатуры. Но при этом потребность может оставаться необособленной. Таким образом, заказ может использовать имеющиеся в наличии доступные запасы необособленных полуфабрикатов. Но если запасов нет и полуфабрикат для заказа приходится производить, он будет произведен обособленно, что может уберечь от его перехвата для более приоритетных заказов с другими назначениями.

Методика управления - настройка использования [графика производства](/db/erp25doc/bookmark/interplantplanning/Version22InterplantPlanning). Если включено использование динамической структуры, доступны варианты: **Планирование по нормативным длительностям, Планирование с учетом ресурсных ограничений**.

Планировать график производства регламентным заданием \- позволяет настроить автоматическое планирование графика производства по заданному расписанию.

Контроль выполнения при закрытии заказов на производство - при включенной настройке система не даст закрыть [заказ на производство](/db/erp25doc/bookmark/version22manufacturingorders/Version22ManufacturingOrders), если по нему произведена не вся продукция. Контроль завершения этапов при закрытии заказа не проводится.

Разрешить использование интервала планирования "Час" - настройка управляет видимостью интервала планирования "Час" в перечне доступных интервалов планирования для подразделений. Кроме того, при включении этой настройки в некоторых рабочих местах и списках колонка с датой дополняется указанием времени.

**Не включать без прочтения статьи** [Интервальное планирование](/db/erp25doc/bookmark/intervalplanning/IntervalPlanning)

### Обособленное обеспечение

При заказе в производство - определяет, что является назначением при обособленном обеспечении заказов на производство. Доступны варианты: по направлению деятельности, по назначению продукции, по заказу на производство, по этапу производства. Значение этой настройки запоминается в создаваемых заказах на производство в момент создания. Это позволяет безопасно менять настройку в системе: изменения скажутся только на будущих заказах, а ранее созданные заказы будут работать с настройкой обособления, которая была в системе на момент создания заказа. Кроме назначения, настройка влияет на формирование этапов для заказов, производящих продукцию под разные назначения. При настройках по заказу на производство и по этапу производства система может объединить в одном этапе выпуск партии изделий под разные назначения.

При выборе настройки по назначению продукции для производства одинаковых изделий под разные назначения будут формироваться отдельные цепочки этапов, чтобы избежать смешения в одной партии материалов разных назначений. Если продукция в заказе производится без назначения, то материалы будут обосабливаться под заказ на производство.

При заказе в кладовую - определяет, что является назначением при заказе материалов в кладову. Доступны варианты: по направлению деятельности, по назначению продукции, по заказу материалов.

### Операции

Виды технологических операций - возможность классификации [технологических операций](/db/erp25doc/bookmark/productionnsi/TechnologicalOperations) по видам с настройкой наборов дополнительных реквизитов. Позволяет описывать контролируемые параметры для операций в спецификациях.

Контроль выполнения операций (ОТК) - включение функциональности контролируемых операций. При включенной настройке появляется возможность для технологических операций задать необходимость контроля.

Контроль выполнения операций при закрытии этапов производства - при включенной настройке система не даст завершить этап, по которому не все операции выполнены.

### Трудозатраты

Учет трудозатрат в разрезе – настройка влияет на отбор исполнителей в документах производства. При настройке в разрезе сотрудников для выбора будут доступны только работающие на предприятии сотрудники (сюда не включаются работающие только по договору ГПХ). Кроме того такая настройка позволяет получить более точный расчет зарплаты в ситуации, когда один и тот же сотрудник в течение месяца меняет место работы внутри предприятия или работает по внутреннему совместительству.

Нормирование и расценка работ по тарифным сеткам – при включении настройки используются тарифные сетки вместо расценок самих видов работ.

## Переработка на стороне

Производство на стороне (версия 2.4) – использование старой функциональности передачи в переработку. Настройка недоступна для новых баз.

Производство на стороне (версия 2.5) (либо только заголовок Производство на стороне  без уточнения версии) - использование функциональности передачи в переработку 2.5. Допускается одновременное использование механизмов 2.4 и 2.5, но в таком режиме нельзя будет создавать новые заказы переработчикам 2.4, можно только продолжать и завершать работу с имевшимися заказами 2.4, а новые заказы делать только в механизме 2.5.

Акты о расхождениях после передачи переработчику, Акты о расхождениях после поступления от переработчика – включение возможности оформления соответствующих документов.

Заказы переработчикам – включение функциональности ведения заказов переработчикам. Система допускает беззаказное оформление переработчки, но отключение этих заказов возможно только если отключено использование собственного производства.

Не закрывать частично отработанные заказы переработчикам, Не закрывать частично оплаченные заказы переработчикам – настройка контроля закрытия заказов переработчикам.

### Обособление материалов при использовании заказов переработчикам

На складе – определяет назначение при обособленном обеспечении заказа переработчику. Доступны варианты: по направлению деятельности, по заказу переработчику, по переработчику / договору, по назначению продукции

У переработчика – определяет обособление материалов, переданных переработчику. Доступны варианты **не обосабливать**, **по заказу переработчику**.

## Производственные затраты

Валюта расценок видов работ сотрудников – определяет валюту, в которой задаются расценки трудозатрат.

Плановые цены продукции и отходов – используется для заполнения цен выпуска по фиксированной стоимости.

Плановые калькуляции при выпуске продукции – использование цен из плановых калькуляций при выпуске.

Аналитический учет по группам (видам) продукции – возможность разделения прямых затрат по группам аналитического учета.

## Статусы документов

Статусы актов выполненных внутренних работ – включает использование статусов для документов Акт выполненных внутренних работ.

Статусы движений продукции и материалов – включает использование статусов для документов Движение продукции и материалов.
