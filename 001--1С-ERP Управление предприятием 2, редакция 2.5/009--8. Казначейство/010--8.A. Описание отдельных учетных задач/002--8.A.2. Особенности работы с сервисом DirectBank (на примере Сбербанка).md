# Особенности работы с сервисом DirectBank (на примере Сбербанка)

## 1С:ДиректБанк – цели , преимущества и возможности сервиса

Технология DirectBank была разработана для того, чтобы облегчить работу пользователей программ «1С:Предприятия» при взаимодействии с банками.

1С:ДиректБанк – это механизм прямого электронного документооборота с банком, целью которого является предоставление пользователю возможности отправлять и получать банковские документы нажатием одной кнопки непосредственно из программ системы «1С:Предприятия».

В отличие от технологии [Клиент-Банк](http://v8.1c.ru/edi/edi_app/30/), работа с сервисом 1С:ДиректБанк не требует установки и запуска дополнительных программ на клиентский компьютер, позволяет избежать выгрузки документов в промежуточные файлы.

При работе с сервисом предоставляется возможность:

■ формировать, подписывать электронной подписью и отправлять платежные поручения прямо на сервер банка;

■ узнавать о статусе платежей, не выходя из программы «1С», получать банковские выписки в режиме онлайн;

■ отправлять в банк заявки на открытие счетов и реестры на зачисление зарплаты работникам организации в рамках зарплатных проектов банка;

■ использовать единый пользовательский интерфейс для управления всеми счетами, открытыми в разных банках;

■ обеспечивать повышенный уровень безопасности, так как подписание электронных документов проводится прямо в «1С:Предприятии 8» (для варианта с использованием криптографии);

■ обеспечивать высокую скорость обмена информацией с банком и возможность работы в одном окне - знакомый интерфейс, привычные команды и ничего лишнего.

Работа с технологией предоставляется в рамках сервиса [1С:ДиректБанк](https://portal.1c.ru/applications/44), входящего в состав Информационно-Технологического Сопровождения (ИТС).

Подробнее с информацией об использовании сервиса [1С:ДиректБанк](https://portal.1c.ru/applications/44) можно ознакомиться по ссылке:

[http://v8.1c.ru/edi/edi\_app/bank/to\_start.htm](http://v8.1c.ru/edi/edi_app/bank/to_start.htm)

## Помощник подключения к сервису 1С:ДиректБанк

Для выполнения подключения к обмену электронными документами с банком, в разделе НСИ и администрирование – Настройка интеграции – Обмен электронными документами требуется установка функциональной опции Обмен с банками - Сервис [1С:ДиректБанк](https://portal.1c.ru/applications/44). При этом становиться доступна гиперссылка Настройки обмена с банками, открывающая окно, из которого по команде Создать возможен переход к форме Помощник подключения к сервису [1С:ДиректБанк](https://portal.1c.ru/applications/44).

Команда Далее обеспечивает доступ к следующему шагу настройки подключения, где из предложенного списка требуется выбрать организацию и банк, для которых будет выполнена настройка обмена.

Далее программа предложит заполнить реквизиты, относящиеся к ранее выбранному банку. Поскольку, взаимодействие с каждым банком реализовано по-разному, для каждого из них предусмотрены свои реквизиты установления соединения, шифрования и передачи данных.

Способы создания настроек обмена с сервисом [1С:ДиректБанк](https://portal.1c.ru/applications/44) могут быть следующими:

■ автоматическое получение с сервера банка;

■ загрузка из файла;

■ заполнение параметров вручную.

Форма Помощник подключения к сервису [1С:ДиректБанк](https://portal.1c.ru/applications/44) доступна так же из:

■ карточки банковского счета организации на вкладке Настройка обмена с банком (включен) при включенной опции Сервис [1С:ДиректБанк](https://portal.1c.ru/applications/44) (рекомендуется) по ссылке Подключить;

■ рабочего места Выгрузка в банк (Казначейство – Банк – Безналичные платежи – Выгрузка и загрузка платежей – Выгрузка в банк)по ссылке [1С:ДиректБанк](https://portal.1c.ru/applications/44) – Подключить банки.

После того, как настройки подключения к сервису выполнены, необходимо убедиться в том, что прямой обмен данными с банком включен, то есть в карточке банковского счета организации на вкладке Настройка обмена с банком установлена опция Сервис [1С:ДиректБанк](https://portal.1c.ru/applications/44) (рекомендуется).

При возникновении проблем с обменом проверить работоспособность настроек можно с помощью команды Проверить в форме Организация – Банк (Настройка обмена с банком), доступной по соответствующей гиперссылке из карточки банковского счета.

Успешным результатом выполнения данной команды будет вывод служебного сообщения «Тест выполнен успешно».

## Отправка в банк платежных поручений

Отправка в банк платежных поручений, созданных в журнале Казначейство – Безналичные платежи,  может осуществляться:

■ отдельными платежами из формы каждого документа по команде 1С:ДиректБанк – Отправить электронный документ. В момент выполнения этой команды происходит создание и отправка в банк на обработку электронного документа, который так же может быть сформирован по команде Создать электронный документ.

■ Списком документов, выбранных в журнале, по команде 1С:ДиректБанк – Отправить электронный документ.

■  Списком документов из рабочего места обмена с банком Казначейство – Безналичные платежи - Выгрузка и загрузка платежей – Выгрузка в банк. При этом в открывшейся форме Выгрузка платежей в банк необходимо сначала отметить флагом банковский счет, по которому будет осуществляться обмен, а затем из списка ниже выбрать платежные поручения для выгрузки в банк. Отправка документов на оплату выполняется по команде Выгрузить платежи. В момент соединения с сервером банка система запросит данные аутентификации и ввод SMS-пароля, после чего сформирует сообщение об отправке.

Если перед установлением сеанса связи с банком было отмечено одновременно несколько банковских счетов, то выгрузка платежных поручений будет осуществлена по тем выбранным счетам, для которых настроен прямой обмен с банком и созданы платежные документы. При формировании пакета платежей красным цветом выделяются те из них, которые не могут быть выгружены в банк.

Важно помнить, что все документы Списание безналичных денежных средств, отправляемые в банк для оплаты, должны быть предварительно проведены в оперативном учете.

Проверить список выгруженных документов можно при помощи Отчета о выгрузке платежей, доступного из формы Выгрузка платежей в банк по команде Документы к выгрузке / Отчет о выгрузке.

## Получение выписки банка

Загрузка выписки банка осуществляется в рабочем месте Казначейство – Безналичные платежи - Выгрузка и загрузка платежей – Загрузка выписки по команде Загрузить платежи. Перед выполнением данной команды следует указать период загрузки выписки, а также, при необходимости автоматического:

■ создания новых контрагентов по информации о плательщике / получателе платежа - установить флаг Создавать контрагентов автоматически;

■ проведения загруженных банковских документов в информационной базе - отметить флаг Проводить документы.    

Информация об операциях по расчетному счету поступает из банка в виде электронного реестра платежей (выписки банка), по данным которого в журнале Казначейство – Безналичные платежи формируются документы Поступление безналичных денежных средств и Списание безналичных денежных средств. При этом механизм обмена [1С:ДиректБанк](https://portal.1c.ru/applications/44) проверяет наличие в журнале за период загрузки уже проведенных документов и добавляет только те, которые не были созданы пользователем.

В процессе загрузки документов происходит автоматическое распознавание поступивших платежей по следующему алгоритму:

■ Из всех платежей выделяются те, которые являются поступлениями оплаты от клиентов, их идентификация осуществляется по уникальному идентификатору платежа (УИП). При наличии в реестре платежа с УИП по нему однозначно определяется, что это оплата от клиента, формируется документ безналичного поступления денежных средств, в котором заполняется Назначение платежа.

■ Для остальных платежей выполняется отбор «по образцу», то есть осуществляется поиск аналогичных оплат с указанием поставщика / получателя, расчетного счета, назначения платежа и др., и «зеркальный» поиск по сочетанию платежных реквизитов. Таким образом, выявляются и распознаются повторяющиеся платежи, например, расчеты по аренде, с бюджетом и т.п., а так же операции возврата оплаты клиенту или возврата от поставщика.

■ В ситуации неудачного поиска платежа «по образцу» для него производится попытка подобрать объект расчетов, и в случае успеха считается, что это оплата от партнера. Дальнейшее заполнение информации о хозяйственной операции выполняется на основании данных о партнере.

■ Для платежей, которые так и не удалось идентифицировать, информация о хозяйственной операции требует заполнения вручную.

Проверить результат загрузки банковской выписки можно из формы Загрузка выписки банка, вкладка Загруженные документы или при помощи Отчета о загрузке платежей (команда Документы выписки / Отчет о загрузке).

## Получение электронных платежных документов с отметкой банка об исполнении

В момент отправки платежей в банк к каждому успешно выгруженному документу Списание безналичных денежных средств формируется электронное платежное поручение, открыть которое можно из журнала Безналичные платежи или из формы самого документа по команде [1С:ДиректБанк](https://portal.1c.ru/applications/44) – Просмотреть электронный документ.

Для того, чтобы после проведения оплаты банком, получить электронное платежное поручение со штампом банка об исполнении, необходимо:

■ сначала загрузить выписку банка за соответствующий период, так как данные для отображения штампов находятся в файле выписки;

■ затем перейти в форму просмотра электронного документа и воспользоваться командой Еще – Печать электронного документа.

При этом важно отметить, что электронные платежные поручения могут быть сформированы только для тех документов, которые были созданы в информационной базе и выгружены с использованием сервиса [1С:ДиректБанк](https://portal.1c.ru/applications/44). Так, например, для входящих платежей и ордеров на списание комиссии банка, добавляемых в журнал платежей при загрузке выписки, электронные документы не создаются, а при попытке их принудительного формирования на экране отображается служебное сообщение «Актуальный электронный документ не найден».

## Получение состояний отправленных платежных поручений

Статусы платежных поручений, отправленных на оплату в банк, доступны для просмотра из формы электронного документа, открываемой по команде [1С:ДиректБанк](https://portal.1c.ru/applications/44) – Просмотреть электронный документ, на вкладке Подписи и статусы.

По умолчанию статусы платежных поручений обновляются автоматически при каждом сеансе связи с банком (например, в момент загрузки выписки банка или отправки платежей).

Для принудительного запуска процедуры обновления состояний документов предусмотрена команда [1С:ДиректБанк](https://portal.1c.ru/applications/44) - Синхронизировать с банком, доступная из рабочего места Казначейство – Безналичные платежи.

Данная команда так же доступна для использования в окне Электронные документы, которое открывается при переходе в него из формы электронного документа по кнопке Открыть электронные документы, расположенной в верхнем левом углу формы.

## Отзыв ранее отправленных платежных поручений

Отзыв платежных документов, ранее отправленных в банк на оплату, возможен только для прямого обмена с банком, поддерживающим такую возможность. Отзыв осуществляется при помощи команды Еще - Отозвать электронный документ, доступной из формы просмотра электронного документа.

## Сценарии работы пользователя по технологии 1С:ДиректБанк

Наиболее часто используемыми сценариями работы с сервисом 1С:ДиректБанк является отправка в банк платежных документов и получение банковских выписок с использованием электронно-цифровой подписи (ЭЦП) в «1С» и без нее. Оба сценария очень близки и состоят из последовательности следующих шагов:

■ создание платежных поручений;

■ выгрузка платежей в банк поштучно или списком документов из журнала Безналичные платежи с использованием команды 1С:ДиректБанк – Отправить электронный документ, а так же списком из рабочего места Выгрузка платежей в банк;

■ ввод пароля для доступа к закрытому ключу сертификата ЭЦП, а затем пароля для входа на сервер банка;

■ если работа с сервисом обмена осуществляется без использования электронной подписи, то доступ к закрытому ключу сертификата ЭЦП не требуется, но в целях безопасности необходим ввод одноразового пароля для подтверждения операций по SMS;

■ получение выписки банка из рабочего места Казначейство – Безналичные платежи - Выгрузка и загрузка платежей – Загрузка выписки по команде Загрузить платежи.

■ прохождение процесса аутентификации так же, как и при отправке в банк платежных поручений.

С более подробной информацией о том, как начать использовать технологию 1С:ДиректБанк можно ознакомиться по ссылке:

[http://v8.1c.ru/edi/edi\_app/bank/to\_start.htm](http://v8.1c.ru/edi/edi_app/bank/to_start.htm)
