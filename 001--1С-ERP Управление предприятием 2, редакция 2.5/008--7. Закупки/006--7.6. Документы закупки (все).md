# Документы закупки (все)

Для комплексной работы с документами закупки предназначено рабочее место Закупки - Закупки – Документы закупки (все), в котором отображаются все оформленные документы закупки и соответствующие им хозяйственные операции, отраженные этими документами (например, документом Приобретение товаров и услуг отражена операция Закупка у поставщика и т. п.).

В списке отображаются только те виды документов, которые доступны пользователю, а также включено их использование с помощью функциональных опций.

В рабочем месте можно отобрать виды документов (режим По видам документов) или хозяйственные операции (режим По хоз. операции), которые необходимы для работы пользователей. Выбор видов документов и хозяйственных операций выполняется в форме, доступной по гиперссылке Настроить. По результатам установленного отбора в шапке рабочего места показывается надпись о количестве показанных документов и хозяйственных операций (например, «Показаны 11 хоз. операций по 3 документам»).

Если выбран только один вид документа, то при создании нового документа будет отображаться только список возможных хозяйственных операций этого документа.

Из рабочего места Документы закупки (все) по соответствующим гиперссылкам можно перейти к рабочим местам:

■ Заявления о ввозе – переход к рабочему месту Заявления о ввозе товаров из ЕАЭС к оформлению, в котором показывается список  документов Приобретение товаров и услуг с типом операции Ввоз из ЕАЭС, по которым необходимо зарегистрировать заявления на ввоз из стран Таможенного союза.

■ Приобретения – переход к рабочему месту Накладные к оформлению (закладка К оформлению приобретения (приемки)).

■ Поступления товаров \- переход к рабочему месту Накладные к оформлению (закладка К оформлению поступления).

■ Контроль ордеров - переход к рабочему месту Накладные к оформлению (закладка Контроль ордеров).

■ ГТД импорт – переход к рабочему месту Таможенные декларации на импорт к оформлению, в котором показывается список документов Приобретение товаров и услуг с типом операции Импорт, по которым необходимо зарегистрировать таможенную декларацию.

■ Выкупы – переход к рабочему месту по оформлению передач и выкупов товаров по распоряжениям (документов Выкуп товаров с хранения).

■ Списание с хранения – переход к рабочему месту по оформлению документов Списание товаров с хранения.
