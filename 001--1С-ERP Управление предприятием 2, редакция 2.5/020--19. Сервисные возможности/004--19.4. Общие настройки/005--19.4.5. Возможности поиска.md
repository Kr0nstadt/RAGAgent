# Возможности поиска

Предусмотрены различные варианты поиска, которые различаются своими возможностями, назначением и точкой входа:

■ Поиск в списках – предназначен для поиска по содержимому колонок списка. Для начала поиска необходимо ввести текст в поле быстрого отбора или нажать Ctrl + F или Alt + F (в зависимости от списка). В отдельных списках, например Номенклатура, предусмотрены дополнительные возможности и  настройки поиска и отбора.

■ Глобальный поиск (поле поиска в строке заголовка программы) – предназначен для поиска объектов информационной базы, настроек (пункт Найти в настройках…), справочной информации, в том числе на в 1С:ИТС (пункт Найти на сайте 1С:ИТС)

Дополнительные возможности поиска в списке Номенклатуры рассмотрены в разделе См. [Настройки поиска в списках номенклатуры](/db/erp25doc/bookmark/goods/GoodListSEarch)

Для перехода к результатам поиска на ИТС необходимо выбрать в результатах поиска пункт Найти на сайте 1С:ИТС, после чего открывается сайт ИТС с результатами поиска.

Для перехода к результатам поиска по панелям настройки необходимо выбрать в результатах поиска пункт Найти в настройках…, после чего в списке поиска отображаются результаты поиска в панелях настройки. В случае, если найдена функциональная опция при переходе по строке результата поиска открывается соответствующая форма настроек с переходом к найденной опции. Если найден элемент настройки подразделений и складов в результатах поиска отображаются элементы соответствующего справочника. При переходе по результатам поиска открывается форма выбранного склада или подразделения (без перехода к элементу формы). В случае поиска по элементам учетной политики в результатах поиска отображаются настройки соответствующей учетной политики по организациям. Дополнительно отображается команда создания новой настройки.

При переходе по результатам поиска открывается форма  учетной политики (без перехода к элементу формы). При выборе команды Создать… откроется форма создания новой учетной политики.

## Полнотекстовый поиск

Предоставляется возможность полнотекстового поиска в любых объектах конфигурации и их реквизитах, а также (при наличии) в присоединенных файлах, содержащих текстовую информацию. Возможности поиска расширены с учетом транслитерации, замещения части символов в русских словах одноклавишными латинскими символами и нечеткого поиска.

В режиме полнотекстового поиска используются поисковые операторы ("И", "ИЛИ", "НЕ", "РЯДОМ"). Для поиска по части слова используются подстановочные символы («\*»).

Примечание

Без указания подстановочного символа будет выполняться поиск по указанному слову, а вхождения указанного слова как части в другие слова учтены не будут.

Если не указаны никакие операторы (слова набраны через пробел), программа осуществляет поиск всех слов из запроса с использованием оператора "И".

См. также: [Полнотекстовый поиск в "1С:Предприятии 8.1"](https://buh.ru/articles/documents/14128/)

Поиск выполняется по всем реквизитам, для которых в конфигурации включено использование полнотекстового поиска.

### Настройка построения полнотекстового индекса

Для использования полнотекстового поиска необходима настройка построения полнотекстового индекса, которая выполняется администратором системы. Данная настройка определяется включением функциональной опции НСИ и администрирование – Администрирование – Общие настройки – Поиск данных – Полнотекстовый поиск данных с последующим переходом по ссылке Настроить.

Процедура актуализации индекса полнотекстового поиска доступна по кнопке Обновить индекс на форме Управление полнотекстовым поиском и извлечением текстов. Автоматическое обновление индекса выполняется с помощью встроенного регламентного задания. Удаление индексных файлов возможно по кнопке Очистить индекс.
