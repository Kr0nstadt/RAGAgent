# Версионирование объектов

В конфигурации ведется история изменений объектов информационной базы, которая позволяет отследить их состояние, то есть ответить на вопросы: кем, когда и какие изменения были внесены при работе с ними?

Версионируемыми объектами могут быть справочники и документы. Возможен как просмотр любой версии объекта, так и сравнение разных версий объекта между собой. Эта работа предполагает два этапа: настройка версионирования и просмотр истории изменений, причем запись версий объектов происходит автоматически в соответствии с настройками, заданными на первом этапе.

## Настройка версионирования объектов

Версионирование объектов определяется установкой функциональной опции НСИ и администрирование – Администрирование – Общие настройки – История изменений – Хранить историю изменений, после включения которой становится доступна гиперссылка Настройки хранения, обеспечивающая переход к форме Настройки хранения истории изменений.

По команде Установить, когда сохранять версии на указанной форме предлагаются следующие варианты настройки версионирования:

■ Никогда – не вести историю версий объекта;

■ По умолчанию – установить рекомендуемые настройки (для справочников – никогда, для документов – при проведении, для бизнес-процессов – создавать версии при старте);

■ При записи – новую запись заносить в [историю](/db/content/erp25doc/idfa7a11cc-7ee0-4550-8d0d-9c7464d57a37/038b5c85-fb1c-4082-9c4c-e69f8928bf3a) версий каждый раз при изменении (или создании нового) справочника или документа;

■ При проведении (для документов) – сохранять версии только при проведении документов, для которых проведение применимо.

Если у документа установлен режим Версионировать при проведении, то первая версия документа будет создана после первого проведения документа. Впоследствии версии документа будут создаваться при каждой записи проведенного документа. Режим позволяет не создавать версии новых и не заполненных окончательно пользователем документов, чтобы не увеличивать размер информационной базы.

Команда Установить вариант версионирования – По умолчанию восстанавливает те варианты версионирования, которые были предусмотрены для объектов на этапе проектирования.

Для каждого типа документов и справочников версии можно хранить: За последнюю неделю, За последний месяц, За последние три месяца, За последние шесть месяцев, За последний год и Бессрочно – период выбирается по команде Установить срок хранения версий.

Для просмотра статистики хранимых версий объектов предусмотрен отчет Количество и объем хранимых версий объектов, доступный по одноименной гиперссылке на форме Настройки хранения истории изменений.
