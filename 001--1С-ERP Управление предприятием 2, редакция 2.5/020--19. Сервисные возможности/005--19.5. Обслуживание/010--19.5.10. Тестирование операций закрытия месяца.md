# Тестирование операций закрытия месяца

В системе присутствует служебная обработка Тестирование операций закрытия месяца. Обработка предназначена для того, чтобы выявить:

● как изменятся имеющиеся в базе данные после выполнения операций закрытия месяца;

● какие ошибки будут диагностированы при выполнении операций закрытия месяца.

Обработка Тестирование операций закрытия месяца выполняет выбранные пользователем регламентные операции процедуры Закрытие месяца за указанный в ней период. Операции выполняются сразу для всех организаций, учет по которым ведется в информационной базе. При этом:

● имеющиеся в базе данные сохраняются во временные таблицы;

● создаются задания к выполнению выбранных регламентных операций;

● выполняются выбранные регламентные операции;

● результаты расчетов записываются в соответствующие регистры;

● новые данные в базе сравниваются с данными из временных таблиц;

● формируются файлы, демонстрирующие различие в данных до и после выполнения обработки;

● формируются файлы с описанием ошибок, препятствующих закрытию месяца.

Обработка Тестирование операций закрытия месяца может применяться, например, для анализа того, как изменятся данные в базе после внесения доработок в код системы.

Внимание

Обработка **Тестирование операций закрытия месяца** должна применяться квалифицированным администратором базы данных.

Не рекомендуется применять обработку **Тестирование операций закрытия месяца** на рабочих базах.

Перед запуском обработки **Тестирование операций закрытия месяца** рекомендуется сделать резервную копию базы.

Обработка Тестирование операций закрытия месяца доступна в меню Функции для технического специалиста.

На закладке Параметры тестирования настраиваются:

● период, за который помесячно будут выполнены регламентные операции;

● Каталог ошибок – адрес каталога, в который будут сохраняться файлы с описанием ошибок, выявленных в процессе выполнения регламентных операций;

● Рабочий каталог - адрес каталога, в который будут сохраняться файлы с расхождениями в данных до и после выполнения обработки.

На закладке План тестирования настраивается состав регистров, которые необходимо протестировать и выявить расхождения.

После запуска обработки в процессе ее выполнения доступна закладка Длительные операции, на которой по кнопке Отменить задание можно прервать выполнение операций.

После выполнения обработки на закладке План тестирования отображаются сведения о найденных расхождениях по каждому регистру, в т.ч. количество найденных расхождений, ссылка на отчет и путь к файлу с расхождениями.

По гиперссылке в колонке Расхождения доступен переход к отчету с описанием выявленных расхождений.
