# Регламентные задания

Ряд действий выполняются в информационной базе автоматически – регламентными заданиями по определенному расписанию. В соответствии с расписанием регламентное задание порождает фоновое задание, которое и выполняет заданные действия.

Настройка и использование регламентных заданий выполняются администратором системы.

## Настройка регламентных заданий

Настройка регламентных заданий выполняется в форме, доступной по ссылке НСИ и администрирование – Администрирование – Обслуживание – Регламентные операции – Регламентные и фоновые задания. Форма настройки позволяет:

■ редактировать состав и расписание регламентных заданий – команда Настроить расписание на закладке Регламентные задания;

■ запускать фоновые задания и контролировать их состояние (флажки Выполнено, Завершено с ошибками, Отменено, Выполняется) – закладка Фоновые задания. Отбор фоновых заданий производится по команде Обновить, поэтому после изменения настройки отбора необходимо выполнение этой команды.

Для каждого регламентного задания поддерживается создание однократного и периодического расписания. В рамках расписания можно задать интервал дат, времени, периодическое повторения по дням недели и месяцам.

Автоматический запуск регламентного задания регулируется установкой флажка Включено на форме задания.

Также в форме можно указать число повторов и временной интервал запусков задания при возникновении ошибок в процессе его выполнения.  

Список можно расширять, добавляя регламентные задания с использованием предопределенных шаблонов.

Можно добавлять в список два и более экземпляра одного регламентного задания (например, если необходимо задать два разных расписания).

Также в форме задания можно указать число попыток выполнения регламентного задания и временной интервал между ними при возникновении нештатной ситуации в процессе выполнения.

Для клиент-серверного варианта работы можно указать пользователя информационной базы, который будет задействован для выполнения регламентного задания. Для файловой информационной базы используется текущий пользователь для выполнения всех регламентных заданий.

Остальные поля формы носят служебный характер и недоступны для редактирования. Более подробно с назначением этих полей можно ознакомиться во встроенной справочной системе.

## Исполнение регламентных заданий

Запуск и исполнение регламентных заданий различаются для разных версий «1С:Предприятия»:

■ в клиент-серверном варианте запуск происходит автоматически;

■ в файловом варианте для выполнения заданий по расписанию необходимо наличие запущенного клиентского сеанса.

Команда Выполнить сейчас позволяет выполнить любое регламентное задание в текущем сеансе (для файловой информационной базы) либо в фоновом режиме на сервере (для серверной информационной базы).

На закладке Фоновые задания есть возможность проконтролировать выполнение фоновых заданий. Для этого можно воспользоваться отбором фоновых заданий по интересующему регламентному заданию, периоду выполнения задания, состоянию (Выполнено, Завершено с ошибками, Отменено, Выполняется).

Отбор фоновых заданий производится только по команде Обновить, поэтому после изменения настройки отбора нужно выполнить эту команду. В нижней части списка отображается общее число фоновых заданий и число отобранных заданий.
