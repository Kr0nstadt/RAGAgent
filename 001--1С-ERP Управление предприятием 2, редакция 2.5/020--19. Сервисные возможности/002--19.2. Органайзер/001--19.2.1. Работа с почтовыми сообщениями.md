# 19.2.1. Работа с почтовыми сообщениями

_Source: about:srcdoc_

# Работа с почтовыми сообщениями

Прикладное решение предоставляет базовый функционал по работе с электронной почтой, возможность использования которого пользователями предполагает выполнение предварительной настройки учетных записей администратором системы.

Например, можно отправлять по электронной почте печатные формы, формируемые в системе; отправлять электронные письма администратору по завершении обновления системы и после формирования отчета с критичными записями журнала регистрации; выполнять обмен данными между информационными базами с помощью электронной почты.

## Настройка учетных записей

Настройка учетных записей осуществляется в форме НСИ и администрирование – Администрирование – Органайзер – Почта – Настройка почты.

Настройка учетной записи производится в пошаговом помощнике, в котором последовательно указываются следующие данные:

■ На первом шаге указывается Адрес электронной почты

■ На втором шаге указываются:

● Имя отправителя писем       (будет отображаться в строке адреса отправителя вместе с адресом, например «Сергей Иванович Иванов»;

● Вариант использования: Всеми пользователями (общая почта) или Только мной (текущим пользователем);

○ Флаг Использовать для получения писем (если не установлен, то учетная запись используется только для отправки писем);

○ Адрес электронной почты – адрес электронной почты учетной записи.

■ На третьем шаге указывается Пароль к учетной записи

■ При переходе к следующему шагу выполняется попытка автоматически выполнить настройку подключения (адреса серверов, порты и т.д.). В случае успешной автоматической настройки (для большинства публичных почтовых сервисов) можно завершить работу с формой настройки.

В случае невозможности автоматической настройки или в случае необходимости задать настройки, отличные от устанавливаемых по умолчанию, можно в помощнике подключения по кнопке Перейти к настройкам открыть форму всех настроек учетной записи.

В форме настроек учетной записи можно ограничить использование учетной записи для рассылки или для получения сообщений (флаги Для отправки писем и Для получения писем) – например, если системная учетная запись используется только для рассылки писем, а получение почты происходит на почтовые ящики пользователей.

Для проверки введенных параметров учетной записи можно использовать команду Проверка настройки.

## Отправка и получение писем электронной почты

Работа с почтовыми сообщениями возможна в следующих случаях:

■ отправка в качестве вложений печатных форм, формируемых в информационной базе;

■ автоматическая отправка писем администратору системы;

■ обмен данными между информационными базами;

■ автоматическая рассылка уведомлений о новых задачах и о задачах, не исполненных в срок.
