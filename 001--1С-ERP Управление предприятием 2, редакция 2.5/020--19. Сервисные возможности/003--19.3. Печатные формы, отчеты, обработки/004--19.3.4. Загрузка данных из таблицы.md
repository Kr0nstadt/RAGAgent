# 19.3.4. Загрузка данных из таблицы

_Source: about:srcdoc_

# Загрузка данных из таблицы

Загрузка данных из таблицы может применяться для начального заполнения справочников, а также для заполнения табличных частей документов.

При начальном заполнении информационной базы в форме НСИ и администрирование – Начальное заполнение – Начальное заполнение – Загрузка данных из файла доступна загрузка элементов отдельных справочников. После выбора вида справочника открывается форма, в которой можно выбрать один из двух режимов работы:

■ Заполнение таблицы – данные копируются через буфер обмена непосредственно в таблицу на форме.

■ Загрузка из файла – данные загружаются из внешнего файла. Поддерживаются распространенные форматы табличных документов. Поля таблицы должна соответствовать реквизитам справочника, в который загружаются данные. Предварительно можно воспользоваться кнопкой Сохранить бланк для заполнения, чтобы создать файл с соответствующими заголовками столбцов для выбранного вида справочника.

При загрузке элементов справочника установлен минимально необходимый набор обязательных реквизитов. Остальные реквизиты не обязательны для заполнения.

После загрузки данных программа производит автоматическое сопоставление данных. Если автоматическое сопоставление не состоялось, то данные выводятся для сопоставления вручную. Для того чтобы просмотреть сопоставленные или несопоставленные данные, можно использовать отбор с помощью поля Показывать. Несопоставленные данные помечаются красным. С помощью соответствующей кнопки можно Разрешить неоднозначность. Для этого в таблице выводятся совпадающие элементы. Необходимо выбрать один из них для загрузки. Для того чтобы вручную сопоставить данные, откройте соответствующий список программы, найдите в нем подходящее значение или введите новое.

После автоматического или ручного сопоставления данных, в случае, если все данные сопоставлены, нажмите кнопку Загрузить данные. После этого данные будут загружены в документ или список. Остается лишь заполнить недостающие поля.
