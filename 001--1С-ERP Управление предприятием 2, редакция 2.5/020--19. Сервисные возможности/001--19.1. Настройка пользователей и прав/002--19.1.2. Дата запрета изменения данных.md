# 19.1.2. Дата запрета изменения данных

_Source: about:srcdoc_

# Дата запрета изменения данных

Для предупреждения случайного или несанкционированного изменения данных информационной базы в предшествующих периодах требуется установка запрета редактирования записей до определенной даты.

Например, после сдачи бухгалтерской отчетности целесообразно установить запрет изменения данных до даты окончания отчетного периода.

Возможность установки даты запрета предусмотрена функциональной опцией НСИ и администрирование – Администрирование – Поддержка и обслуживание – Регламентные операции – Даты запрета изменения.

Внимание

Дата запрета редактирования распространяется только на проводкообразующие документы.

Выбор даты осуществляется в форме Даты запрета изменения данных, доступной по гиперссылке Настроить, и может быть выполнен в одном из следующих режимов:

■ Не установлены – означает отсутствие ограничений на редактирование записей и операций любого периода;

■ Для всех пользователей – запрещает всем пользователям информационной базы изменение данных, внесенных до установленной даты включительно;

■ По пользователям – допускает персональную настройку дат запрета ввода и редактирования информации в разрезе пользователей. Добавление пользователей в группу настройки осуществляется по кнопке Подобрать.

Дату запрета изменений можно устанавливать как для всех пользователей программы (здесь и далее в разделе «пользователями» именуются в том числе и внешние пользователи), так и для конкретного пользователя или группы пользователей. Если дата запрета изменения данных установлена, то при попытке внести изменения в информационную базу до указанной даты пользователю выводится сообщение о невозможности изменения данных. Ниже различные варианты настройки даты запрета изменений рассмотрены более детально.

## Установка даты запрета изменений в разрезе пользователей

Установка даты запрета для всех пользователей информационной базы выполняется в режиме Для всех пользователей. Дата запрета изменения данных для всех пользователей указывается в поле Дата запрета. Если дата запрета не установлена, то ограничения не действуют.

В поле Дата запрета помимо числового предусмотрен также ввод относительного значения, например: Конец прошлого года, Конец прошлого квартала, Конец прошлого месяца, Конец прошлой недели и Предыдущий день.

Существуют ситуации, когда разным пользователям необходимо устанавливать разные значения даты запрета изменений. Например, установка даты запрета изменений может потребоваться для всех пользователей программы, кроме администраторов. В таких случаях необходимо выбрать режим По пользователям в форме установки даты запрета изменения данных.

При этом в форме будет доступен список, в который можно добавлять пользователей информационной базы (группы пользователей) (команда Подобрать) и настраивать для каждого из них свое значение даты запрета изменений.

## Другие способы указания даты запрета изменений

В режимах выбора даты запрета Для всех пользователей и По пользователям в разделе Другие способы указания даты запрета доступны дополнительные способы ее выбора, а именно:

■ Общая дата – устанавливается одна дата запрета для всех элементов данных информационной базы;

■ По разделам – выбирается своя дата для каждого раздела системы (Банк, Касса, Продажи и Закупки и т. д.);

■ По разделам и объектам – дата может быть задана не только для разделов, но и для объектов информационной базы.

В случае выбора варианта По разделам или По разделам и объектам отображается предопределенный список разделов, по которым можно задать дату запрета. В режиме По разделам и объектам дополнительно доступна команда Подобрать, по которой можно для каждого раздела учета указать организации и даты запрета, которые будут применяться для данной организации и раздела.

Сводная информация об установленных датах запрета изменения данных представлена в отчете Дата запрета изменения данных по пользователям, доступном по команде Отчет на форме Дата запрета изменения данных.
