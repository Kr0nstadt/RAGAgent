# Запрет редактирования реквизитов объектов

У ряда объектов информационной базы имеются так называемые «ключевые» реквизиты, то есть те, которые определяют характер данного объекта и влияют на поведение других объектов. Например, реквизит Валюта кассы определяет валюту остатков по кассе и не может быть изменен после начала учета в ней движения денежных средств.

С целью предупреждения необдуманных изменений «ключевых» реквизитов после записи объекта их дальнейшее редактирование будет запрещено. Таким образом, значения реквизитов устанавливаются только при создании объекта.

Если же в процессе работы все-таки возникает необходимость изменить значение «ключевого» реквизита, то такая возможность доступна по команде Еще – Разрешить редактирование реквизитов на форме объекта для пользователей с ролью Полные права. При высоком риске нарушения связей между разными объектами информационной базы перед изменением значений «ключевых» реквизитов на форме возможен дополнительный анализ поиска связей и использования редактируемой записи.

В случае обнаружения таких связей система предупреждает пользователя о возможном рассогласовании данных информационной базы после изменения значений «ключевых» реквизитов. Если риск рассогласования данных оценивается как большой, рекомендуется отказаться от изменений и провести дополнительный анализ с помощью команды Поиск ссылок на объекты (главное меню – Все функции).
