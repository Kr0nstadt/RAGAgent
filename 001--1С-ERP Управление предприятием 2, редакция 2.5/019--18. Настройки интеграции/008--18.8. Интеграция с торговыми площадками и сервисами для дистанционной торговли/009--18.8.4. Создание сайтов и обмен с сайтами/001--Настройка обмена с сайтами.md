# Создание сайтов и обмен с сайтами

В целях поддержки электронной торговли в поставляемом решении предусмотрен механизм создания и публикации готовых сайтов. Механизм реализован в рамках отдельного сервиса по автоматизированному созданию и наполнению сайта в «один клик» – 1С-UMI, который доступен в меню НСИ и администрирование – Настройка интеграции – Обмен с сайтом.

При создании сайта требуется указать его тип (интернет-магазин, сайт компании, лендинг, сайт специалиста), а также имя и адрес почтового ящика, на который будет выслано служебное сообщение. В случае выбора типа сайта «интернет-магазин» дополнительно необходимо определить перечень данных, требующих публикации.

Кроме того, использование сервиса 1C-UMI обеспечивает автоматизированный двусторонний обмен данными и предоставляет инструменты управления сайтом с возможностью обновления данных по расписанию. Для этого пользователю должна быть назначена роль Полные права.

## Настройка обмена с сайтами

Началом настройки обмена данными является включение функциональной опции НСИ и администрирование – Настройка интеграции – Обмен с сайтом – Использовать обмен с сайтом.

Работа с настройками осуществляется в журнале Настройки обмена с сайтами, доступной по одноименной гиперссылке из рабочего места Обмен с сайтом.

Для созания сайта необходимо указать адрес электронной почты, на который будет выслан пароль и название домена магазина. При этом проверяется, чтоанный адрес свободен.

По кнопке создать сайт автоматически создается домен с указанным именем в сервисе 1C-UMI, а в программе автоматически будет создан узел обмена с вновь созданным сайтом в списке НСИ и администрирование – Настройка интеграции – Обмен с сайтом – Настройки обмена с сайтом.

Если у организации уже есть сайте, то узел обмена можно создать вручную в списке НСИ и администрирование – Настройка интеграции – Обмен с сайтом – Настройки обмена с сайтом. Также в этом списке можно редактировать или удалять настройки обмена данными с сайтом.

### Основные настройки обмена

В рамках обмена с сайтом может выполняться Выгрузка товаров и Обмен заказами.

В форме настройки обмена с сайтом настраивается режим обмена данных. При установленной опции Выгрузка товаров в рамках данного узла обмена каталог товаров на сайте будет автоматически заполняться и обновляется по данным номенклатурного справочника в программе. При установленном флажке Обмен заказами на основании созданных на сайте интернет-магазина заказов в программе будет автоматически создаваться документы [Заказ клиента](/db/erp25doc/bookmark/wholesale/CustomerOrders) (должна быть включена соответствующая функциональность), а по мере работе с заказом в программе, на сайте будет обновляться статус заказа. Для обмена данными необходимо установить как минимум один из этих флажков.

 

Предусмотрена возможность обмениваться с сайтом следующими способами:

■ непосредственно с сайтом (требуется подключение к сети Интернет) – режим Выгружать на сайт. В этом случае необходимо указать адрес сайта (например, для сайтов, построенных с помощью «1C-Битрикс: Управление сайтом», необходимо указать адрес вида http://www.example.com/bitrix/admin/1c\_exchange.php, где www.example.com – URL сайта, с которым производится обмен данными), имя пользователя сайта, под которым будет производиться подключение к сайту для обмена, и его пароль. C помощью команды Проверить соединение можно проконтролировать корректность введенных данных и узнать о возможности начать обмен с сайтом;

■ посредством выгрузки/загрузки данных через файлы (не требуется подключение к сети Интернет) – режим Выгружать в каталог на диске. В этом случае необходимо указать каталог на диске (поле Каталог выгрузки), в который будут выгружаться файлы обмена (при клиент-серверном варианте работы каталог выгрузки будет создан на сервере «1С»). Если предполагается обмен заказами, то дополнительно нужно указать полное имя файла с заказами (поле Файл загрузки заказов), который будет формироваться на сайте.

### Настройка выгрузки товаров

Для настройки выгрузки товаров на сайт необходимо в форме узла на закладке Выгрузка товаров указать организацию, от лица которой будут продаваться товары на сайте – поле Организация-владелец каталога товаров. Данные организации будут записаны в файл обмена.

На сайт можно выгружать файлы с изображением товара. Для выгрузки изображений на сайт необходимо установить режим опцию Файлы изображений. Режим Прочие файлыотвечает за выгрузку файла описания номенклатуры в формате html, который указывается в реквизите Файл описания для сайта справочника [Номенклатура](/db/erp25doc/bookmark/goods/Goods).

В режиме Все данные будет полностью обновлен каталог по данным программы. Это режим, в отличи от режима Изменения передает значительно больше данных и требует больше времени. При использовании режима Изменения в первый запуск рекомендуется Выполнить полный обмен данными (в меню Еще).

В табличной части Таблица каталогов можно задать произвольное имя каталога. Для каждого каталога может быть сформирован список значений отбора по группам или видам номенклатуры.

### Настройка обмена заказами

Для работы с заказами в интернет-магазине необходимо для документа Заказ клиента создать [дополнительные реквизиты](/db/erp25doc/bookmark/additionalrequisitesandinformation/AdditionalRequisitesAndInformation), в которых будут указываться дата (тип значения Дата) и номер (тип значения Строка) заказа на сайте. Сделать эту рекомендуется в форме НСИ и администрирование – Администрирование – Общие настройки – Свойства – Свойства. Далее созданные реквизиты необходимо указать в форме настройки узла обмена с сайтом на закладке Обмен заказами в полях Дата заказа на сайте и Номер заказа на сайте.

В информационной базе необходимо создать [Типовое соглашение об условиях продаж](/db/erp25doc/bookmark/rulesofsales/Agreements), в котором прописать все условия, по которому будут оформляться заказы, загружаемые из интернет-магазина. Для работы с соглашениями должна быть включена соответствующая функциональность. В соглашении на закладке Условия продаж необходимо выбрать детализацию расчетов По заказам, а также установить флажок Доступно для обмена с сайтом (в зависимости от настроек информационной базы может также называться Доступно внешним пользователям и для обмена с сайтом) на закладке Прочие условия. Далее его необходимо указать в форме настройки узла обмена с сайтом на закладке Обмен заказами в поле Соглашение. Также необходимо указать Организацию, по которой будут создаваться заказа. Кроме того, можно указать менеджера и склад, которые будут подставляться по умолчанию в документ.

При загрузке с сайта выполняется поиск в информационной базе контрагента, который соответствует указанному на сайте покупателю. Найденный контрагент будет указан в документе Заказ клиента. В настройках обмена с сайтом на закладке Обмен заказами указывается Способ поиска существующих элементов справочника «Контрагенты»:

■ Наименование;

■ ИНН/КПП.

Если контрагент не будет найден среди существующих, то будет создан новый элемент справочника Контрагенты. Также есть возможность одновременно Создавать партнеров для новых контрагентов.

На сайте интернет магазина может создаваться Для вновь создаваемой номенклатурной позиции можно задать следующие реквизиты по умолчанию (раздел Реквизиты для создания новых элементов справочника «Номенклатура»):

■ Вид номенклатуры для товаров;

■ Вид номенклатуры для услуг;

■ Единица измерения;

■ Группа номенклатуры (где в иерархии справочника будет создаваться номенклатура).

Оплата заказов может производиться на сайте интернет-магазина, причем интернет магазин может предполагать несколько вариантов оплаты (разные банки/платежные системы). На основании информации о выполненных на сайте оплатах можно автоматически создавать документы Эквайринговая операция. Для этого в форме настройки узла обмена с сайтом на закладке Обмен заказами необходимо установить флажок Загрузка онлайн оплаты и далее в таблице для каждого предусмотренного на сайте варианта оплаты указать его название и код на сайте, а также контрагента-эквайера и договор эквайринга, по которым будет создаваться в программе [Эквайринговая операция](/db/erp25doc/bookmark/acquiring/Acquiring). В договоре эквайринга на закладке Расчеты необходимо выбрать вариант Платежи принимаются через Интернет-эквайринг.

На закладке Дополнительно выполняются следующие настройки:

■ причина отмены заказа. Например, если с сайта будут загружаться отмененные заказы, то в настройках можно указать причину отмены, которая будет устанавливаться у таких заказов по умолчанию;

■ установка соответствия статусов заказов в информационной базе и на сайте. В поле Статус на сайте необходимо точно указать строкой значение статуса заказа на сайте, а в поле Статус в информационной базе выбрать соответствующий ему статус заказа в информационной базе. Если соответствие статусов установлено, то при загрузке заказа с сайта программа будет пытаться установить соответствующий статус у заказа клиента. В противном случае такая попытка предприниматься не будет.

■ Настройка Загружать формы оплат с сайта и таблица соответствия форм оплаты на сайте и в программе.

Обмен заказами происходит в два этапа: сначала происходит загрузка с сайта, затем выгрузка на сайт (или в каталог на диске). По заказам, загруженным с сайта, формируется документ Заказ клиента. При последующих сеансах обмена табличная часть заказа обновляется в соответствии с информацией, полученной с сайта. В ответном сообщении на сайт отправляется информация об оплате и отгрузке по заказам, ранее загруженным с сайта. Контрагенты и номенклатура, полученные с сайта, идентифицируются в соответствующих списках. Объекты, которые не найдены, создаются.

### Выполнение информационного обмена с сайтом

В форме узла обмена помимо настроек самого узла можно выполнить следующие действия:

■ Выполнить обмен – запускает процедуру обмена данными по настройкам, заданным в форме узла обмена;

■ Еще - Выполнить полный обмен данными – запускает процедуру обмена данными по настройкам, заданным в узле обмена, за исключением настройки Режим выгрузки данных;

■ Еще - Показать зарегистрированные изменения – отображает изменения в информационной базе, произошедшие с момента последнего обмена с сайтом. После выполнения команды будет открыта форма, где будет представлен список объектов, участвующих в обмене с сайтом, в которых зарегистрированы изменения. То есть тех объектов, которые будут выгружены на сайт в следующей сессии обмена. Любой объект (регистрацию изменения объекта) можно удалить из списка, и тогда информация об изменениях объекта не будет выгружаться на сайт.
