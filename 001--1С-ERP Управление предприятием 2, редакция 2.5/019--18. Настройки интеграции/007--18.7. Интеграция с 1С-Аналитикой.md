# Интеграция с 1С:Аналитикой

1С:Аналитика – это инструмент в составе платформы «1С:Предприятие» для решения задач оперативного просмотра и анализа данных. 1С:Аналитика –это дополнительный визуальный интерфейс для учетной системы на платформе «1С:Предприятие», позволяющий упростить процесс быстрого построения аналитических отчетов и оперативного анализа данных «на лету».

Описание сервиса: [https://v8.1c.ru/platforma/1s-analitika/](https://v8.1c.ru/platforma/1s-analitika/).

Документация к 1С:Аналитке на ИТС: [https://its.1c.ru/db/analytics](/db/analytics).

Упрощенно процесс настройки можно представить в следующем виде:

■ Установить веб-сервер: Appach или IIS

■ Опубликовать базу на веб сервере

■ Установить сервер 1С:Аналитика

■ Настроить в информационной базе отчеты, используемые в рамках интеграции с 1С:Аналитикой

■ Разослать коллегам, которые планируют работать не из информационной базы, адрес подключения к серверу 1С:Аналитики

Настройка интеграции выполняется в разделе НСИ и администрирование – Настройки интеграции – Интеграция с 1С:Аналитикой.

Функциональность включается установкой флага Интеграция с 1С:Аналитикой. Также в форме необходимо указать адрес сервера 1С:Аналитики. Из панели настроек по соответствующим ссылкам можно открыть:

■ Описание сервиса и интернет-ресурс для загрузки дистрибутива

■ Рабочее место Управление панелями

■ Рабочее место Управление дополнительными источниками

В форме настроек по ссылке Управление панелями можно перейти в рабочее место, предназначенное для выполнения настроек панелей отчетов 1С:Аналитики, которая позволяет установить определенным пользователям панели отчетов из сервиса 1С, файла и копировать панели отчетов от одного пользователя 1С:аналитики к другому.

Для загрузки поставляемых панелей используется кнопка Сервис 1С. При переключении проверяется доступность сервисов интернет поддержки. Кнопка Загрузить панели из сервиса вызывает окно загрузки панелей.

При открытии формы по умолчанию устанавливаются флаги для панелей (наборов отчетов), которые были загружены ранее. Выбранные панели загружаются из сервиса интернет поддержки в полном объеме.

В основной части формы копирования панелей слева отображаются список панелей отчетов в источнике, справа – в приемнике. Для приемника предусмотрено отображается состояние актуальности элемента пиктограммой – кружком зеленого (актуальный отчет) или желтого (не актуальный отчет) цвета, а также быстрый отбор по состоянию над таблицей.

Настройка панелей выполняется путем переноса панелей для соответствующего владельца (пользователя) в таблицу справа. Команды переноса размещаются между таблицами. Для копирования необходимо выделить элемент в панели источника и выделить владельца (или подчиненный элемент) в панели приемника. При позиционировании на элементе в панели приемника происходит поиск и позиционирование на элемент с таким же идентификатором в панели источника, если он есть.

Если выбрано несколько владельцев в приемнике, необходимо выбрать, кому будет установлена панель, а кому будут созданы ссылки на эту панель. Если не предполагается независимо редактировать панели, то имеет смысл установить панель одному владельцу, а остальным владельцам сделать ссылки. Если предполагается несколько редактируемых независимо вариантов панелей, то для каждого такого варианта требуется установить панели.

В настоящее время в сервисе доступны следующие наборы:

■ План-фактный анализ продаж (для ERP и КА)

■ Дебиторская и кредитрская задолженности

При загрузке из файла поведение формы аналогичное загрузке панелей из интернет-сервиса.

Файл с настройками дашборда «План-фактный анализ продаж» 1С:Аналитика для 1C:ERP публикуется на странице дистрибутивов конфигурации [https://releases.1c.ru/project/EnterpriseERP20](https://releases.1c.ru/project/EnterpriseERP20).

Если отчет передается через файл (например от партнера к пользователю) и при этом он построен с использованием "Дополнительного источника данных", то надо загружать строго сначала дополнительный источник, потом связанный с ним отчет.

При выборе режима настроек вариант источника Сервер аналитики можно создавать ссылки на ранее установленные панели новым владельцам или скопировать ранее созданную панель новому владельцу, если предполагается в дальнейшем ее редактировать и использовать независимо.

Все пользователи 1С:Аналитики должны быть зарегистрированы в качестве пользователей информационно базы, при этом они могут не работать в базе, а только использовать отчеты на сервере 1С:Аналитики.

После завершения настроек необходимо сохранить (пиктограмма в виде дискеты) настройки для всех или выбранных владельцев.

Рабочее место Управление дополнительными источниками позволяет создавать и редактировать источники данных для сервиса 1С:Аналитики, которые получаются по данным информационной базы с использованиям запросов на встроенном языке запросов.

После настройки интеграции с сервисом в разделах Главное – Отчеты и Финансовый результат и контроллинг – Отчеты будет добавлена команда Сервис 1С:Аналитка для переход
